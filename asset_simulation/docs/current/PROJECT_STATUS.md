## 市场边界

全球宏观能源世界保留总液体口径，油轮世界另有 crude-only 物理池。十个贸易盆地只从原油产量、炼厂原油加工、原油库存和原油管道形成独立且守恒的海运差额，航线矩阵再匹配出口供给与进口需求。模型不再以区域石油消费代理原油进口缺口；它仍不是国家级炼厂、油种品质、制裁流向、影子船队或实际港口装船模型。

所有扰动字段仅供测试恒等式与方向性；API、Viewer 与正常世界都不暴露扰动控制，也不会把扰动反馈进油价。
