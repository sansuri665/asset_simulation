# Asset Simulation 项目现状

> 状态：当前实现与近期路线的可分享摘要  
> 核对日期：2026-08-26  
> 模型根目录：仓库根下的 `asset_simulation/` Python 包  
> 原则：代码、注册配置和 JSON 契约高于本文。

## 一句话结论

项目已经形成第一个可运行的单品种机构竞技闭环：确定性全球宏观和原油期货市场之上，玩家与三家 AI 各自使用一套预测、策略研究、策略／公司两层风控、投委会资金授权和交易执行配置，再经正式现金／保证金账户约束，按半月盯市并生成排名和报告。

这还不是完成的游戏。模型闭环明显领先于界面和产品系统：当前 UI 适合开发验证，不适合正式游玩；玩家不能真正进行人员选择、额度批准或委托决策，账户也没有正式持久化。

## 当前可玩的闭环

```text
加载 Seed
→ 查看同一世界的原油现货、主连和4个月份合约
→ 查看玩家与3家 AI 随机抽中的四类负责人
→ 推进半个月
→ 四家机构分别生成预测、目标、风控批准和成交
→ 使用下一半月已实现 K 线盯市
→ 查看权益排名与本回合报告
→ 继续推进或重置同一 Seed
```

随机并不等于不可复算。同 Seed、相同版本和相同回合会得到相同市场、任命和结算；不同 Seed 会改变市场与人员配置。

## 关键架构事实

### 单一全球世界

产品只有一条全球宏观运行和一个计价单位，没有正式区域、G17、RoW 或双边汇率。`global_dollar_index` 是全球美元资金松紧代理，不是 DXY 或汇率。

全球同年顺序固定为：

```text
real_economy
→ inflation_nominal
→ rates
→ funding_credit
→ oil_commodity
→ asset_reference
→ 年度 row
→ NextYearInputs
```

同年只沿箭头前馈；返回上游只允许下一年生效。六个特殊宏观事件端口在普通 Seed 中全零。

### 原油市场

- 游戏使用现货参考、不可交易主连和4个 `OIL-YYMM` 命名合约。
- 交割月按01／05／09轮换，相邻交割月间隔4个月；单合约最长16个月、32个半月状态、64根周 K。
- 主连在到期月上半月换仓，以回溯比例调整消除机械跳空。
- 长期 carry 由资金、仓储、期限风险溢价减去便利收益形成；库存宽松倾向正向市场，库存紧张倾向反向市场，到期基差归零。
- 期货规格为1000桶／手、0.01美元／桶最小跳动、10美元／手跳值、15%初始保证金和12%维持保证金、现金结算。
- 全球巨型机构硬边界包括动态单合约限仓、150,000手全期限总仓和按近期成交量派生的半月成交上限。
- 玩家与 AI 都是价格接受者，不能改变市场价格、公开成交量、公开持仓量或宏观路径。

### 组织分工

| 组织层 | 决定什么 | 不决定什么 |
|---|---|---|
| 预测研究 | 未来方向、路径、区间和修订 | 仓位和额度 |
| 策略研究 | 把普通预测转换为理想目标仓位与换手授权 | 风险授权、公司额度和成交价格 |
| 策略风控 | 风控部按每个策略提出容量、波动、回撤与流动性建议 | 决定公司将多少资金押在该策略 |
| 投资决策 | 批准策略风险授权，直接决定项目资金授权 | 改写市场容量或跳过公司硬风控 |
| 公司风控 | 提出并执行公司汇总资本／回撤／集中／流动性要求 | 创造新信号或扩大目标 |
| 交易部 | 在公开容量内完成订单并控制磨损 | 改变预测和目标意图 |

配置能力分只负责生成预测质量和事后评价，绝不作为策略仓位的直接输入。策略可以完全使用预测上下限，但只能看到普通预测对象，不能读取隐藏未来路径。

## 当前竞技 Demo

每个 Seed 创建4个机构：玩家机构、北辰全球商品、瀚海资源资本和赤道宏观基金。每家初始参考权益为30亿美元，并稳定随机抽取预测、策略研究、公司 CRO 和交易执行负责人。CRO 的六维蛛网表示风险容忍取舍，不是能力总分；同一位 CRO 会根据各策略结构生成不同审阅。

每个半月报告包含：

- 主力合约、结算前后价格、市场结构变化；
- 本回合盈亏、累计收益、权益和排名；
- 期末仓位、买入／卖出／成交手数；
- 执行成本、风控状态和被裁剪手数；
- 各命名合约的策略目标与风控批准目标；
- 现金、冻结初始保证金、维持保证金、可用资金和超额流动性；
- 策略盈亏、空闲现金利息、保证金融资成本、追保缺口和强平成本。

Seed 0、42、99 的首回合冒烟结果已经出现不同抽签哈希、不同玩家名次和不同赢家。这证明流程没有写死，不证明候选人已经公平，也不构成成熟收益率分布。

## 现实可信度应该怎样表述

当前可信的是结构和相对机制，不是逐笔市场复制：

- 年度宏观、供需库存、期限收敛、换月、容量、成本与组织职责有明确 owner；
- 价格、成交量、持仓量和机构账户都可按 Seed 重放；
- 预测能力、策略风格、风控偏好和执行能力确实通过不同路径影响结果；
- 但周 K、月 K、流动性和合约曲线仍是合成市场，没有校准到具体交易所逐日历史；
- 当前收益不能宣传为现实机构预期收益，也不能把首回合排名解释成人员能力结论。

期限结构的跨 Seed 审计、预测能力隔离、策略成本、公司风控与机构交叉结果详见 [`MODEL_QUALITY_AUDIT.md`](MODEL_QUALITY_AUDIT.md)、[`OIL_TRADING_STRATEGY.md`](OIL_TRADING_STRATEGY.md) 和 [`CORPORATE_RISK_CONTROL.md`](CORPORATE_RISK_CONTROL.md)。

## 最大短板

1. **玩家没有真正的决策权。** 当前投资决策只是查看系统随机任命和结算结果。
2. **UI 明显落后于模型。** 信息密、层级弱、报告不够易读，尚无正式游戏视觉系统。
3. **存档不完整。** 浏览器只记回合；服务器状态是进程内缓存，重启后依靠 Seed 重放。
4. **利润引擎多样性仍不足。** 单合约方向引擎内部已有延续／回归、资金、反应、选择性、换手与持有差异，但期限结构相对价值尚未运行。
5. **账户制度仍缺持久化和组合化。** 正式现金／保证金、追保和强平已运行，但没有外部注资、动态 SPAN 近似、跨品种组合保证金、授信和可迁移账户存档。
6. **平衡尚未完成。** 首批3 Seed×3风格×3授权的三年分布已建立，仍不足以证明候选人长期强弱、胜率和多策略组合适合作为最终游戏规则。

## 下一阶段建议

### 第一优先：把 Demo 变成可决策

- 让玩家从 Seed 候选中任命四类负责人；
- 投资决策委员会批准原油额度、最大回撤和策略授权；
- 保持能力蛛网只读，不开放自由捏数值；
- 把同一套规则也应用于 AI。

### 第二优先：正式存档与账户扩展

- 建立可版本迁移的游戏存档 owner；
- 保存任命、账户、仓位、报告与回合位置；
- 长距离推进改为有进度的后台重放；
- 保存正式现金、保证金、追保、强平与破产状态；后续再加入动态保证金和组合抵押品。

### 第三优先：报告与 UI 重做

- 先重构信息架构，再做视觉装饰；
- 把委员会、风险、成交归因和排名拆成可比较视图；
- 增加回合变化、决策原因和主要盈亏来源；
- 统一桌面／窄屏布局，避免当前表格在宽屏过空、窄屏过密。

### 第四优先：策略和品种扩展

- 实现期限结构相对价值，并把单合约方向与跨期价差作为两个独立利润引擎管理；
- 再引入组合额度、期现关系和其它商品；
- 只有在独立市场对象真正出现时才建立资本市场 owner，不恢复旧区域／G17宏观机。

## 验收状态

2026-08-26 已完成8个 Seed×4家预测机构×6位策略负责人的全交叉审计，共13,824个账户回合。相同报告下策略收益相关为0.850，活跃策略对产生相反目标方向的比例为15.40%，策略年化中位数跨度为10.74个百分点，6种风格全部在至少2个样本单元获胜。这证明多样性门禁通过，不代表长期收益分布已经成熟。

正式账户首批27个三年情景的现金恒等式、账户不扩权和维持保证金恢复门禁也已通过；CAGR 中位数4.93%、年化波动中位数4.13%、最大回撤中位数−3.55%，普通样本无追保或破产。另有27条未参与门禁选择的留出情景全部通过，留出 CAGR／波动／回撤中位数为7.88%／5.56%／−3.79%。详见 [`OIL_FORMAL_ACCOUNT_AND_CALIBRATION.md`](OIL_FORMAL_ACCOUNT_AND_CALIBRATION.md)。这些验收保护确定性、边界和功能，不代表 UI 已完成，也不代表长期收益分布已经成熟。
