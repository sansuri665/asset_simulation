# 项目现状

> 最近核对：2026-09-01

## 已完成

- 单一全球年度宏观和原油价格锚；
- 不回写宏观的原油月度 OHLC 价格路径；
- 月度物理原油需求、产能、产量和库存；
- Seed 固定的延续增长、转型平台、较快转型三类长期需求路径；
- 围绕现实区间缓慢变化的动态库存目标；
- 年度振幅、相位和形状会变化的非模板化月度需求季节性；
- 不再机械复制需求波形的月度生产调整；
- 严格库存数量守恒；
- 十个贸易盆地的产量、原油当量需求、库存变化与管道流向；
- 由区域海运盈余和缺口内生生成的全球海运原油货量；
- 九条显式主要航线与一个其他航线池；
- 区域出口、区域进口与航线货量三重守恒；
- 航线级基准航程、有效航程、咽喉节点与贸易黏性；
- 加权平均航程与贸易改道；
- 回合及年化吨海里需求；
- 仅用于测试的供应、区域平衡与航程扰动注入，不进入正常游戏；
- 确定性、前缀、截点和多 Seed 审计；
- 三个同级 Viewer：宏观与原油、原油物理平衡、原油海运；
- 原油海运按全球总览、区域平衡、主要航线分图；
- 主要航线以可点击列表展示货量、份额、航程、吨海里和状态；
- 月度图统一支持悬停选月与固定72个月窗口拖动。

## 已退役

- 商品卫星；
- 原油期货和期限结构；
- 预测、策略、风控、交易执行和正式账户；
- 四机构竞技；
- 旧宏观／交易 Viewer 和游戏 Viewer。

这些内容仍可从 Git 历史恢复，但不再进入当前注册表、服务或测试。

## 尚未实现

- 原油轮船队和船龄结构；
- 活跃、封存、维修、降速和拆船；
- 船厂产能、订单、交付延迟和取消；
- 船队有效运力；
- 利用率和内生运价；
- 船东资产负债表与经营决策；
- 正式游戏 UI 和存档。

因此当前产品只能回答“市场需要多少原油运输工作量”，还不能回答“运价是多少”。

## 市场边界

全球物理原油仍是单池，但区域层已不再只是对预设海运总量的会计拆分。十个贸易盆地从全球产量、原油当量需求、库存和管道总量形成独立且守恒的海运差额，航线矩阵再匹配出口供给与进口需求。当前需求仍取全球石油消费的区域代理，不是独立炼厂加工量；它也不是国家级炼厂、油种品质、制裁流向或影子船队模型。

所有扰动字段仅供测试恒等式与方向性；API、Viewer 与正常世界都不暴露扰动控制，也不会把扰动反馈进油价。
