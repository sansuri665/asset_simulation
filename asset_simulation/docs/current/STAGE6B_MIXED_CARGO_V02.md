# Stage6B v0.2：共用货物、可替代船型与外部配船接口

分支 `stage6b-class-agnostic-mixed-fleet`，继承旧Stage6B `1d9f824ad6c099e7671446698f2fc5053054f38c`。本轮不动main，不改宏观/原油需求，不导入旧成本与垄断模型。

## 1. 关键边界

货物只属于起终点航线，不属于VLCC/Suezmax/Aframax。输入是该航线本回合**全部货量**和实际在港的各类船，输出统一的服务价值与各船型收益基准。船型份额是执行后的统计结果，不是需求分配规则。

```
完整Seed航线日货量 × 10运营日
 → 一份整数桶队列（新计划＋真实历史欠运）
 → 三类兼容船的合计即时载量
 → 纯报价组件
 → 外部配船方案，或可替换的测试装运规则
 → 对同一队列扣货、冻结航程、真实交付
 → 同一个目的地空船池、跨产地压载
```

源端、在途、交付和船号始终守恒，不能给三个船型各复制一份需求。没有货物核销、长期需求破坏、成本或船东利润优化。

## 2. 文件与版本

- `mixed_cargo_contract.py`：从Stage6A提取物理路径、兼容性、船速；生成同船型固定载量的服务定义。
- `mixed_cargo_pricing.py`：全航线货量与合计兼容运量→服务价值→各船型TCE基准；不选择船、不改台账。
- `mixed_cargo_market.py`：共用货物台账、永久船型与船号、外部配船/转场接口、测试装运器。
- `stage6b_mixed_fleet_v0.2.json`：明确的实验船队及报价/调度参数，没有航线船型比例。
- `stage6b_mixed_cargo_v2.json`：输入输出的单位与责任契约。
- `audit_stage6b_mixed.py`：同货量、近似同总载量的多配比审计。

旧Stage6A及Stage6B v0.1文件未删除，作为可复跑历史对照；新默认入口是 `run_seeded_mixed_market`。旧 `run_seeded_multi_origin` 仍表示旧VLCC份额子市场，不能混用口径。

## 3. 船型载量固定，份额先验不参与执行

| 船型 | 固定标准载量 |
|---|---:|
| VLCC | 1,971,000桶 |
| Suezmax | 985,500桶 |
| Aframax | 584,000桶 |

同一船号从海湾去西非后不会变载量。Stage6A的TD15等商业参考货盘只留在旧目录中作基准说明；不再决定新物理执行。没有港口吃水/油种密度模型的前提下，本版不增加这些差异。

新实现不读取 `class_share_bps` 来切货、配船、定价或初始化。修改全表至100% Aframax、或改变旧参考货盘，不改变新spec、实际装运或报价，已做变形回归。

只保留航路的兼容性掩码：某类船不能走选定路径时不能装运。份额为0不等于物理禁行。Aframax可用于当前允许的长程路径，只表示物理/游戏上可行，不意味着经济上值得这样运营。

所有船维持装货0回合、卸货1回合和固定10日时钟。阶段化参考计划仍归Stage6A的路径定义；选定出航后冻结，不追溯改变在途船。船型不同导致的航速/路径差异可在服务定义中表达。

## 4. 配船方案由外部提供；测试规则不是船东经济选择

`step_mixed_market(..., dispatch_by_origin_class=...)` 可明确指定每个产地派几艘每种船；只校验船在本地、船型兼容、没有重复派船且有足够真实货物。

例如面对同一份货和相同报价时，可以选一艘VLCC或两艘Suezmax。两者都装1,971,000桶并消耗对应真实船号。没有强制参考比例。

没有提供方案时，默认使用**最大化本回合完整装载量的测试规则**：用有界整数背包从实际开放船中选出不超过共用货量的组合；同体积平局时按较大船先的确定性规则处理。它不是最低成本，也不代表最终船东选择；未来经济层应替换它。

目前每艘被派出的船均按标准载量满载。不够最小可用船一票的余桶继续留在同一队列；没有部分装货、没有凭空补桶。更小船能接部分VLCC无法独自满载承运的尾量。

`ballast_orders={ship_id: target_origin}` 同样允许外部替换调船；省略时使用按**合计容量/参考循环时间**衡量覆盖的测试规则，不按每船型货量份额设目标。已向某地出发的船立刻计入承诺，不能复制给另一产地；在途船不计当前prompt。

## 5. 定价只对总运量算一次

每条航线先计算：

```
S_capacity = Σ(本地兼容船型数量 × 该船型固定载量)
D = 本回合完整航线货量
R = 正常prompt缓冲系数 × (D + 平滑容量)/(S_capacity + 平滑容量)
x_local = 3 × ln(R)
```

因此同一地点同一回合，1艘VLCC和2艘Suezmax替换后的总载量相等，航线紧张度及服务报价完全相同。不为每类船再分别创建一份D。

仅有总货量和可替代船舶输入，并不足以唯一识别三套独立船型稀缺溢价；本版不从“某类船少”凭空制造一条隐藏船型需求。不同船型独立的机会成本、燃油和资本差异交给未来相应模块。

## 6. 共同市场信号与小航线局部偏离

两地共享的市场信号是本地供需信号按参考货量加权的平均，**不是在本地短缺之上再叠一个全球涨价乘数**。

局部偏离围绕共同信号居中，并用 `tanh` 有界化；窗口容量小的航线给予较低局部证据权重。归一化后的局部残差加权和严格为0。公共变化保留，只有过大的局部差异被收敛。这是明确可配置的游戏报价规则，不是成本套利求解，也不是实证结果。

源端与共享目的地的压力仍有±5参考日的边界、3回合半衰期；真实欠运不截断。共同目的地信号按所选市场**完整货量**归一化，不把同一目的地缺口除以每个船型或小航线的日量反复放大。

报价参数不进入默认装运和调船。关闭共同信号、更改价格弹性，都不能改变同一场景下的装船序列与欠运桶数。它们只改变报价。

## 7. 各船型TCE不是同一个美元数，也不是毛运费

先产生以标准VLCC为单位的 `route_benchmark_real_tce`，再得到本航线统一的每桶净运输服务价值：

```
net_service_value_per_bbl
  = 标准船日收益基准 × 航线参考循环日数 / 标准VLCC载量

class_TCE
  = net_service_value_per_bbl × 该船型载量 / 该船型参考循环日数
```

当VLCC与Suezmax在同一航线上参考循环相同时，容量为一半的Suezmax得到一半TCE基准。这是**同一每桶服务价值的换算约定**，不是宣称现实Suezmax行情永远为VLCC的一半。没有成本和差异化需求时不强行求出“真实”三个船型价格。

换算使用显式的返原产地参考周期，不代表实际船一定这样返航。未来真实现金流必须使用实际执行的全周期和航次费用，不能重复收取参考压载收益。

所有报价均为指示性净运输服务基准，不是毛运费、成交发票或利润。每船型分别输出是否当前可执行；零船也可显示比较基准，但不能产生装运或现金收入。无新需求只沿用既有指示信号，原欠运仍可承运。

名义值使用最近已结算年度CPI；实际值仍按2025美元。参考VLCC的1,000—122,500美元软边界暂时保留；本轮没有声称已实现无上限的全世界价格发现。

## 8. 参考交付不能随着配船改变

每条航线只建立一份参考交付计划，默认用该航线VLCC服务的交付滞后（不支持VLCC时选第一种兼容服务）。实际到货则逐船按其冻结计划产生。

因此更慢船型迟到会真实体现在目的地计划偏离中，不能通过临时改变“正常到货日期”来消掉缺口。初始在途油和参考在途油配对登记，避免开局假欠运。

逐回合检查：永久船号与船型不变；真实在途等于全部载货船装载之和；装运按船型加总等于只扣一次的队列出库；源端＋在途偏离＋目的地贡献等于0。

## 9. 验证口径

见 `STAGE6B_MIXED_VALIDATION.json` 与CI附件。专题覆盖同载量替代、全部船型独立服务、任意外部配船、无配额先验影响、货量守恒、冻结航程、目的地共享、前缀一致、全货量Seed和四产地扩展。

20次年度转移包含2025—2045这21个标签年。首年预热只排除统计，不清空欠运；报告2026—2045的720回合、7200运营日。

新模式使用全部航线货量，旧模式只用原先VLCC份额。因此不能直接把旧265艘结果和新混合船队价格做优劣判断。同口径比较使用相同完整Seed货量和相同/近似相同的船队总载量。

即使总载量完全相同，实时船位、完整货盘组合和返航批次也可能不同，所以不同混合船队的长期价格并非必须完全一致。只有在**当前同一地点总可用载量和其他输入一致**时，才要求纯报价替代不变。

## 11. 本轮实际数值（不是实证校准）

本地Python3.13完整222项回归通过（新增34项），Viewer27项断言通过。新专项审计5个Seed × 4种船队 × 20次年度转移，另有四产地Seed42及60次年度转移长窗，16项审计门槛全部通过。最终远端CI状态以该提交Actions为准。

### 等/近等总载量，而不是等船数对照

| 方案 | VLCC | Suezmax | Aframax | 总载量（百万桶） |
|---|---:|---:|---:|---:|
| 全VLCC | 300 | 0 | 0 | 591.300 |
| 混合一 | 240 | 120 | 0 | 591.300 |
| 混合二 | 210 | 180 | 0 | 591.300 |
| 三船型 | 225 | 120 | 50 | 590.935 |

以上均服务海湾→东亚和西非→东亚**全货量**。不能拿旧Stage6B的265艘VLCC份额子市场来直接比。

### 恒定日流量（海湾9.3，西非1.2 mb/d）

| 方案 | 海湾报价CV | 西非报价CV |
|---|---:|---:|
| 全VLCC | 2.25% | 10.85% |
| VLCC＋Suezmax | 1.03% | 4.15% |
| 三船型 | 0.60% | 2.73% |

这些结果使用相同的共同报价规则。另关闭共同信号，在同一混合船队、同一实际装运记录上西非CV为7.35%，中位数约10,249；开启后CV4.15%，中位数约12,444。由此区分“小船改善整票离散”和“报价规则收敛局部差异”的两种作用，不能把全部改善都说成真实市场套利。

### 真实Seed42，2026—2045统计窗口

| 方案 | 海湾参考TCE中位数/P95 | 西非参考TCE中位数/P95 | 海湾/西非最大欠运日 |
|---|---|---|---|
| 300VLCC | 25,280 / 68,836 | 20,925 / 94,912 | 15.17 / 31.37 |
| 240VLCC＋120Suezmax | 24,764 / 65,829 | 21,760 / 99,565 | 14.26 / 33.47 |
| 210VLCC＋180Suezmax | 24,764 / 65,829 | 21,760 / 99,565 | 14.26 / 33.47 |
| 225VLCC＋120Suezmax＋50Aframax | 24,597 / 63,745 | 22,247 / 95,633 | 14.32 / 32.03 |

金额为2025美元/日、统一标准VLCC等效基准，不是把小船每天收入也设为相同金额。240＋120组中Suezmax对应的指示TCE中位数约海湾12,382、西非10,880。

在当前相同船速/路径条件下，240＋120与210＋180两组在本次实验中有相同的有效装载和报价路径，但实际船型结构明显改变：海湾VLCC实际承运份额由83.4%变为73.5%，西非由81.7%变为69.2%。它们由当前船队与测试配船算法产生，不是回写了隐藏配额。

三船型组海湾/VLCC、Suezmax、Aframax承运约78.4%、17.3%、4.3%；西非约75.8%、19.4%、4.8%。这一结果不是“最优经济结构”，较大船平局优先的测试规则会影响份额；外部经济模块可直接替换。

注意：240＋120组的西非有33回合没有当前可用运力；其全部指示报价P95并不等于成交P95。按实际装运量加权的标准船TCE基准均值约海湾31,116、西非24,715。混合船队在真实Seed中的西非P95并未比全VLCC低，最大欠运也没有全面改善。小船改进可用货盘粒度，不保证任何供需路径都更平稳，更不能消除真实总运力约束。

### 真实冲击仍会涨价

恒定市场中仅将西非第80—91回合的工作翻倍，240VLCC＋120Suezmax不增船：海湾观察窗峰值由约15,835升至114,628；西非由13,178升至117,833。伴随实际运力重分配，前80回合路径完全一致。这证明没有把全部响应压平；由于报价含共同信号，此表不单独证明全部涨幅都是物理转场造成，只有承诺容量变化是直接物理证据。

原始台账仍可出现较长欠运，指示报价不等于实际成交/收入；更不能以通过守恒门槛认定价格现实性已被校准。
