当前换算锚为7.3桶/公吨。不同油种密度会产生差异，因此它是全球原油池的统一近似，不是逐油种计量。

## 守恒恒等式

```text
期末库存
= 期初库存
+ 产量 × 回合天数
- 实际需求 × 回合天数
```

```text
单航线回合吨海里
= 航线货量（百万桶/日）
× 回合天数
÷ 桶/公吨
× 航线有效航程
÷ 1000

总回合吨海里
= Σ 单航线回合吨海里
```

场景端口支持需求率、生产中断、区域生产／炼化／库存偏移和航程变化，但只用于测试，不由服务、Viewer 或正常游戏暴露。契约明确不含运价、TCE、船队或订单簿。

每个月还必须满足：

```text
区域海运净平衡
= 区域产量 − 区域原油当量需求
− 区域库存变化 ÷ 天数 − 区域管道净出口

Σ 区域海运净平衡 = 0

Σ 航线货量
= Σ 区域出口
= Σ 区域进口
= 全球海运总货量
```
