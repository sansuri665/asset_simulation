## 2. 全球快照

`global_macro_minimum_v3` 有3个身份字段、26 个 A 级字段、11个 B级字段和2个派生恒等式，共 42 项。

所有金额和价格默认使用单一全球美元账户。不存在本币／美元换算。`global_dollar_index` 是无量纲资金松紧代理，不是 DXY 或双边汇率。

### 名义与实际

- 名义 GDP：当年万亿美元；
- 实际 GDP：2025年不变价万亿美元；
- CPI／GDP平减指数：2025=100；
- 名义资产／商品：包含一般物价环境；
- 实际商品和实际财富：支持审计口径，不是默认主图。

## 3. 商品 overlay

`commodity_overlay_v1` 只读已结账全球行：

- Brent 内部价格透传全球石油 owner；
- WTI 是相对 Brent 的价差卫星；
- 其它合约由实际油价、综合商品和美元资金条件派生；
- 一级种类篮子是成员实际指数加权平均；
- 月线12根沿年开盘到年收盘展开，月内影线扫到年度高低；
- 每月4根周线嵌在月度包络内。

这些月／周 OHLC 是合成长周期路径，不进入全球42项，也不能回写宏观。主 Viewer 对外统一显示“原油”，不把 Brent／WTI 当成两个二级商品。

## 4. 原油期货

### 时间与标的

`oil_futures_overlay_v8` 每月有上／下半月两个截点，固定列出4个 `OIL-YYMM` 合约。交割月份按01／05／09循环；单合约最长16个月、32个半月状态、64根周 K。上半月公开 W1—W2，下半月补齐 W3—W4。

主连是回溯比例调整展示指数，不可交易。现货是现金结算参考，不带期货成交量、持仓量和参与者限额。

### 价格与期限

报价和 OHLC 单位均为美元／桶。长期 carry 目标：

```text
资金成本 + 仓储成本 + 期限风险溢价 - 便利收益
```

便利收益随已结账库存松紧、供需缺口和近期可见趋势有界变化。长期斜率、近端压力和曲率把目标展开到期限曲线；最终结算基差归零。

### 流动性

- `volume_lots`：周成交手数；
- `open_interest_lots`：周末持仓手数；
- `open_interest_change_lots`：周末持仓变化；
- 月／年成交量：可见周求和；
- 月／年持仓量：期末值。

全球总持仓由有界慢周期生成，成交量由持仓和周换手率形成。最后8周使用共同 `smoothstep` 迁移合约份额，最终结算周归零。

### 标准规格与限额

| 项 | 单位／规则 |
|---|---|
| 合约规模 | 1000桶／手 |
| 报价 | 美元／桶 |
| 最小跳动 | 0.01美元／桶 |
| 每手每跳价值 | 10美元 |
| 初始／维持保证金 | 15%／12% |
| 结算 | 现金 |
| 总持仓上限 | 四合约绝对头寸合计150,000手 |
| 常态单合约上限 | `min(当前市场持仓量3%, 75,000手)` |
| 半月成交上限 | 最近4周周均折算两周后的0.8% |
| 到期收紧 | 15,000手 → 8,000手 → 仅结算 |

后台策略和竞技账户已经执行限仓、成交容量、现金冻结、初始／维持保证金、追保和强平。仍未实现的是玩家外部追加资金、动态组合保证金和委托界面；不能再笼统写“保证金状态机尚未执行”。

## 5. 预测研究

`oil_short_term_forecast_v1` 覆盖当前主力和下一主力两个命名合约，价格为美元／桶，能力与评分为0—100分。

- 半月 vintage 只包含截点后的预测周；
- 当前普通预测对象不含未来真实行情；
- 评分只能读取评价截点已经实现的周；
- 能力总分只生成预测质量和事后评价，不得进入策略仓位公式；
- 独立预测 API 保留，游戏行情页不再展示预测 K；竞技会话后台调用。

## 6. 策略研究

`oil_strategy_research_v2` 的八维是延续／回归倾向、资金部署倾向、调仓反应、入场选择性、换手活跃、持仓耐心、近月集中和预测期限。各维0—100连续，没有能力总分。

档案只能改变策略授权参数，不能修改合约规格、硬限额、公开容量、手续费、价差或基础滑点。资金部署按已分配策略权益计算，当前单品种 Demo 暂以当期账户权益代理该额度；公开限仓仍是其后的独立硬上限。roster API 只接受 Seed 和候选数量，不接受玩家自由输入蛛网。

## 7. 策略风控与公司风控

`oil_strategy_risk_v1` 让风控部对每一位已任命策略负责人单独生成容量、波动、回撤、集中、流动性和移仓建议。建议不是资金分配；决策委员会批准风险授权，并独立设置该策略的资金授权。

`corporate_risk_control_v2` 的六维偏好不变，但职责收口为公司组合总要求：风控部提出，决策委员会批准，每回合由风控部自动执行。它位于所有单策略风险授权之后，只能保留或缩小汇总目标。

## 8. 交易部

`oil_execution_desk_v1` 有六项连续能力和三项风格。能力按25%／20%／15%／15%／15%／10%形成招聘总分；50.0严格对应中性执行。

能力只能修改可避免价差、冲击、周权重、正常指令完成、旧合约退出磨损和软性经纪费，不能改变预测、策略目标、硬限额、市场容量、交易所／清算／现金结算费。

## 9. 交易策略与账户

`oil_trading_strategy_v8` 当前运行模型为 v1.1.0：

- 决策委员会先设置策略资金授权，资金部署倾向只作用于这笔资金；
- 策略研究在延续／回归光谱上组合冻结预测与已可见历史，形成理想意图；
- 上一份预测只能在下一回合结算后被评价，观点观察／失效状态会缩小目标并阻止直接穿零反转；
- 单策略风险授权先裁剪，公司组合风控再裁剪，市场单合约与总持仓上限始终是最终硬边界；
- 公司风控形成批准目标；
- 交易部在下一半月两根新周 K 中执行；
- 限价穿透决定成交；
- 净调仓和额外往返成交共享公开容量；
- 持仓收益拆为共同油价方向与合约相对表现，净调仓拆为机械移仓与普通方向调仓；成本与盈亏按周、合约和回合严格归因；
- TCA 使用同一批订单比较50分中性交易部。

带符号仓位：正数为净多，负数为净空。买入增加仓位，卖出减少仓位。回报百分比以回合起始权益为分母；最大回撤以历史权益峰值为基准。

## 10. 尚未冻结的产品契约

当前没有正式契约的对象包括：

- 游戏存档、玩家账户和版本迁移；
- 投资决策委员会的额度与审批；
- 现金余额、保证金冻结、追保和强平；
- 多策略组合、多品种和期现账户；
- 长期报告分页和年度快照；
- LLM 指令、招聘和人员生命周期。

这些对象在实现前必须先明确 owner、单位、时序、身份和最小验收，不能直接塞进现有市场或宏观契约。
