# Stage5A v0.2：固定10天、有限报价记忆、完整运输台账

分支：`stage5a-fixed10-bounded-pressure`。继承 `7c2cc8a` 的编号船与整数桶台账，替代旧 `stage5a-gulf-east-asia-physical-market`；main 不改。旧提交通过本分支祖先保留。

## 1. 这一轮的边界

只改运营时钟与报价压力，不新增船、不拆船、不加入船东策略、成本或需求破坏。船的 `0装货 + 2重载 + 1卸货 + 2压载` 不变；每回合固定10个运营日，因此30日交货、50日返回。

`single_route_fleet` 仍只负责船；`single_route_market` 负责真实运输和计划台账；新增纯函数组件 `bounded_route_pricing` 负责有限压力与软边界报价。main 的 `single_route_pricing` v0.2.1 代码和配置完全不改，保留作对照。

## 2. 两个时钟必须说明白

每个月的 Seed 日货量用于三个10日回合，即游戏月30日、标签年360日。保留日货量，而不是强行保留28/29/30/31日的源月总桶数。不会在月末或年末补5/6天的突发货盘。

这是从上游参考世界到运营世界的投影规则，不是丢弃已经进入运输台账的货。源数据仍保留自然日口径，且不被回写。

每月分别输出 `source_calendar_month_cargo_bbl`、`operating_month_cargo_bbl` 和 `clock_projection_difference_bbl`。以 Seed42 的2025—2045窗口为例，上游自然日参考量为72,430,642,730桶，360日运营计划为71,392,769,640桶，差约−1.43292%。因此新旧船队需求变化不能全部归功于压力函数。

正常9.3 mb/d在50运营日循环下占用约235.92艘，而不再是旧自然月窗口下约239.2艘。245艘在恒定需求下多于参考所需运力，故价格不必等于35,000。

## 3. 真实欠运不截断，报价压力有上限

真实 `origin_bbl`、实际在途、实际交付继续按整数桶严格守恒。没有核销、过期、遗忘或需求永久下降。250天的原始欠运可以继续显示为250天。

但报价不再每回合把这250天重新变成“全新紧急货盘”。新增 `pricing_pressure_days` 是一个有界短记忆信号，不是第二个货物库存：

- 上限/下限：默认±5个参考流量日；
- 回合开始：加入本回合已知的交付偏差变化；
- 回合结束：压力乘 `2^(-1/3)`，再加入本回合装船偏差变化；
- 两端各计一半，以免同一缺运过程双倍加权；
- 两次都将信号限制在±5日，避免极端历史躲在报价上限后无限累积；
- 补运导致的缓解不会在原始缺口仍为正时产生虚假的“过剩恐慌”。

写成公式，设参考日量为q0：

```
x_open = clip(x_previous + (reference_arrival - actual_arrival)/(2*q0), -5, 5)
x_close = clip(2^(-1/3)*x_open + (planned_load - actual_load)/(2*q0), -5, 5)
```

没有新的错配变化时，额外压力每3回合减半。之后进入报价函数的有界等效压力为：

```
u = tanh(x_open/2) / tanh(5/2)
priced_pressure_days = 5*u
```

真实欠运只作为诊断字段，不会再次直接注入报价。**单纯对原始欠运用tanh只能限制幅度，不能限制持续时间；短记忆信号是本轮额外引入的明确游戏规则。**

## 4. 不用报价压力决定是否偿还旧欠运

实际派船仍受原有有界补运意向、真实可装货物与prompt船数约束。原始欠运继续用于实际补运排队；该执行规则不读取新报价、半衰期或压力阈值。

报价中的“急迫需求”和执行中的“可运输旧货”不是同一个量。历史欠运可以继续运输，但不必永远获得紧急货盘的最大溢价。字段分别输出 `pricing_cargo_demand_mmbbl` 与 `execution_request_bbl`，不会伪称这是买卖双方内生清算的成交量。

改变压力半衰期或价格曲线，不能改变同一输入下的发船序列和欠运桶数；该项有回归测试。

仍须注意：旧货占船是真实约束。**有界报价记忆不能保证在持续物理缺船时价格也快速恢复。**本轮只去掉无限累积的额外焦虑，不制造空闲船。

## 5. 上下界是软边界，不是成本线

先保留原有船货比信号和敏感度3.0、库存系数0.03、价格惯性0.25，再用锚定的logistic曲线输出实际TCE：

```
L=1000, B=35000, H=122500
p0=(B-L)/(H-L)
a=log(p0/(1-p0))
k=B/((H-L)*p0*(1-p0))
TCE=L+(H-L)*sigmoid(a+k*signal)
```

该曲线在信号0时等于35,000，并保留旧指数曲线在正常锚附近的局部斜率；高低两端渐近饱和。价格惯性在可逆的logistic信号空间处理，不在每回合重复压缩上一报价。

这仍是游戏中的指示性TCE，不是已实证标定的货主支付意愿，更不是OPEX地板。零供给不产生运输收入；零新增需求可以继续清理旧货，但沿用上一指示价格而非制造新价格观测。名义值继续使用已结算年度CPI。

## 6. 实际效果

本地Python3.13完整131项测试通过，Viewer的27项断言通过。5 Seed × 8船队 × 20次年度转移，以及Seed42四种船队60次年度转移的审计门槛全部通过。最终远端CI会再次在3.11、3.13执行。

### 分离改进来源（Seed42/245艘）

旧日历/旧曲线中位数80,323；固定10日的同一真实执行记录，用旧原始欠运曲线重报价，中位数67,499；固定10日＋原始欠运静态饱和＋软价格边界为55,389；固定10日＋有限记忆＋软边界为38,032。

后三者使用相同船位和相同真实执行量，只重新计算报价。时间参考归一化为10日，因此不是对旧版输出单独改一个公式的伪对照。

### 欠运仍多但不继续无限焦虑

纯报价隔离控制：固定100日原始欠运，当前供需回到参考状态，不再产生新错配。只用静态饱和会将价格长期留在约53,802；有限记忆版本在第12、24、36回合约为38,031、35,188、35,012。原始100日欠运未被删除。这个控制只检验报价记忆，不代表真实船队一定同时具有这些输入。

### 短期真实冲击没有被抹掉

245艘的恒定日量世界，连续9回合增加10%运输工作，峰值实际TCE仍达约66,149；最大欠运约5.18个平均流量日。说明去掉的是机械回声和无限历史溢价，而不是把供需价格压成一条直线。

## 8. 有意保留的局限

只有一条航线，没有货物替代、货主策略或停航博弈；软上下界与半衰期仍是明确可配置的设计参数。跨年代同时报告实际/名义价格。报价改善不等于偿清物理欠运，也不等于完成了全市场价格发现。
