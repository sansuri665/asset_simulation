# 当前运行架构

> 状态：当前实现事实  
> 权威范围：年度／半月时序、状态、缓存、API 和回写边界  
> 代码基线：全球 v0.8.1、服务 v5.41  
> 最近核对：2026-08-25

## 1. 产品边界

默认宏观入口是 `model.engine.run_global_macro`，返回单一 `asset-simulation-global-macro-v0.8.1`。世界只有一个计价单位，没有正式区域、G17、RoW 或双边汇率。旧 `capital_market_lab`、四区宏观、银行行业和命名个股都不是运行时依赖。

服务 `asset-simulation-macro-ui-v5.41` 默认监听8783。主 Viewer 投影全球年度世界；游戏页在同一 Seed 世界上投影半月原油市场和四机构投资决策竞技。

## 2. 两个时间尺度

### 年度宏观

`model/engine.py::_transition` 的同年顺序固定为：

```text
real_economy.step
→ inflation_nominal.step
→ rates.step
→ funding_credit.step
→ oil_commodity.step
→ asset_reference.step
→ 年度 row
→ NextYearInputs
```

同年信息沿箭头前馈。资产、信用或油价若要影响上游，只能通过具名 `NextYearInputs` 在下一年生效；禁止同年隐藏第二次求解。

### 半月游戏

游戏把2025—2029作为只读观察期，从2030-01上半月开始，每月两个状态，到2085-12下半月，共1344个状态。一个状态只公开当前截点及以前的周数据。

```text
当前半月市场
→ 四家机构分别生成当前预测 vintage
→ 策略研究形成理想目标
→ 公司风控形成批准目标
→ 交易部在下一半月两根周 K 中执行
→ 下一半月价格盯市
→ 更新账户、排名和报告
```

普通推进只能向未来；跳到未来必须依次补算中间回合。重置当前 Seed 是唯一正式倒流操作。

## 3. 市场所有权

`oil_futures_overlay` 只读已经结账的全球与商品数据，并在指定半月截点生成：

- 现货参考；
- 4个01／05／09交割月份合约；
- 不可交易的回溯比例调整主连；
- 截点内月／周 OHLC；
- 合约成交量、周末持仓量、换月迁移和参与者限额。

期货定价不读取玩家行为或未来游戏周价。投资决策、预测、策略、风控和执行也都不能写回市场。因此竞技是“共同市场路径上的价格接受者比较”，不是四家互相撮合形成的价格博弈。

## 4. 竞技会话

`OilInvestmentCompetitionSession` 为每个 Seed 世界创建玩家和三家 AI。每家拥有自己的：

- 预测、策略研究、公司风控、交易执行档案；
- 预测 vintage 链；
- 权益、仓位、峰值和最大回撤；
- 风控状态与费用返还历史；
- 成交、成本、胜负回合和报告累计。

四家使用同一套 runtime 和同一市场，只在人员配置和账户历史上不同。首版任命由 Seed 稳定随机抽取，界面只读。

## 5. 身份与确定性

全球 identity 绑定模型版本、配置、字段契约、随机流、结果哈希和下一年输入哈希。竞技 identity 另外绑定：

- 上游全球 identity hash；
- 参与机构 roster hash；
- 竞技模型版本；
- 当前结果 hash；
- `write_back=false`。

同 Seed、相同版本、年数和回合可重建相同状态。短窗口必须保持长窗口前缀一致；不同 Seed 不保证排名顺序或候选人强弱相同。

## 6. 缓存与持久化

| 状态 | owner | 生命周期 |
|---|---|---|
| 全球运行 | `_RUN_CACHE` | 进程内，最多64条 |
| 竞技账户与报告 | `_COMPETITION_CACHE` | 进程内，最多8个世界 |
| 当前游戏回合 | 浏览器 `localStorage` | 按 Seed 保存，当前版本 v3 |
| 正式账户存档 | 无 | 尚未实现 |

竞技缓存键包含 Seed、年数、全球 identity 和竞技模型版本。服务重启后，浏览器仍知道当前回合；首次请求会从2030-01上半月确定性重放至该回合。长距离重放目前同步完成，可能产生明显等待。

请求比当前竞技状态更早的回合时，会清空该会话账户并从开局重放。这一能力服务于“重置游戏”，普通 UI 不允许随意倒流。

## 7. API

| 路由 | 时间边界 | 写状态 |
|---|---|---|
| `/api/health` | 当前服务 | 否 |
| `/api/global` | 年度完整运行 | 只写进程缓存 |
| `/api/oil-futures` | 指定年／月／半月截点 | 否 |
| `/api/oil-investment-competition` | 从开局至指定半月 | 推进或重放进程内竞技会话 |
| `/api/oil-short-term-profile` | 无市场时间 | 否 |
| `/api/oil-short-term-forecast` | 指定半月 | 否 |
| 三个 roster API | 无市场时间 | 否 |

游戏页并行请求 `/api/oil-futures` 和 `/api/oil-investment-competition`，并检查二者 `asOf` 与前端回合一致。行情详情不再请求短期预测 K；预测 API 保留给独立研究调用和后台竞技。

## 8. 回写矩阵

| 下游层 | 可读取 | 可修改 |
|---|---|---|
| 商品 overlay | 已结账全球行 | 自己的只读派生结果 |
| 原油期货 | 截点内商品／宏观和可见历史 | 自己的期限与流动性派生结果 |
| 预测 | 当前市场、机构档案、后台隐藏路径用于制造误差差异 | 自己的报告；不改市场 |
| 策略研究 | 普通预测、市场、账户 | 理想目标 |
| 公司风控 | 理想目标、市场、账户、风险状态 | 只能保留或缩小目标 |
| 交易部 | 批准目标、公开容量、下一半月实现 K | 账户和执行报告 |
| 竞技会话 | 上述所有普通对象 | 各机构账户与排名；不改公共市场 |

## 9. 当前架构缺口

- 投资决策委员会仍由系统代理，没有玩家批准、额度分配或策略组合。
- 浏览器回合与服务器账户分属两个临时 owner，没有正式存档事务。
- 保证金预算和限额进入策略约束，但没有现金冻结、追保和强平状态机。
- 竞技接口返回全部历史报告，长期运行后载荷会膨胀；尚无分页或快照。
- 长距离推进同步重放，没有任务队列、取消和进度 API。
- 只有原油和一个方向信号家族，尚不能检验真正的多资产投委会架构。
