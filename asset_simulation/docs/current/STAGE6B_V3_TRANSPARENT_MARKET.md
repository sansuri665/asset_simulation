# Stage6B-v3：透明报价、逐船装载、货批与已承诺运力

分支 `stage6b-v3-transparent-market`；继承Stage6B-v2 `6f6aaa24e44784ff3eb0538e488636cff5f7d88b`。不改main、上游原油需求、旧Stage5A/6A及v2计算代码。新入口为 `asset_simulation.model.shipping_v3`。旧代码保留为可重跑对照，不混用模型版本。

## 1. 这次的边界

这是所选产地到同一个目的地的航运研究内核，默认海湾、西非→东亚，可配置原来的四产地。不是全世界，也不是船东公司。

```
当前真实船位和已冻结的航程
       + 本回合新货批
       ↓
到期交货 → 货批台账 → 即时与已承诺运力曲线
       ↓
可解释的指示报价（一次）
       ↓
外部逐船装货/空船转场决策
       ↓
原子执行、逐船冻结实际载货和批次来源
       ↓
下一回合重新读取真实计划
```

核心不选择收益最优航线，没有成本、公司、债务、船厂、拆船、货主议价或长期需求破坏。没有同一回合“价格→改派→重新价格→再改派”的循环求解。

## 2. 不满载成为能力，不是强制策略

标准载量仍固定：VLCC 1,971,000桶；Suezmax 985,500桶；Aframax 584,000桶。同船型不因产地改变标准载量。

外部指令是逐船的 `LoadOrder(ship_id, cargo_bbl)`，只要求：

```
0 < actual_load <= vessel_capacity
所有船实际装货之和 <= 本产地真实剩余货量
船在本地、船型可用、没有在途中、没有重复出发
```

700,000桶的VLCC与满载VLCC占用同一完整航次；不能按载量把船体或航程折成0.355艘/回合。实际舱单、实际到货、报价参考价值均用实际桶数，满载TCE换算值只作比较基准，不作为部分装载收入。

默认测试策略先使用原最大完整装载量组合，再允许每个产地最多一艘尾货船。默认最低尾货装载率70%，审计另做50%和100%对照。阈值不限制外部合法订单，例如用户仍可明确让一艘VLCC只装100,000桶。测试算法不是船东经济选择，更小的阈值也不保证更高效率。

## 3. 货物有身份、年龄和自己的交付日期

每一批新货有 `batch_id / origin / destination / created_turn / due_turn / total_bbl / remaining_bbl / delivered_bbl`。同一船可以装多个批次，同一批可以分给多艘船；舱单中的 `CargoSlice` 把真实桶数和来源绑定。

装货优先最早到期批次，到期相同按产生时间、稳定ID排序。原始欠运完整保留，已交付批次也保留用于追溯，没有过期删除、遗忘或按价格上限核销。

计划交货日期由货物服务计划确定，不由被选船型决定。默认配置显式写出海湾→东亚3回合、西非4回合、巴西5回合、美湾6回合；也可在 `BatchOrder` 中指定独立到期日。更慢的船晚到，就实际产生迟延，不能通过修改“正常到货日”消除迟延。

一条船到港时只交付它的真实舱单，不按到港时的市场报价重新定价。输出区分未装货年龄、已过期未装量、已过期未交付量及实际交付迟延；“欠运20个正常流量日”不等于“最老一批已等20天”。

初始化中已有在途货用 `bootstrap:` 批次标识，并配对参考到货。只有这些已登记的开局前史可使用负的产生/出发回合。普通用户回合从0开始，不再暴露旧实现的内部时间偏移。

## 4. 不是预测，而是可重建的已承诺到港表

报价的每一项运力来自具体船号：

- `A0`：现在就在产地的兼容开放船；
- `A1`：正在压载，冻结计划明确于下一回合抵达此产地；
- `A2`：同理，两个回合后抵达。

这些是**逐期新增到港量，不是累计船数**。当前船不会在A1/A2里再计一次；同一船不能出现在两个产地或两个桶中。超出观察范围的确定到船单列，不计当前报价。正在载油去东亚的船不推定它以后回哪里；东亚未决定转场的空船也不分摊给任何产地。

默认权重 `[1, 0.5, 0.15]` 是公开可调的设计参数。未来运力只影响指示报价，不参加当前装货校验、不形成未来订舱合同。已开出的航程不可改派；尚未执行的外部方案可以重做，但只有实际提交后才进入下一回合的到港表。

每次从当前船和MovementPlan重建，而不是维护另一套容易漂移的预测库存。`build_availability`提供船号、类别、容量、目标和到港回合，支持逐项追溯。

### 为什么不能简单把未来船加到今天供给上

直接使用 `A0 + 0.5 A1 + 0.15 A2` 去对比一回合需求，会把正常返航算成免费额外供给。v3使用显式正常运力曲线归一化：

```
W = A0 + 0.5*A1 + 0.15*A2
normalizer = 1.06 + 0.5 + 0.15
normalized_capacity = W / normalizer
R = (当前一回合货量 + 平滑容量) / (normalized_capacity + 平滑容量)
```

在普通覆盖状态 `A0=1.06Q, A1=Q, A2=Q` 下，R=1，基准报价35,000不随预期窗口长度而变化。这不是额外创建了未来货物，也没有读取未来Seed货量；Q只是当前货量被用作不变工作率的比较基准。配置关掉未来项时归一化也随之变化。未来预期权重仍需要标定，不把这套规则声称为现实交易价格定律。

## 5. 欠运紧迫度与总价格限制拆开

源端与共享目的地压力仍有±5参考日上限、3回合半衰期，只记录新失衡及其近期影响。物理欠账不衰减。

价格结构为：

```
局部供需信号 = 3 * ln(R)
共同市场信号 = 所选产地按参考货量加权的信号
局部差异 = 围绕共同信号的有界、居中偏离
最终市场信号 + 独立有界欠运信号
    ↓ 分别加入0.25惯性
TCE = 35,000 * exp(市场信号 + 欠运信号)
```

局部偏离在重新居中后再统一缩放，保证“加权和为0”和“绝对偏离不越界”同时成立。共同项仍是明确的平滑设计，不是经济套利解，也不额外叠加一个重复的全球短缺乘数。

欠运项在默认参数下最大乘数约为1.65；严重历史欠运不能仅靠这个项把正常35,000推成200,000。但是当前市场确实缺船时，市场项可独立推过旧122,500上限。

最终只保留1—1,000,000美元/标准VLCC日的宽数值保护，命中会在每个报价和审计里显式报告；它不是OPEX底线或买方支付上限。保护触发时去掉藏在限幅后的超额价格记忆。当前指数标尺仍为正，不代表本版已涵盖现实负TCE或成本风险。

所有价格均先按2025购买力生成，再以最近已结算年度CPI名义化。相比v2，去掉logistic整体软上限本身就会改变高尾部，不能把新旧价格差全归于部分装载或未来运力。

## 6. 每个报价有可以复算的解释账本

输出当前货量、A0/A1/A2、权重、归一化除数、参考货量、平滑容量、供需比、共同项、本地偏离、原始和有界压力、上期两类价格记忆、惯性、最终对数价格、数值保护与CPI。

`recompute_price(explanation)`可以独立复算最终报价。部分装载实际执行也输出实际桶数对应的参考服务价值及参考周期日收益；所有字段明确不是发票、利润或现金。

各船型仍从统一每桶净运输服务价值按容量和参考周期换算。没有成本、质量差异或独立船型外部市场时，不凭空制造三套船型需求溢价。实际非满载参考收益按装载比例变化，而不是继续使用满载日收益。

## 7. 决策接口与时点

`prepare_turn`只接收当前货物和真实状态，处理到期到货并生成冻结快照。`settle_turn`接收明确船级订单，检查快照ID一致，再一次性执行。无效方案不能部分修改输入。一个开放快照不能再被当作新回合打开。

相同快照可以用于多组离线反事实比较；它是纯函数，不承担服务器持久化的并发锁。未来正式服务应把快照/状态版本校验作为写入条件，不能把同一份订单重复计入持久账。

`Decision`允许不派船、不转场。停在产地的开放船仍是市场供给，不因测试策略没有派它就被当作撤回报价。未给外部策略时才使用独立 `policies.py` 的测试方案；修改价格参数不会修改这个测试方案的实际配船路径。

`dump_state / load_state`只对已结算状态存档，保存全部批次和在途舱单，带版本、spec和内容校验。中断再继续与连续运行完全一致。

## 8. 时间机会诊断，不引入成本

`time_only_opportunities(snapshot, spec, ship_id)`比较一艘当前开放船去各个兼容产地、再运输到共同目的地的参考服务价值/占用时间。所有选项终止于同一卸货完成的目的地。

它显式包含从当前位置压载至产地的时间，不重复加第二次“标准回程”。例如从东亚开始、经海湾装货再回东亚是2+3=5回合，不是5回合再加2回合。部分装载降低价值，但不缩短时间。

这只是诊断，不读取未来运价、不算燃油港口成本，不参与自动分配，不能称为利润或无套利均衡。

## 9. 验证与结果纪律

完整原有回归继续保留，新增专项测试检查货批分割、最早到期顺序、逐船部分装载、跨船型等运量替代、船/桶守恒、冻结航程与装载报价、短期已承诺供给不重计、未来船不可提前装货、正常窗口锚、旧价格上限突破、有限欠运溢价、解释账本复算、存档恢复和同回合因果。

专项审计同时跑：

- 恒定货量，50%/70%/100%尾货阈值 × 有/无未来项；
- v2满载/当期/logistic，与v3满载/当期/指数、满载/未来/指数、部分装载/未来/指数分项比较；
- 5个Seed × 3种等/近等总载量船队 × 20次年度转移；
- 四产地Seed42、两产地Seed42 60次年度转移；
- 西非单独货量冲击及冲击前完全相同的对照。

首年预热只排除统计，不删除期间形成的欠运。指示价格P95、实际有装运窗口P95和按实际装货量加权基准分别发布。即使价格变平，仍必须报告无船回合、服务迟延、装载率及原始欠运；不以“曲线好看”替代物理与经济解释。

具体数值由 `STAGE6B_V3_VALIDATION.json` 和工作流附件提供；最终CI状态必须以最终提交为准。通过守恒和行为测试不等于完成真实市场弹性校准。

```python
from asset_simulation.model.shipping_v3 import run_seeded_market

```

外部策略：

```python
from asset_simulation.model.shipping_v3 import (
    make_market_spec, initial_market, prepare_turn, settle_turn,
    BatchOrder, Decision, LoadOrder,
)
spec = make_market_spec(origins=('gulf',))
state = initial_market(spec, {'vlcc':1}, initialization='cold')
snapshot = prepare_turn(state, spec,
    new_batches=[BatchOrder('order-001', 'gulf', 700_000, due_turn=3)])
state, result = settle_turn(snapshot, spec,
    Decision(snapshot.snapshot_id, loads=(LoadOrder(1, 700_000),)),
    include_events=True)
```
