# 当前 Viewer 与游戏界面

> 状态：当前实现事实  
> 权威范围：8783页面、数据投影、URL、交互和已知 UI 技术债  
> 代码基线：服务／Viewer v5.41  
> 最近核对：2026-08-25

## 1. 页面结构

服务提供两个页面：

| 页面 | URL | 作用 |
|---|---|---|
| 主 Viewer | `/?seed=42&years=60` | 浏览全球宏观和商品年度世界 |
| 游戏运转 | `/game?seed=42` | 按半月查看原油市场、投资决策竞技和报告 |

主界面的“游戏运转”按钮把当前 Seed 传给游戏页。游戏页返回主界面时也保留 Seed。

## 2. 主 Viewer

主 Viewer 请求 `GET /api/global`，响应包含全球42项年度快照、支持字段、下一年输入和商品 overlay。

顶层只有“宏观／商品”：

- 宏观展示全球增长、通胀、政策与曲线、资金信用、原油、企业盈利和资产复利参考；
- 商品保留一级种类和二级通用商品选择；
- 界面将 Brent 内部 owner 投影为“原油”，不并列 Brent／WTI；
- 目前只有原油有完整图表，其它商品可以选择但图表留空。

原油商品页有总览、年线、月线和周线。年／月／周 K 支持横向拖动、固定右侧价格轴、年份跳转和白色年份游标。它们是合成长期价格路径，不是交易所成交 K。

## 3. 游戏时间轴

游戏页把2025—2029显示为已完成观察期，从2030-01上半月开始，每月上／下半月各一个状态，到2085-12下半月结束。

- “推进半个月”结算一个回合；
- 未来跳转依次经过所有中间回合；
- 普通跳转拒绝过去；
- 重置需要二次确认；
- 当前回合按 Seed 保存到浏览器本地；
- 加载新 Seed 会读取该 Seed 自己的进度。

## 4. 游戏一级导航

时钟下方的“市场行情”和“投资决策”是同级入口。

### 市场行情

市场列表上方保留两级筛选，目前固定为：

- 种类：能源化工；
- 品种：原油。

行情表有6行：原油主连、现货参考和当前4个01／05／09月份合约。每一行都可进入自身周 K、月 K、年 K。

命名合约显示挂牌、到期、生命周期、价格、月内涨跌、高低点和状态。主连显示当前来源合约与比例复权；现货明确标为结算锚。

期货面板另显示：

- 期限结构状态、现货锚、主连映射和近端压力；
- 4个合约节点的曲线；
- 1000桶／手等标准规格；
- 单合约、总持仓、半月成交和到期收紧限额。

主连和命名合约 K 线下方显示成交量柱和周末持仓线；现货保持纯价格。上半月只公开 W1—W2，下半月补齐 W3—W4。

行情详情已经取消“预测配置／短期预测”按钮和预测 K。周 K、月 K、年 K 只画截至当前回合已实现的数据。预测仍在投资决策后台使用。

### 投资决策

投资决策页由三块组成：

1. 本局委员会席位：四家机构各自的预测、策略研究、公司风控和交易执行负责人；
2. 机构权益排名：权益、累计收益、最大回撤和总持仓；
3. 半月报告：市场变化、本回合盈亏、买卖手数、执行成本和风控状态。

历史报告下拉可以查看本进程已经重放的全部回合。当前任命只读，玩家不能点击更换人员或修改蛛网。

## 5. URL 与前端状态

游戏页主要 URL 参数：

| 参数 | 示例 | 作用 |
|---|---|---|
| `seed` | `42` | 世界与人员抽签 |
| `view` | `investment` | 打开投资决策一级入口 |
| `market` | `oil` | 打开原油详情 |
| `instrument` | `OIL-3005` | 选择行情对象 |
| `period` | `weekly` | 周／月／年 K |

前端每次刷新世界时并行请求期货和竞技接口，并检查 Seed 时间截点一致。竞技请求失败时不会静默使用旧排名。

## 6. 数据与文案边界

- 所有金额是全球美元账户；`global_dollar_index` 不显示为汇率或 DXY。
- 权益和主权债称“复利参考”，不是成交指数。
- 主连是不可交易展示指数，现货是结算参考。
- 期货保证金和限额已进入后台策略约束，但界面没有下单和现金冻结。
- 玩家／AI交易不写回公共行情。
- 预测能力总分不能解释为必然收益或排名。

## 7. 当前 UI 技术债

当前界面是开发工具级功能原型，短板需要明确记录：

- 视觉层级弱：委员会、排名和报告的主次不够清楚；
- 信息过密：表格同时展示过多指标，缺少渐进披露；
- 超宽屏利用差：内容受固定宽度约束，右侧容易出现大面积空白；
- 窄屏虽然有响应式规则，但委员会和报告仍偏拥挤；
- 缺少决策原因、仓位变化、主要盈亏来源等解释层；
- 推进和长距离重放缺少明确加载进度；
- 没有正式空状态、错误恢复、键盘工作流和可访问性专项验收；
- 主 Viewer 与游戏页的视觉系统仍不完全统一。

下一轮不应只做颜色和装饰。应先重构信息架构：机构总览 → 本回合变化 → 决策理由 → 风险／执行归因 → 历史比较，然后再确定正式视觉语言。

## 8. 验收基线

当前静态契约保护：

- 主／游戏入口与关键 DOM id；
- 行情详情不存在短期预测入口；
- 投资决策同级导航和竞技接口；
- 半月推进、禁止倒流和本地进度；
- K 线周期、成交量、持仓量和限额字段。

2026-08-25 已在真实浏览器验证 Seed 42 的四家任命、首回合排名和报告，并检查命名合约详情只有周／月／年 K，控制台无 error。该验收不等于 UI 已达到产品完成标准。
