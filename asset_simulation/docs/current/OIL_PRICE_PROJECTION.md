# 原油价格年度锚与月度路径

> 状态：已实现
> 模型：`asset-simulation-monthly-oil-price-v0.1.0`
> 最近核对：2026-09-01

年度原油收盘价仍由全球宏观中的 `oil_commodity.py` 唯一决定。`oil_price_projection.py` 读取相邻年度锚、年度原油波动状态和价格包络，在每年内部生成12根连续月度 OHLC。

核心约束：

- 每年1月开盘等于上一年度收盘；
- 每年12月收盘严格等于当年宏观年度锚；
- 月与月之间前收盘等于后开盘；
- 月度最高／最低完整覆盖年度包络；
- 同 Seed 确定性且长短窗口前缀一致；
- 月度路径只用于观察，不回写宏观、物理油池或航运需求。

因此首页中的“月线”是原油价格的年内展开，不是现货交易撮合、期货合约或新的价格发现层。
