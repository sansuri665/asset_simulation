对应分支 `stage6b-v3-transparent-market`，父版本 `6f6aaa24e44784ff3eb0538e488636cff5f7d88b`。本表已纳入最终的开盘时点归一化修正：海湾正常已承诺曲线为[1.06,1,0]，西非为[1.06,1,1]。之前开发过程使用统一1.71除数的数值不作为最终结果。

## 1. 验证范围

本地Python3.13完整270项回归通过，其中新增48项v3专项测试；Viewer27项断言通过。25项专项审计门槛全部通过。

本地实际运行0、1、5、7、42五个Seed，每个Seed使用300VLCC、240VLCC+120Suezmax、225VLCC+120Suezmax+50Aframax三组等/近等标准载量船队，各20次年度转移。另测四产地Seed42及两产地60次年度转移、所有恒定控制和单独西非冲击。

最终远端CI分别执行Python3.11/3.13完整回归；3.11重新运行Seed42三组船队、四产地、60次年度转移、全部隔离控制，并执行原有8Seed/60次转移需求审计及Stage6A审计。最终CI是否完成以该提交Actions为准，不能把本地五Seed结果冒充远端五Seed结果。

## 2. 恒定货量对照

所有组均为240VLCC+120Suezmax，完整货量海湾9.3 mb/d、西非1.2 mb/d，216个10日回合、首36回合预热。CV=标准差/均值。

| 模式 | 海湾CV | 西非CV |
|---|---:|---:|
| v2，满载、当前在港、旧logistic | 1.03% | 4.15% |
| v3，满载、当前在港 | 0.86% | 3.54% |
| v3，满载、已承诺到船 | 0.38% | 2.27% |
| v3，尾货最低70%、当前在港 | 0.73% | 1.86% |
| v3，尾货最低70%、已承诺到船（默认） | 0.19% | 0.42% |
| v3，尾货最低50%、已承诺到船 | 0.10% | 0.31% |

默认组海湾最低/中位/最高为20,838 / 20,867 / 20,945；西非19,084 / 19,257 / 19,286，单位为2025美元/标准VLCC日。

改善有两个来源：部分装载减少尾货取整，已承诺船位让报价读取确定的近期容量，而非仅看当前一批船。不是把所有经济波动都压平。50%阈值仅在这组控制中更平稳，不代表任何Seed或经济条件下最优。

未来到船引入后中位价格也会变化：常态锚保持35,000，但当前闲船与未来流入在归一化窗口中表达的松紧程度不同。不能声称这项改动只降低方差而完全不影响价格水平。

## 4. 分项对照，不混淆上限与未来供给

| 模式 | 海湾中位数/P95 | 西非中位数/P95（含无船报价） |
|---|---:|---:|
| v2 满载、当前、logistic | 24,764 / 65,829 | 21,760 / 99,565 |
| v3 满载、当前、指数 | 24,935 / 74,090 | 22,223 / 174,037 |
| v3 满载、已承诺到船、指数 | 27,769 / 62,077 | 26,046 / 112,224 |
| v3 尾货70%、已承诺到船、指数 | 27,720 / 62,818 | 26,670 / 120,859 |

只改变报价窗口不会改变物理发船序列，已独立验证；允许部分装载以后才允许物理路径改变。去掉旧logistic整体上限本身就会扩大尾部，不把这一变化全部算给满载或预期。

## 5. 真实冲击仍有响应

恒定货量中仅将西非第80—91回合的新工作量翻倍，固定船队不变。观察80—139回合，海湾峰值由20,945升至153,528，西非由19,286升至199,620。冲击前80回合完全一致，承诺循环运力也真实发生重新分配。

报价中有共同信号，不能仅凭价格同步上涨就说全部涨幅都来自物理转场。直接物理证据是船位和承诺容量变化。15万/20万表示组件不再被旧12.25万总价上限锁死，不代表这些幅度已经符合现实。

## 6. 四产地与长窗

四产地Seed42使用350VLCC+180Suezmax+20Aframax；同一实现、同一东亚目的地、完整所选航线货量。海湾/西非/巴西圭亚那/美湾中位基准约22,342 / 20,417 / 19,323 / 18,845，均没有当前无船回合或数值保护命中。这里只服务所选四条航线，不能推导全球只需这些船。

两产地60次年度转移，首年后2160回合全部船号、实际桶数、货批舱单和参考计划守恒，报价解释重算最大误差为0。保留早期西非33个无船回合，不靠重置历史改善长窗结果。

## 7. 替代边界

v3具备继续开发所需接口：逐船实际装载、货批年龄和日期、真实已承诺短期运力、外部决策、解释报价与恢复。只有最终分支验证通过且旧v2仍停在预期祖先提交时，才退役旧分支引用；main不动。

未完成的仍包括真实货主出价与船东套利、成本/利润、独立船型机会溢价、完整全球多目的地、动态拥堵/改道、港口吃水、部分装载的最优经济选择、负TCE和现实弹性校准。价格更平滑不等于均衡已求出。所有默认装运、调船、未来权重与压力参数仍可替换、可审计。
