# Stage6B-v3：实际验证结果与适用边界

本说明对应 `stage6b-v3-transparent-market` 的v3实现，父版本为 `6f6aaa24e44784ff3eb0538e488636cff5f7d88b`。详细设计见 `STAGE6B_V3_TRANSPARENT_MARKET.md`，机器可读摘要见 `STAGE6B_V3_VALIDATION.json`，完整扫参与逐回合结果由CI附件提供。

本地Python3.13执行268项完整回归（新增46项v3测试）和27项Viewer断言通过。专项审计25个门槛全部通过。远端最终提交的Python3.11/3.13回归、完整v3审计和继承审计仍必须以该提交的Actions状态为准，不能用本地结果冒充远端完成。

## 1. 测试不只要求价格平滑

本轮覆盖：逐船部分装载与满船体占用、批次拆分/合并/最早到期顺序、实际舱单和真实交付、计划到期日与船型独立、冻结装载报价、无效方案原子拒绝、检查点恢复完全一致、未来船号不重复、不预测未承诺空船、未来船不能提前装货、正常到船时间表保持报价锚、独立有限欠运溢价、局部偏离有界且加权和为0、报价解释重算，以及时间机会比较不重复计算标准返程。

研究范围仍是具名产地到同一目的地，不是完整全球航运。固定10日回合与360日运营年不变，完整航线货量只输入一次，不按船型份额切割，不修改原油世界。

## 2. 恒定需求：分离满载限制与到船信息的作用

所有组使用相同240艘VLCC、120艘Suezmax，海湾9.3 mb/d、西非1.2 mb/d日货量恒定，运行216个10日回合、首36回合预热。CV是标准差/均值。

| 装载测试规则 | 报价运力窗口 | 海湾CV | 西非CV |
|---|---|---:|---:|
| v2，仅满载 | 当前在港、旧logistic | 1.03% | 4.15% |
| v3，仅满载 | 当前在港、指数价格 | 0.86% | 3.54% |
| v3，仅满载 | 当前及已承诺未来到港 | 0.36% | 1.98% |
| v3，尾货最低70% | 当前在港 | 0.73% | 1.86% |
| v3，尾货最低70%（默认） | 当前及已承诺未来到港 | 0.21% | 0.48% |
| v3，尾货最低50% | 当前及已承诺未来到港 | 0.10% | 0.36% |

默认组海湾报价范围26,534—26,679、中位数26,570；西非21,379—21,666、中位数21,566，均为2025美元/标准VLCC日。

这些不是“所有经济波动都应该消失”的验收条件，只检验恒定工作下不必要的批次振荡。50%阈值在这一组更平滑，不代表任何真实Seed、船队或经济条件下都更优。部分装载消耗完整船舶航程，可能降低后续有效运力。

未来到船纳入后，中位价格也改变：常态锚仍保持35,000，但当前闲船堆积与未来流入放在归一化窗口后，对宽松/紧张的解释不同。不能说新增未来信息只降低方差、完全不影响价格水平；权重与归一化依然是需要校准的规则。

## 3. 真实Seed42：默认混合船队

运行2025—2045，首年预热，只统计2026—2045的720回合/7200运营日。两条线路完整日货量均值分别9.4561、1.3645 mb/d；相同240VLCC+120Suezmax，不新增船。

| 指标 | 海湾→东亚 | 西非→东亚 |
|---|---:|---:|
| 指示TCE中位数 | 35,287 | 30,095 |
| 所有指示报价P95 | 79,035 | 147,712 |
| 有实际装运回合的报价P95 | 79,035 | 79,598 |
| 全部指示报价最高值 | 116,339 | 265,345 |
| 按实际装货量加权的基准均值 | 41,706 | 32,828 |
| 没有当前可用运力的回合 | 0 | 33 |
| 数值价格保护命中回合 | 0 | 0 |
| 最大未装计划量/窗口平均日量 | 14.15日 | 34.07日 |
| 最老未装批次的最大年龄 | 1回合 | 3回合 |
| 期末未装货量 | 265,026桶 | 40,689桶 |
| 部分装载船次 | 178 | 186 |
| 发出船舶的容量加权装载率 | 99.956% | 99.713% |

所有金额为2025年购买力的标准VLCC等效指示值，不是每种小船相同的日收入，也不是成交发票或利润。“有装运回合的报价”仍然是该时点基准，尚未模拟谈判成交价。

最重要的负面结果：西非依然有33个无船回合，与旧版默认对照相同。因此不能把本轮视为已经解决了调船缺口。西非所有报价P95很高，但剔除无装运回合后约7.96万美元；不能将无船时的高报价当成船东实际赚到了26万美元/日。

旧版满载同口径最大欠运为海湾14.26日、西非33.47日；新版约14.15/34.07日。部分装载并没有全面降低最大欠运，西非甚至略增。期末余货、全路径最大欠运与船舶装载效率必须分别看。

新增批次年龄让“欠了多少天正常流量”与“真正最老的货等了多久”不再混淆。1回合仍代表10运营日，不是连续日级精细测量。

## 4. 分项对照：不能把去掉总价上限的作用算给预期

相同完整Seed42货量、船队与原物理参数：

| 模式 | 海湾中位数/P95 | 西非中位数/P95（含无船报价） |
|---|---:|---:|
| v2 满载、只看当前、logistic | 24,764 / 65,829 | 21,760 / 99,565 |
| v3 满载、只看当前、指数 | 24,935 / 74,090 | 22,223 / 174,037 |
| v3 满载、已承诺到船、指数 | 35,300 / 78,094 | 29,378 / 133,085 |
| v3 尾货70%、已承诺到船、指数 | 35,287 / 79,035 | 30,095 / 147,712 |

只改报价窗口不能改变物理装运序列，这一项有独立哈希与回归测试。允许部分装载以后物理路径才允许改变。新指数价格突破旧12.25万是接口能力，不代表新的26.5万峰值已经实证校准。

## 5. 真正冲击仍然存在

恒定货量世界中只将西非第80—91回合新货量翻倍，船队不变。观察第80—139回合，海湾最高指示报价由26,679升至191,545，西非由21,666升至241,436。冲击前80回合历史完全一致。两地承诺的循环运输能力也实际重新分配。

该实验含共同报价信号，不能仅用价格共同上涨就断言所有涨幅都由实际转场引起。物理证据是承诺容量与真实船位变动；价格幅度只是规则压力测试。没有利用需求销毁或新增船把账做平。

## 6. 多Seed、四产地与长期窗口

0、1、5、7、42五个Seed，各使用300VLCC、240VLCC+120Suezmax、225VLCC+120Suezmax+50Aframax三组等/近等总标准载量，均运行20次年度转移。另运行四产地Seed42（350VLCC+180Suezmax+20Aframax）及默认两产地60次年度转移。

四产地组统计窗口中，海湾/西非/巴西圭亚那/美湾报价中位数约27,974 / 22,057 / 21,171 / 21,075，均无当前无船回合、未触发宽数值保护。这个较大船队只服务所选四条到东亚的完整货量，不是全球总需求的船数估计，不能与两产地默认船队直接比较优劣。

两产地长窗首年后2160回合全部船号、实际桶数、批次舱单与参考计划守恒，报价解释最大重算误差为0。长窗依然保留早期的33个西非无船回合，没有重置历史欠运来改善统计。

## 7. 可以替代什么，尚不能证明什么

v3可替代v2作为继续开发的接口：逐船实际载量、批次年龄、已承诺短期供给、外部策略、解释报价和状态恢复都已具备。旧v2代码仍在祖先和文件中可复跑；只在新分支最终验证成功且旧分支没有推进时退役旧引用，不改main。

尚未完成：真实货主出价/船东套利、成本/利润、独立船型机会溢价、全世界多目的地、动态拥堵/改道、港口吃水限制、非满载的最优经济选择、负TCE及现实价格弹性校准。默认装运与调船都是可替换测试策略，曲线平滑不等于均衡已经实现。
