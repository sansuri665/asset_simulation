# Stage6B：多产地—单目的地VLCC物理市场

分支 `stage6b-multi-origin-east-asia-market`，直接继承Stage6A `c8c8f0ade48ebfb8cf2ff32407a1c1693a44d31b`。不改main，不删除Stage5A/6A，也不合并旧成本、垄断或全球船池实验。

## 1. 本轮做成了什么

默认市场是“海湾、西非→东亚”，同一组265艘固定编号VLCC共享东亚卸货后的空船池。265只是实验入口，不是全球真实船数，也不是用来覆盖所有原油流量的船队。相同实现可直接配置三个或四个具名产地。本轮另测了海湾、西非、巴西/圭亚那、美湾四产地到东亚，不复制四套独立船队。

```
现有Seed月度航线日货量
 → Stage6A船型份额，只取本子市场VLCC份额
 → 每回合10运营日的整数桶计划
 → 各产地实际在港可用船
 → 通用单航线报价公式
 → 本地整船装运
 → 冻结的载货航程/卸货计划
 → 同一个东亚空船池
 → 一次性分配给某个产地的压载计划
 → 下一轮各产地的即时船位
```

不是完整全球市场，不模拟燃油、港口费、OPEX、公司、债务、订单、拆船、货主议价、油种替代或长期需求破坏。没有新增全球TCE乘数，避免把同一船队短缺重复计价。

## 2. 三个独立职责

- `multi_origin_market.py`：NetworkSpec / Ship / LaneLedger / NetworkState；固定船号、真实桶数、调度顺序与转场。
- `multi_origin_pricing.py`：通用指示性TCE函数。仅消费本产地即时供给、当期需求、有限压力，不产生船、不结算利润。
- Stage6A的 `MovementPlan`：继续拥有航程、船型路径、货盘与时点。新层复用它，不把西非强行写成海湾的五回合循环。

已有 `single_route_pricing.py`、`bounded_route_pricing.py`、`single_route_fleet.py`、`single_route_market.py` 和Stage6A实现均未改动。

## 3. 货量、船型和时间口径

海湾→东亚使用Stage6A的90% VLCC份额，西非→东亚使用80%；这些比例仍是低置信度设计先验，不是重新研究的现实统计。非VLCC货量明确排除，不会悄悄塞给这支船队。

| 服务 | 参考VLCC日量 | 每票桶数 | 载货/卸货/返原产地回合 | 参考循环占用 |
|---|---:|---:|---|---:|
| 海湾→东亚 | 8.37 mb/d | 1,971,000 | 2+1+2 | 约212.33艘 |
| 西非→东亚 | 0.96 mb/d | 1,898,000 | 3+1+3 | 约35.41艘 |

同一艘VLCC换航线后，下一票可使用另一规格的标准货盘；已经装船的桶数绝不随下一条航线改变。船型载量不是统一用“船数×1.971百万桶”估算。

一运营回合10天，标签月30天、标签年360天。保持源月的日货量，不强求自然日年度总量相同。自然日参考量、运营量和差额单独报告；CPI使用当前标签年之前已完成年度值，初始年用初始条件。

这版执行固定Stage6A目录路径；上游动态effective haul只保留为诊断，没有把混合统计航程再乘到每条在途船上。动态改道、港口拥堵和不同航速留作以后专门的事件接口。

## 4. 同一个目的地，不复制库存

每个产地仍有独立的运输计划账本，以保留货物来源与不同的参考交货滞后：

```
G_r = 累计新计划 − 累计实际装船
E_r = 累计实际交货 − 累计参考交货
W_r = 实际在途 − 参考在途
G_r + W_r + E_r = 0
```

东亚只公布一个合计：`E_destination = sum(E_r)`。这里E_r是合计的来源贡献，不是两份可以分别消耗的东亚岸罐。

真实交付必须来自本回合实际完成卸货的船号；参考交货只用于计划偏离，不生成油。初始在途货单独登记，并配同样的初始参考交货，因此没有空管线制造的假短缺。

物理账用整数桶，所有残差必须严格等于0；原始欠运不截断、不取消、不遗忘。当前执行层不借用未建模的岸罐，所以源端G非负，目的地/在途偏离仍可正可负。

## 5. 目的地压力只计算一次

沿用有界短记忆的思想，但将来源压力和共享目的地压力分开：

```
目的地开盘压力 = bounded(上期目的地压力 + (合计参考到货 − 合计实际到货)/合计参考日量)
航线报价压力_r = (产地压力_r + 共享目的地压力)/2
产地收盘压力_r = bounded(衰减×上期产地压力_r + (本回合新计划_r − 实际装货_r)/本产地参考日量_r)
目的地收盘压力 = 衰减×目的地开盘压力
```

压力各限制在±5日，半衰期3回合，并保持与真实偏离的方向一致。共同目的地缺口按本子市场的合计日流量归一化，不能将合计缺口除以每条小航线的日流量再分别放大。

这个东亚信号只代表所选VLCC子市场的交付计划，不代表全东亚所有原油来源、其他船型和炼厂绝对库存。两条航线都受到同一个信号影响，并不意味着货量被算了两次。

## 6. 单航线报价如何通用化

保留原Stage5A的基本公式、3.0船货比敏感度、0.03紧迫度系数、0.25价格惯性与锚定logistic软边界。路线参考日量、货盘和正常prompt窗口由本航线自己提供；流动性平滑项随参考货盘数同比例缩放，不把海湾“4艘平滑”原样塞给只有约5票/回合的西非。

将原海湾的参数与输入传给新函数，28组供给/压力组合的报价与Stage5A对应值一致到2美分以内。它是公式的参数化推广，不是为了扩展航线另外编一套价格曲线。

共同的12.25万美元实际TCE软上限仍保留，**本轮没有解决以后完整全球定价的绝对上限问题**。它是实验护栏，不是货主现实支付上限，不是成本线。库存附加溢价有界、全市场价格中枢与终值保护，后续仍须分别标定。

报价一律不是谈判成交、发票或现金。零供给可以给高指示价格，但执行量为0且执行基准价为空；无新计划只沿用上一指示价，旧货仍可继续运输。输出同时给全部指示报价分布与有整船执行时的基准价分布，不能将无船时报出的尖峰说成实际收入。

## 7. 一批空船只能分配一次

顺序固定：

1. 完成到期航行/卸货，交付货物，更新各节点真正开放的船号。
2. 仅将各出口节点的开放船公布为本地prompt供给。东亚空船和在途压载船一律不加入。
3. 给各航线报价，受真实货物和本地船数限制执行整船装运。
4. 将东亚空船逐艘分配给目标产地；已经派去某地的压载船立即占用该目标的未来承诺数。
5. 只有在没有待运整票货、保留下一窗口覆盖、且另一个产地真有目标缺口时，才允许出口区间空船转场。

转场一经发出不能中途改目标。已载货船也不能被抽走。回合内同一船不能既载货又压载出发。东亚卸货完成后可立刻开始压载，不另加一回合“空船卸货”。

## 8. 当前分船规则是明确的实验规则

调船使用当前/历史货量的指数平滑，估算“参考循环占用+有限补运+少量备用船”，与已承诺到该产地的全部船比较。船舶目标占用与实际即时供给是两个概念，报价只使用后者。

当前报价给这个覆盖缺口排名一个很小的有界倾向，权重0.01；它不是完整的船东收益优化。最初试了0.05，恒定小货量下的追价摆动较大，因此没有采用。没有调整核心TCE弹性来凑某个结果。

目标覆盖全满但仍有当前运输工作时，东亚空船仍分配到相对宽松程度最低的出口节点，不藏在一个永远不参与报价的“免费全球备用池”里。供给过剩必须最终表现为真实在港闲船。

另提供 `home_return` 对照：每艘船固定回初始所属产地，不能跨产地借船。它只用于比较共享船池与独立船队，不是正式推荐策略。

## 9. 实际效果：物理传导对照

265艘、恒定参考日量，只有西非在第80—91回合增加50%货量，海湾新计划完全不变。观察第80—129回合：

| 航线 | 无冲击窗口最高指示TCE | 有冲击最高指示TCE | 相对对照的船舶承诺变化 |
|---|---:|---:|---|
| 海湾→东亚 | 19,229 | 51,460 | 最多减少20艘 |
| 西非→东亚 | 16,298 | 91,174 | 最多增加20艘 |

这里的20艘是该路线服务中/已承诺的船，**不是同一回合立刻出现20艘prompt**。

更严格的隔离实验关闭共享/本地压力报价项和报价对调船的倾向，只留实际船队约束。海湾窗口高点仍从18,747变为48,571。再关闭跨产地调船，海湾冲击与对照每回合报价完全一致。这证明传导不是靠额外的“全球运价系数”伪造。

## 10. 实际Seed42，265艘两产地共享船队

2025年预热，统计2026—2045：720回合、7200运营日。使用实际上游月度需求乘Stage6A份额，不是人工替换的正弦需求。

| 航线 | VLCC日量均值mb/d | TCE中位数 | P95 | 最高指示TCE | 最大未装计划天数 |
|---|---:|---:|---:|---:|---:|
| 海湾→东亚 | 8.511 | 29,826 | 57,757 | 68,433 | 25.33 |
| 西非→东亚 | 1.092 | 16,778 | 90,061 | 122,452 | 29.45 |

单位是2025实际美元/日；未装计划天数用本航线窗口平均日量换算，不是炼厂可用库存。

同样265艘，固定返原产地的对照把228艘留给海湾、37艘留给西非。西非期末欠运约6.493亿桶，最大欠运约594.8天；共享船池期末只剩185,605桶、不足一票。海湾也不是无成本地得到好处：其平均承诺船数从228降为约222.46，报价中位数由23,768升为29,826。

## 11. 四产地扩展与剩余局限

相同引擎也跑了四产地→东亚的Seed42，340/360/380艘三组。380艘时海湾、西非、巴西/圭亚那、美湾的TCE中位数约18,316、10,188、8,122、4,812；最大欠运分别约0.23、1.74、1.76、4.95天。360艘组在高需求阶段积累更多欠运，小航线也频繁出现极端指示报价。

这不是“全球船队只需要380艘”。这里只分配四条亚洲向航线的VLCC部分，其余路线、其他船型和集合地理仍在范围外。

恒定整票工作（海湾42票、西非5票/回合）在250艘对照中，预热后两条报价严格平稳。恒定日流量但货盘有小数余量时，265艘的海湾报价CV约3.27%、西非约34.61%。后者体现小市场整船离散、批次和调船规则的放大，**不能当作已校准的真实市场波动**。它被审计明确列为warning，不能被“守恒测试通过”掩盖。

默认265艘的真实Seed42中，西非有2回合无即时供给、11回合接近价格上边界；所以最高指示值尤其不能直接解释成真实成交高点。后续在扩成全世界前，仍须改进小市场报价窗口、调船策略和全局/局部定价尺度的校准。本轮没有回滚到混杂成本的旧模型来隐藏这些问题。
