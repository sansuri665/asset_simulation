# 海湾→东亚单一船东运营原型

> 分支：`gulf-east-asia-monopoly-operations-prototype`  
> 模型：`asset-simulation-gulf-east-asia-monopoly-operations-v0.1.0`  
> 状态：实验；不进入 `main`

## 一、范围

这一版退回到一条航线，只模拟：

```text
Seed生成的海湾→东亚结构货量
        ↓
一家船东拥有全部固定VLCC
        ↓
船东选择本回合实际派出多少船
        ↓
未派出的船停在海湾港口/锚地
        ↓
派出的船执行五回合完整循环
        ↓
毛运费－航次成本－全部船舶OPEX
        ↓
单一船东运营现金结果
```

明确不模拟：

- 折旧；
- 船价与资产重估；
- 债务、本金和利息；
- 公司税与资本结构；
- 新船订单和交付；
- 拆船、买船、卖船；
- 期租与多家公司竞争。

因此这不是公司金融模型，而是固定资产规模下的运营状态实验。

## 二、固定船队与五回合状态机

船东固定拥有280艘编号VLCC：

```text
VLCC-0001 ... VLCC-0280
```

参考贸易在9.3 mb/d附近需要约239艘持续运力。开局将191艘放入四个已有航次队列，在海湾留下89艘prompt船；正常首回合派出约48艘后，约有41艘成为正常运营和垄断控制缓冲。

最初试验曾只设250艘。该规模的极限持续吞吐只有约9.7 mb/d，而seed42会在较长时期超过该水平，导致模型退化为物理缺船和库存长期积压。固定船队最终校准为280艘：不依赖新增船也能覆盖已测试Seed的大部分峰值，同时在高需求阶段仍会接近满负荷。

每一艘派出的船自动完成五个shipping turns：

| 航次年龄 | 状态 |
|---:|---|
| 0 | 装货半回合 + 前半段重载航行 |
| 1 | 重载航行 |
| 2 | 后半段重载航行 + 卸货半回合 |
| 3 | 第一段压载返程 |
| 4 | 第二段压载返程 |
| 5 | 回到海湾，重新成为可调度船 |

进入航次后不能中途撤回。没有派出的船留在海湾，继续支付常规OPEX和待港燃油。

每回合严格检查：

```text
active voyage ships + Gulf idle ships = 280
```

同一编号不能重复出现、消失或凭空生成。

## 三、货物与虚拟仓库

货量直接读取现有`oil_shipping_world`在该Seed下真实生成的：

```text
gulf_east_asia.cargo_mbd
```

每月拆成3个约10日的shipping turns。每票标准货物为：

```text
270,000 tonnes
≈ 1.971 million barrels
```

虚拟仓库继续使用相对正常管线的偏离：

```text
Gulf deviation
in-transit deviation
East Asia deviation
```

并严格满足：

```text
Gulf + transit + East Asia = 0
```

实际装船少于结构流量时，海湾相对积压；少装的影响经过运输时滞后表现为东亚相对见底。库存是偏离值，不是区域绝对库存。

## 四、收入、航次成本与TCE

每一票成交后，船东获得毛运费：

```text
Gross Freight Revenue
```

市场状态先形成实际TCE，再根据完整航次成本反推出毛运费：

```text
Gross Freight
= [TCE × Cycle Days
   + Bunker
   + Port
   + Other Voyage Cost]
  / (1 - Commission Rate)
```

因此恒等式为：

```text
Gross Freight
- Commission
- Bunker
- Port
- Other Voyage Cost
= Net Voyage Revenue
= TCE × Cycle Days
```

TCE已经扣除与该航次直接相关的燃油、港口、佣金和其他航次费用，但尚未扣除船舶常规OPEX，所以TCE不是船东最终利润。

当前采用的可配置VLCC代表值：

| 项目 | 原型值 |
|---|---:|
| 重载燃耗 | 57.3 t/day |
| 压载燃耗 | 39.5 t/day |
| 装货港燃油 | 20 t |
| 卸货港燃油 | 110 t |
| 等待燃油 | 10 t |
| 海湾装货港费用 | 125,000美元（2025实际） |
| 东亚卸货港费用 | 175,000美元（2025实际） |
| 其他航次费用 | 25,000美元（2025实际） |
| 总佣金 | 3.75% |

燃油价格不直接等同Brent。原型建立独立marine-bunker proxy：

```text
real bunker price
= 550 USD/t
× [25% + 75% × real oil price index / 100]
```

实际燃油价限制在250–1,200美元/吨的2025购买力范围，随后由CPI转为当期名义价格。以后可由独立船燃价格模块替换。

## 五、不开船也要承担的成本

全部280艘船每天都承担：

```text
Vessel OPEX = 9,500 USD/day，2025购买力
```

它代表船员、保险、日常维修、备件、物料、润滑油和管理等船舶存在成本。

船停在海湾时，还承担：

```text
Idle fuel = 4 tonnes/day
```

因此停船不是零成本。折旧、债务和利息明确排除在本模型之外。

每个航次的毛运费和佣金在五个回合中平均确认；燃油和港口费用按对应航次阶段确认。每回合运营结果为：

```text
Accrued Gross Freight Revenue
- Accrued Commission
- Accrued Sailing/Port Bunker
- Accrued Port and Other Voyage Cost
- Gulf Idle Bunker
- OPEX on all 280 vessels
= Operating Cash Result
```

这是便于比较的运营应计口径，不模拟真实发票和付款日期。

## 六、垄断运力控制

这一版不模拟owner/charterer逐票竞价，也不使用自由市场撮合。

每个回合，模型对可派出的不同船数逐一计算反向TCE需求曲线：

```text
ln(TCE / baseline TCE)
= prompt shortage effect
+ virtual inventory pressure
+ structural demand level effect
```

船东选择使下式最大的派船数：

```text
contracted net voyage revenue
- Gulf idle bunker
- inventory/service shadow cost
```

常规OPEX没有写进当期派船目标，因为固定拥有280艘时，无论某一条prompt船本回合开不开，全部船舶OPEX都必须支付；它会进入公司运营现金结果，但在“本回合多派一艘还是少派一艘”的边际比较中属于共同项。

库存影子成本表示长期客户关系、储罐约束、炼厂连续性、合同或政府干预风险。它只约束自动策略，不是已发生的会计费用。

默认自动策略单回合最多主动扣留15艘prompt船。实验控制还可以使用：

```text
dispatch_override_vlcc = 0 ... available
additional_withholding_vlcc = 0 ... policy dispatch
```

因此既可以测试正常垄断策略，也可以测试完全停航和额外压船。

## 九、自动垄断策略与全部派船对照

在同一条seed42需求路径上：

| 指标 | 自动垄断策略 | 全部满足可运需求 |
|---|---:|---:|
| 平均派船/turn | 48.602 | 48.609 |
| 平均闲置船 | 36.93 | 36.90 |
| 库存偏离P95 | 1.507天 | 0.084天 |
| 实际TCE中位数 | 42,129 | 35,162 |
| 实际TCE P95 | 44,320 | 36,428 |
| 实际TCE最大值 | 45,933 | 37,271 |
| 20年累计实际运营现金结果 | 57.710十亿美元 | 44.630十亿美元 |

自动策略长期运输总量几乎没有减少；它主要维持约1.5天的可控库存错配，并把少量货盘从当前回合推迟到后续回合。相对于每回合尽量全部派船，模型内的累计运营现金结果增加约13.080十亿美元，即约29.3%。

该结果不应直接解释成现实垄断利润估计。它主要证明：在当前反向需求曲线下，固定船东通过微调装船时点可以形成运力稀缺溢价。溢价幅度仍需用现实运价弹性、长期合同、客户流失和监管约束校准。

## 十、连续三个回合完全停航

将seed42第37–39个shipping turns强制设为零派船：

| 指标 | 正常自动策略 | 三回合完全停航 |
|---|---:|---:|
| 库存偏离最大值 | 1.610天 | 29.342天 |
| 实际TCE最大值 | 45,933 | 122,500（触及护栏） |
| 物理缺船合计 | 4 | 25 |
| 20年累计实际运营现金结果 | 57.710十亿美元 | 60.918十亿美元 |

压力测试中，账面运营现金结果反而更高，是因为当前模型尚未把以下后果记为真实现金损失：

- 货主改用其他来源或运输方式；
- 长期客户流失；
- 合同违约与赔偿；
- 政府或监管干预；
- 炼厂减产和需求永久消失；
- 极端报价下货量需求弹性增大。

因此“三回合完全停航”只能用于验证库存和运价冲击传播，不能视为可持续最优策略。自动策略之所以不会主动这样做，是因为库存/服务影子成本会阻止极端停航。

## 十一、当前局限

1. 所有派出的船都自动压载返回海湾；尚不能在东亚卸货后长期停留。
2. 航速固定，不做slow steaming或抢速。
3. 港口拥堵、天气、故障和坞修尚未进入。
4. 船东只使用当期信息做近视优化，没有求解多年动态规划。
5. 库存影子成本是行为参数，不是已校准的现实合同罚金。
6. TCE仍有1,000–122,500美元/日的2025实际价格护栏。
7. 当前只有一家船东和一条航线，不代表现实市场结构。
8. 财务结果不含折旧、债务、利息、税、资本开支和船舶残值。

## 十二、结论

这一版已经完成用户要求的最小运营闭环：

```text
固定船队
+ 可闲置船舶
+ 五回合物理占用
+ Seed实际航线货量
+ 正负虚拟库存
+ 垄断派船控制
+ 毛运费
+ 航次燃油/港口/佣金
+ 全船队OPEX
= 单航线运营现金状态
```

下一阶段如继续深化，最优先的不是加入债务或船价，而是校准垄断反向需求曲线，并补上长期合同、货量流失和监管/服务约束，避免极端停航成为账面现金流套利。
