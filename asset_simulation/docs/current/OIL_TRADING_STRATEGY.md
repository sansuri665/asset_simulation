# 原油投资策略部与基础交易策略

> 状态：策略研究、跨回合观点失效、策略／公司两层风控、投委会系统代理、交易部、收益归因和逐回合结算已接入四机构竞技；玩家自主审批、正式存档和可选信号引擎尚未实现  
> 权威范围：策略研究八维偏好、观点失效、风控建议与资金授权、单合约延续／回归信号、连续换手、换月、全成本执行、收益归因与逐回合盯市  
> 代码基线：策略研究 `asset-simulation-oil-strategy-research-v0.2.1`、策略风控 `asset-simulation-oil-strategy-risk-v0.1.0`、公司风控 `asset-simulation-corporate-risk-control-v0.2.0`、交易部 `asset-simulation-oil-execution-desk-v0.2.0`、交易策略 `asset-simulation-oil-trading-strategy-v1.3.0`
> 最近核对：2026-08-29

## 产品位置

当前策略位于只读期货市场和短期研究预测之后，是四机构竞技共同使用的可复算交易闭环：

```text
当前可见 oil_futures_overlay_v8
+ 当前已发布双合约预测 vintage
+ 当前账户仓位与权益
→ 任命的策略研究负责人及其只读八维偏好
→ 预测中枢回归 + 可见8周趋势／预测路径延续
→ 投委会资金授权 × 负责人资金部署倾向
→ 命名合约理想净持仓
→ 上一份预测的已实现偏差触发观点观察／失效缩放
→ 单策略风险授权裁剪
→ 公司组合总风控裁剪
→ 可见信息估算的净优势与往返预算使用率
→ 下一半月两个周执行窗口的净调仓与往返交易
→ 限价穿透决定实际入场与目标退出数量
→ 动态价差、参与率滑点、手续费／返还
→ 回合末净成本盯市、保证金摘要与交易报告
```

策略决策函数 `build_oil_strategy_decision` 没有 `GlobalMacroRun` 参数，只接收当前市场、当前预测、仓位和权益，因此无法读取隐藏真实周线或构造未来市场。`settle_oil_strategy_turn` 必须推进到紧邻的下一半月，才可使用该窗口新实现的两根周 K 结算。`simulate_oil_trading_strategy` 负责按此顺序逐回合重放。

它不写回期货价格、成交量、市场持仓量、预测或全球宏观。主连仍不可交易，仓位只落在 `OIL-YYMM` 命名合约。

## 部门边界与当前代理

运行边界按通用机构职能拆成六个节点：预测研究发布报告；策略研究形成理想目标；风控部进行单策略审阅；投资决策批准风险并分配资金；公司风控执行汇总上限；交易部执行。当前投资决策仍由系统代理：

| 层级 | 当前 owner | 状态 |
|---|---|---|
| 预测研究 | `oil_short_term_forecast` | 已有短期双合约预测、六维能力和评分 |
| 投资策略部 | `oil_strategy_research`（兼容 owner 名） | 已有可任命 PM／Strategy Director、八维只读偏好和参数映射 |
| 策略风控 | `oil_strategy_risk` | 将策略八维压力与公司 CRO 六维无总分风险偏好交叉，生成容量、波动、回撤、集中、流动性和移仓建议；偏好不代表能力 |
| 投资决策 | `oil_trading_strategy` 内的系统代理 | 批准风险建议，并独立授权策略资金；玩家尚不能操作 |
| 公司风控 | `corporate_risk_control` | 风控部提案、决策委员会批准、运行时按公司汇总暴露自动执行 |
| 交易执行 | `oil_execution_desk` + `oil_trading_strategy` | 已有六维执行差异、价差、滑点、费用、穿透成交和 TCA |

玩家不能提交八个自由数值。`GET /api/oil-strategy-research-roster?seed=42&count=5` 只按 Seed 发布1—8名稳定候选。竞技 Demo 会自动抽取其中一人并展示任命；未来玩家只能从候选中任命，而不是自由捏蛛网。相同 Seed 与候选序号得到相同姓名、蛛网、策略授权和哈希。蛛网表达取舍，没有总分，也没有“越高越好”。

## Investment Strategy Department / PM personnel philosophy

投资策略部采用 **style-first personnel system**。预测研究员的报告可以与未来真实市场直接比较，因此预测部可以有专业能力和事后准确性评分；PM 的职责则是在不确定信息下，把已经发布的研究转化为投资表达。延续或回归、快或慢、集中或分散、积极或保守都可能在不同市场状态下胜出，不存在统一正确的风格端点。

```text
latent traits
    ↓
eight continuous investment styles
    ↓
runtime strategy policy
    ↓
actual decisions
    ↓
historical track record
    ↓
player evaluation
```

潜在特质只负责让候选人的八维偏好形成稳定且内部相关的人设，不代表能力、alpha 或质量等级。PM 不设 `capability_total_score`、`quality_score`、`alpha_score`、`investment_skill` 或其它隐藏综合分，也不存在系统内部候选排名。**Stable behavior ≠ stable performance ranking**：趋势型 PM 在趋势阶段表现出色、在震荡或转折阶段受损，是预期的风格结果，不是人员生成失败；同一人在不同 Seed 和市场阶段的相对名次可以变化。

未来招聘与履历层可以展示收益、波动、最大回撤、换手、平均持有期、资本利用率、分市场状态表现、大行情捕获、回撤后恢复以及最大单笔／单期盈亏。这些都是已发生决策的可观察 track record，用于玩家判断，不得回填为隐藏 PM skill，也不得据此给未来信号或仓位偷偷增加奖励。

部门之间不计算 compatibility／matching score。预测部发布预测，投资策略部生成目标，风控部审阅并裁剪，交易部执行；协同或摩擦只通过这些真实业务接口自然产生。PM 只能读取当期可见市场、已发布预测和自身既有状态，不能读取隐藏未来。`capital_deployment` 只表示 PM 在已经获授权资本中通常愿意部署多少；公司给该策略多少资本始终由投资决策层决定。

四类人员无需形式对称：预测研究部具有可测专业能力和研究风格；投资策略部当前只建模投资风格；公司风控部当前建模风险哲学，专业能力留待独立验证；交易部具有可测执行能力和执行风格。

## 已实现的单合约延续／回归方向信号

当前底层信号仍是 `forecast_continuation_reversion_directional_edge_sized_turnover_v7`；v1.1 新增的是信号之后的跨回合观点状态和结算归因，不伪装成另一套信号引擎。它对当前主力和下一主力分别独立形成单合约目标，读取2／4／8周预测；默认负责人使用50%／30%／20%期限权重，其他负责人由预测期限轴插值。回归侧先计算当前价与预测中枢的距离：

```text
预测不确定性 = max(0.008, 0.5 × log(置信上限 / 置信下限))
回归信号 = clamp(log(预测中枢 / 当前锚价) / 预测不确定性, -1, 1)
```

因此预测中枢高于当前价时回归信号为正，倾向增持；中枢接近当前价时趋近零；中枢低于当前价时倾向减持或反向。它不是读取未来真实价格，而是完全承担已发布预测可能错误的后果。

延续侧只读截点已经可见的最近8周收盘趋势和预测远近端路径。可见趋势按8周首尾收盘对最近周均振幅的2倍归一；预测路径只有2周至8周的置信上下界同时上移或同时下移才有效。两者都可用时按65%／35%组合，缺少一项时只使用另一项；组合后乘1.5并裁剪到−1至1。

v1.3 修正了一个重要语义偏差：预测中枢相对当前价格的基础方向不再随着 PM 偏向延续而被丢弃。`continuation_reversion` 现在控制延续叠加的强度，两个信号按 L2 归一化，避免单纯相加机械放大风险：

```text
叠加前信号 = 回归基础信号 + 延续强度 × 延续信号
归一化因子 = sqrt(1 + 延续强度²)
原始信号 = clamp(叠加前信号 / 归一化因子, -1, 1)
```

负责人的 `continuation_reversion` 从回归端到延续端连续映射：0分为0.05延续叠加强度，50分保持0.30基线，100分为0.90。兼容字段 `continuation_weight`／`reversion_weight` 仍保留，但运行公式明确发布 `continuation_overlay_intensity` 和两个归一化后的有效权重。入场选择性随后施加0.05—0.25死区。因此面对同一报告，不同负责人可以形成不同方向和幅度；系统没有事后识别真实行情或替负责人择时。

机构 `capability_total_score` 和六维配置只用来生成预测质量和事后评分，不进入信号、风险容量或目标仓位公式。交易策略对已发布的中枢和上下限完全负责：低水平机构如果错误且过度自信，应通过实际亏损体现，不由后台提前缩小它的仓位。

长期策略目录只保留两种顶层引擎：当前已实现的单合约方向策略，以及未来的期限结构相对价值。旧称“预测偏差逆向”并入方向策略的回归侧，未来可作为旧预测残差证据；突破确认属于延续侧过滤器，不单列策略。完整定义见 [`OIL_FUTURES_TURN_EXECUTION.md`](../design/OIL_FUTURES_TURN_EXECUTION.md)。

## 任命制八维策略偏好

策略负责人包含八个0—100偏好维度。延续／回归轴使用分层候选槽，默认5人招聘池稳定覆盖回归、均衡和延续侧；其余维度由资本态度、节奏、纪律和曲线关注等相关潜在特质共同生成。默认负责人八维均为50。

| 维度 | 运行映射 | 当前范围 |
|---|---|---:|
| 延续／回归 `continuation_reversion` | 预测中枢基础信号上的延续叠加强度 | 0.05—0.90；50分为0.30 |
| 资金部署 `capital_deployment` | 在已获配策略资本内愿意部署多少 | 25%—75% |
| 调仓反应 `responsiveness` | 目标缺口追踪速度与普通净成交容量使用率 | 26%—74%；25%—75% |
| 入场选择性 `selectivity` | 信号死区、最小价阶和净优势底线 | 0.05—0.25；0.20%—2.10%；0.05%—0.225% |
| 换手活跃 `turnover_activity` | 半月毛成交预算和执行紧迫度 | 0.60—7.50倍；0—100活动值 |
| 持仓耐心 `holding_patience` | 预计持有回合与减仓／反转时的仓位保留 | 0.5—6回合；0—70%保留率 |
| 近月集中 `near_month_focus` | 主力／下一主力风险权重 | 主力50%—80% |
| 预测期限 `forecast_horizon` | 2／4／8周预测权重 | 短端70/22/8至长端30/38/32 |

决策委员会的资金授权已经是独立运行字段。当前单策略 Demo 由系统代理授权当期公司权益的100%，玩家还不能操作；风控同时发布建议资金比例，但该建议不会自动取代委员会决定。资金部署只作用于 `allocated_strategy_capital_usd`，市场限仓不乘人员偏好：

```text
资金部署预算 = 已获配策略资本 × 资金部署比例
资金容量 = 资金部署预算 × 合约权重 ÷ 单手初始保证金
市场硬容量 = min(动态单合约限仓, 组合总限仓 × 合约权重)
理想容量 = min(资金容量, 市场硬容量)
最终目标 = 理想目标 → 观点失效状态 → 单策略风控 → 公司总风控
```

每个合约明确发布 `binding_capacity` 为资金部署、市场限仓或停止新增。15%初始保证金率目前只是把获配资本换算成手数的第一版尺度，不是正式 VaR；12%维持保证金率、市场限仓和费用不是策略负责人的偏好，公司风控则由另行任命的 CRO 六维风险偏好提出。未来品种负责人和投委会发布真实额度后，无需再把整家公司权益交给单策略代理。

持仓耐心已不再只是说明字段。当新目标要求减少同方向仓位时，按0—70%保留一部分现仓；反转时只使用一半保留率，防止耐心变成拒绝止损。保留后的目标始终裁剪在当前风险容量内。调仓反应随后决定本回合向该目标移动多快，两者职责分开。

换手活跃只决定毛周转预算及滑点紧迫度，不再改变调仓速度、信号死区、价阶门槛或仓位规模。`turnover_intensity` 参数仅作为后端校准兼容入口覆盖这一维，服务 API 不向玩家暴露它。换手预算仍是上限而非配额，实际毛成交取策略预算、公开 `turn_trade_limit_lots`、预测净优势使用率、限价穿透率和临时持仓空间的较低者。

未成交差额不作为死订单保存。下一回合使用新预测、实际仓位、新负责人授权和新限额重新计算。研究机构能力分仍不进入任何策略偏好或仓位公式。

## 聚合成交、成本和盈亏

当前回合产生决策，下一回合结束时读取新实现的两根周 K。净调仓和毛成交预算按决策截点最近两根可见周成交量的权重冻结拆分，不读取未来两周成交量；周中性成交价为 `OHLC4 = (开+高+低+收)/4`。决策同时只用当时已发布预测，为未来两周冻结方向、入场价和退出价；结算时只有新实现周线真正触发入场才产生往返交易。

周内时序采用明确的聚合假设：阳线按 `开→低→高→收`，阴线按 `开→高→低→收`。入场后若预测退出价未触发，则在周收盘强制平掉该笔周内仓位。它不是逐笔盘口或真实日内路径，只是保证相同 OHLC 和 Seed 可复算、且不倒看实际极值来制定订单的第一版执行代理。

决策截点还会用最近可见周的成交量、波动率和当前返还档位估算下一窗口的往返成本。最低净优势与最小价阶均由负责人的入场选择性映射，分别落在0.05%—0.225%和0.20%—2.10%；价阶门槛冻结为：

```text
required_edge_after_cost_pct
= max(
    strategy_minimum_trade_edge_pct,
    estimated_round_trip_cost_pct + net_edge_floor_pct
  )
```

预测周开盘到收盘的方向性变动扣除估算成本和最低净优势后，决定毛预算的实际使用率：

```text
edge_quality
= clamp(
    (forecast_expected_edge - estimated_cost - net_edge_floor)
    / 0.60%,
    0,
    1
  )

signal_utilization = 0.40 + 0.60 × abs(parent_signal)

round_trip_budget_utilization
= sqrt(edge_quality) × signal_utilization
```

因此预测仅仅勉强覆盖成本时不做往返交易；优势增加时连续放量，只有强方向和充分净优势同时存在时才接近使用完整周预算。它不改变方向目标或净仓位规模，也不读取未来周成交量。

结算时，冻结限价必须被真实周路径穿透才形成成交。入场和目标退出分别使用：

```text
fill_ratio
= clamp(
    penetration_beyond_limit
    / (realized_weekly_range × 20%),
    0,
    1
  )
```

刚好触碰限价的成交率为0；穿透不足时只部分成交。入场后目标退出也按穿透率部分成交，剩余已入场数量在周收盘平仓。穿透只在结算时读取已经实现的周 OHLC，不参与此前决策。

动态完整价差以主力2 tick、下一主力3 tick、退出旧合约5 tick为基准，再按当周成交量和波动率调整，最终限制在1—20 tick。每侧参与率滑点为：

```text
slippage_bps
= min(
    75,
    0.35 × weekly_volatility × 10000
    × sqrt(side_lots / weekly_market_volume_lots)
    × urgency_multiplier
  )
```

`urgency_multiplier` 仍随换手活跃从0.85连续升至1.15，但不会连带改变仓位、调仓反应或选择性。它不是逐笔冲击模型；同一合约同一周同一方向的聚合手数作为一个执行母单计算，防止仅靠虚假拆单消除冲击。

硬手续费逐边按每手2.50美元收取：交易所1.40、清算0.35、经纪0.75。交易所费与经纪费可返还，清算费不可返还；返还档位只读取此前24个半月回合的毛成交量，门槛依次为25万／75万／150万手，对应10%／20%／30%。返还不得超过可返还部分，净手续费不得为负。到期现金结算不收价差或滑点，仅收每手0.50美元结算费。

每个周窗口和半月报告均满足：

```text
net_delta_lots = buy_lots - sell_lots
gross_turnover_lots = buy_lots + sell_lots
round_trip_lots = (gross_turnover_lots - abs(net_delta_lots)) / 2
```

每个周窗口先把外部成交严格拆成净调仓和往返交易；两者共用同一方向聚合母单的滑点，但按各自原始名义额分摊，价差与费用按各自手数归属。逐周、逐合约和逐回合均满足：

```text
gross_pnl_before_cost
= carry_gross_pnl
  + net_adjustment_gross_pnl
  + round_trip_gross_pnl

execution_cost
= net_adjustment_execution_cost
  + round_trip_execution_cost
  + cash_settlement_fee

net_pnl
= 共同油价方向持仓收益
  + 合约相对表现收益
  + 移仓执行盈亏
  + 普通方向调仓执行盈亏
  + 周内往返盈亏
  - 对应价差、滑点、手续费与结算费
```

周报告同时给出原始平均买卖价和包含价差、滑点、净费用的现金等价 `all_in_buy_price`／`all_in_sell_price`。原始市场成交价必须位于周 K 高低区间内；现金等价价可以因外加费用略超出区间。账户以“原始成交盈亏减成本”入账，因此不会再通过 all-in 价格重复扣费。

回合报告同时发布目标、计划与实际净成交、总买入、总卖出、毛成交、往返手数、往返盈亏、未用毛成交预算、两个周执行明细、期末仓位、指示性保证金和限额超额。动态限额下降且当期成交容量不足时允许暂时报告整改缺口，但缺口期间不得新增风险。

## 当前限制

- 只提供单合约延续／回归方向引擎；旧预测残差证据、突破确认过滤器、期限结构相对价值和多策略组合分配器尚未实现；
- 竞技 Demo 已显示玩家与 AI 的随机任命和账户，但没有玩家自主选择、正式存档或委托界面；
- 已有周度聚合价差、参与率滑点、逐边手续费和返还，但参数仍是全球原油市场的游戏化初值，不等同于某一家真实交易所或经纪商报价；
- 执行已有连续交易员能力，但仍没有盘口深度、限价排队、拒单或多实体内部撮合；穿透成交只是周 K 级代理，不能还原真实周内订单顺序；
- 投委会资金授权已经进入后端决策，但仍是“单策略获配公司当期权益100%”的系统代理；尚无玩家审批、固定子账户额度和跨策略分配；
- 策略研究负责人已经形成显著方向、收益、风险、成交和成本差异；投资决策委员会的选择与额度职责仍由系统代理；
- 交易部随机任命摘要已经出现在竞技界面，但玩家选择、持久成绩和滚动实测能力蛛网仍不存在。

交易部 v0.1 已实现六维连续能力总分、三维独立执行风格、50分兼容基线和相对中性执行器的 TCA 归因；详见 [`OIL_EXECUTION_DESK_ARCHITECTURE.md`](../design/OIL_EXECUTION_DESK_ARCHITECTURE.md)。

## v1.3 观点失效校准、行情分段与换月归因

每个命名合约持久保存 `active／watch／invalidated` 三态观点记录。结算后才使用上一份已发布预测和刚实现的半月价格检查预测区间突破与方向错误。原始出界仍完整记录，但只有超出区间1.0个不确定性单位的“实质出界”才累计失败；连续两次实质出界／方向错误，或一次超出2.0个不确定性单位的严重出界，才进入失效并把下一目标缩放至30%。一次实质失败进入观察并缩放至70%；失效仓不得增加同方向风险；一次无实质失败回合先从失效恢复到观察，再恢复正常。信号发生绝对值均不低于0.20的反转时，旧方向仓位必须先退出至零，下一回合才可反向。研究配置能力分不进入状态机。

`audit_oil_direction_regimes` 用已经结算的现货参考路径作事后标签，策略在决策时看不到标签。四个半月窗口中，累计变化至少3.5%且路径效率至少55%为趋势；前后两个双回合方向相反且各自至少1.5%为转折；其余为震荡。Seed 0／42／99、2030—2031共观察趋势37、震荡48、转折50个窗口，只改变延续／回归轴的10／50／90分，其他七维、预测、风控和交易部保持相同。汇总平均半月收益 bps 为：

| 风格 | 趋势 | 震荡 | 转折 |
|---|---:|---:|---:|
| 回归10 | 282.67 | 73.86 | 61.30 |
| 平衡50 | 310.96 | 72.97 | 41.89 |
| 延续90 | 309.60 | 57.85 | 43.59 |

三 Seed 汇总中，平衡型以极小差距领先趋势，回归型领先震荡和转折；32 Seed 开发集则由延续型领先趋势、回归型领先震荡与转折，32 Seed 验证集的延续型趋势收益只比平衡型低2.17bp／半月、回归型继续领先转折。残余“震荡”桶会混入低幅缓慢单边行情，因此不把某一风格必须赢得全部震荡样本设为生产公式硬约束。结论是方向风格已经产生可复算的环境差异，但不能预先知道下一阶段赢家。

`audit_oil_directional_economic_calibration` 另以单轴受控档案冻结其余七维、市场、预测、CRO、交易部和资金授权。最终开发／验证小样本中，90分对10分的实际成交手数比中位约4.8—4.9倍，P90不高于5.72倍；执行成本比P90不高于8.34倍；生成候选清除90%陈旧仓位的结构性P95为9.85个半月回合。低／中／高／精英预测的观点失效占比保持严格排序；中等组目标为5%—25%，小样本硬护栏为5%—30%。5%—25%是校准目标，不会因差几个百分点而反向修改隐藏预测或读取未来。

结算归因现在以不可交易的 `OIL-REF` 现货参考变化作为共同方向基准：命名合约持仓收益拆为共同油价方向与合约相对表现；净调仓再拆为机械移仓与普通方向调仓，周内往返和现金结算单列。移仓只在旧 `legacy_exit` 与新主力同方向开仓能匹配时确认，不把真正的方向反转伪装成移仓。Seed 42 的 `2030-09-H1` 识别3,411手机械移仓，移仓期执行毛盈亏226.82万美元、成本33.80万美元。全部分项逐合约、逐回合和全模拟严格加总回账户净盈亏。

## v1.0 策略／公司两层风控

风控部现在会为每个“策略负责人 × CRO”组合生成独立审阅。Seed 42 的5位策略候选在同一中性 CRO 下，建议资金授权为公司权益的62.70%—72.79%，策略总容量建议为市场总限额的72.7%—79.5%，年化波动风险预算为获授权资本的99.94%—106.37%。这些差异来自八维策略结构，不读取未来收益或事后市场状态。

当前系统代理可以在不改变风控建议的情况下独立设定资金授权。Seed 42 默认策略把授权从100%降到60%和30%时，理想总目标从31,393手分别降至21,282手和10,641手，但市场150,000手总限额不变。单策略回撤状态也已与公司回撤状态分开：某策略可以进入仅减险，而公司组合仍处于正常状态。专项测试覆盖不同策略建议差异、审批防篡改、资金授权独立缩放和两层回撤分离。

## v0.9 不同预测机构 × 策略负责人交叉审查（通过）

2026-08-26 使用 Seed 100—107、2030-01-H1至2033-01-H1，在每个市场路径内交叉4家预测机构和6位策略负责人，共24格、13,824个账户回合。四家机构能力总分约18.61、52.76、50.04和79.70；六位负责人覆盖均衡、回归、延续、资本部署、换手、耐心与期限差异。所有组合都使用30亿美元连续账户、相同公司风控、交易部、费用、滑点、容量和盯市规则，能力分仍不直接进入策略公式。
