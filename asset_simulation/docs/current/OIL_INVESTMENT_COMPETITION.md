# 原油投资决策竞技 Demo

> 状态：当前实现事实  
> 权威范围：四机构抽签、账户、逐回合编排、排名、报告和 UI 接入  
> 代码基线：`asset-simulation-oil-investment-competition-v0.6.0`、服务 v5.42
> 主要 owner：`model/oil_investment_competition.py`  
> 最近核对：2026-08-30

## 1. Demo 目标

这一层验证一个最小机构竞争闭环：同一市场中，不同预测研究、策略负责人、资金授权和交易执行组合，在同一版本的注册策略风险 mandate 下是否能形成可解释的账户差异。公司组合风险在单策略阶段休眠。

它不是完整投资决策委员会，也不是市场撮合模拟器。当前机构口径是自营交易机构，不建模外部AUM或管理公司经济账。当前玩家与 AI 都是价格接受者；机构成交不会反向改变公共价格、成交量、持仓量或宏观世界。

## 2. 产品入口

游戏运转页把“市场行情”和“投资决策”作为同级入口。行情详情只显示已实现的周 K、月 K和年 K，不再混入短期预测 K。

预测引擎没有删除。它从前台研究工具变为竞技后台输入：每家机构在每个半月都有自己的预测 vintage，策略只能读取普通预测对象。

## 3. 参与机构

每个 Seed 固定创建4家：

| ID | 显示名 | 身份 |
|---|---|---|
| `PLAYER` | 玩家机构 | 玩家 |
| `NORTHSTAR` | 北辰全球商品 | AI |
| `PELAGIC` | 瀚海资源资本 | AI |
| `EQUATOR` | 赤道宏观基金 | AI |

四家初始自营资本相同，当前均为1000万美元。AI 没有额外未来信息，也没有特殊成交待遇。

这个尺度不是将旧30亿美元账户的手数和盈亏等比例缩小。小型自营盘更少触及市场容量上限，因此单位资本的仓位、收益和风险分布已经重新校准，不沿用旧30亿美元基线。

## 4. Seed 随机任命

每家机构在世界建立时稳定随机抽取一次完整配置：

1. 预测研究机构；
2. 策略研究负责人；
3. 交易执行负责人。

预测能力中心按参与者独立随机流产生，并在18—82分内有界；系统再按中心上下约5分生成六维研究档案。策略和交易分别先生成5名候选，再按参与者地址选择一名。策略候选使用分层延续／回归槽位，一组标准 roster 会同时包含回归、平衡与延续风格；每位候选还具有独立生成的仓位构造、调仓规划和合约生命周期三维能力，但没有能力总分或 Alpha 排名。策略风险使用固定注册 mandate，不抽取人员。

任命满足：

- 同 Seed 重复请求完全一致；
- 不同 Seed 通常得到不同 roster hash；
- 各机构使用独立随机地址，避免共享同一候选；
- 前端只收到公开档案摘要，不收到运行用完整 profile；
- 当前不能刷新、自由拖蛛网或手工改分。

这是一种 Demo 分配方式，不代表正式游戏的人才招聘规则。

## 5. 单回合流水线

竞技从2030-01上半月开始。推进一个半月时，每家机构独立执行：

```text
当前市场 + 上一预测 vintage
→ 生成当前主力／下一主力预测
→ 八维策略风格生成理想目标仓位
→ 三维策略构造能力形成提交方案
→ 注册策略风险 mandate 根据 PM 结构生成边界
→ 投委会系统代理批准 mandate 并授权资金
→ 单策略风险裁剪；组合风险层在单策略阶段透传
→ 正式账户按现金／初始保证金做最终授权
→ 交易部在下一半月两根周 K 执行
→ 结算成交成本与变动保证金
→ 计算现金利息／融资并检查维持保证金
→ 必要时追保、强平并更新账户
```

四家都完成后，系统按期末权益排序并生成一份共同回合报告。

## 6. 账户状态

每家机构的正式账户独立持有：

- `cash_balance_usd = equity_usd`；
- 冻结初始保证金、维持保证金、可用资金与超额流动性；
- 各命名合约带符号仓位；
- 正常／只减仓／强平／破产状态与追保历史；
- 上一预测 vintage；
- 单策略回撤状态；
- 组合风险状态（当前固定为单策略休眠）；
- 最近24回合毛成交历史，用于费用返还；
- 累计交易盈亏、现金利息、融资成本、强平成本、执行成本和成交手数；
- 胜／负回合数；
- 权益峰值与最大回撤；
- 各风险状态出现次数。

账户不是浏览器伪造数字。它由正式预测、策略、风控、执行、账户授权和盯市函数逐回合更新；保证金是受限现金而非二次费用，现金桥逐回合哈希并对账。它仍是进程内 Demo 状态，不是可迁移的持久存档。

## 7. 回合报告

报告分市场和机构两层。

市场部分包括：

- 起止半月；
- 主力来源合约；
- 主力结算前后价格与回报；
- 起止期限结构状态。

机构部分包括：

- 本回合及期末排名；
- 起止权益、本回合盈亏和回报；
- 累计收益与最大回撤；
- 期末仓位、总仓位、现金、初始／维持保证金、可用资金与保证金／权益比例；
- 策略盈亏、现金利息、融资成本、追保金额、强平手数与强平成本；
- 买入、卖出和总成交手数；
- 成交前毛盈亏与执行成本；
- 策略风险状态、裁剪手数；
- 投委会资金授权、mandate 参考资本比例与单策略风险状态；
- 方向策略当前仓位风险区间、风险占用率和新增风险完成率；
- 每个合约的信号、观点状态、观点调整前后目标、策略风险批准目标和分层裁剪量；
- 共同油价方向、合约相对表现、机械移仓、普通调仓、周内往返和执行成本的完整收益归因。

界面当前只展示其中较精简的一组；完整字段保留在 API，便于后续报告和归因界面使用。

## 8. 排名和历史

排行榜按当前权益降序排列，同时返回累计收益、最大回撤、期末总仓位、累计成交、累计执行成本和胜负回合。

`report_history` 按最新优先返回从开局到当前截点的全部报告。前端历史下拉可以选择任一已完成回合。长期运行后全量历史会增大响应体，分页、年度快照和报告压缩尚未实现。

## 9. 确定性与重置

竞技会话绑定 Seed、年数、上游全球 identity 和竞技模型版本。

- 请求未来截点：按顺序补算所有中间回合；
- 请求当前截点：直接返回已有状态；
- 请求更早截点：清空账户，从开局确定性重放；
- 服务重启：进程缓存消失，但可由 Seed 和浏览器回合重建。

游戏普通推进不允许倒流，只有二次确认重置会有意请求开局状态。

## 10. 公平性与信息边界

当前公平性只保证运行规则一致：

- 玩家与 AI 使用同一组函数；
- 四家读取同一市场路径；
- 都受市场限仓、成交容量、注册策略风险、正式账户和执行成本约束；
- 都不能修改公共市场；
- 预测能力分不作为仓位公式输入。

当前不保证候选人在长期收益上强弱均衡。v0.9 的8 Seed×4预测机构×6策略交叉审计已证明方向、收益、换手和成本多样性，但人员随机抽取与预测能力差异仍可能让某些 Seed 出现明显先天优势；这需要更长时段和更多 Seed 的游戏平衡审计。

## 11. UI 当前展示

投资决策页有：

- 四张机构任命卡；
- 权益排行榜；
- 最新／历史半月报告；
- 玩家身份高亮；
- 正负收益、买卖手数、成本和风控状态。

当前 UI 只是观察面板：没有任命、更换、批准、额度、止损或委托按钮。视觉层级和报告解释也尚未达到正式游戏品质。

## 12. 当前边界与下一步

未实现：

- 玩家和 AI 的正式人才选择逻辑；
- 玩家可操作的投委会审批、跨品种／跨策略额度配置；当前系统代理已完成风险审批和单策略资金授权，但不是最终交互；
- 正式存档、多个档位和版本迁移；
- 外部追加资金、组合抵押品、动态保证金和跨品种账户净额；
- 多策略、多品种、期现和组合风险；
- 机构间撮合与市场冲击；
- 长期公平性、收益分布和难度校准。

最合理的下一步不是再加一张展示卡，而是让玩家在只读候选中完成一次真实任命或额度批准，并把决定冻结进存档和后续每回合报告。

## 13. 验收证据

自动测试覆盖：

- 同 Seed roster 确定性；
- 不同 Seed roster 分离；
- 四机构完整任命；
- 同一市场回合结算；
- 排名1—4完整；
- 报告历史增长；
- 重置回放清空账户；
- 初始保证金不二次扣权益、可用资金恒等式；
- 高杠杆亏损触发追保、强平并恢复维持保证金；
- 空闲现金利息、融资成本、破产锁定和逐回合现金桥；
- 服务和 Viewer 静态契约。

真实浏览器已验证 Seed 42 首回合；Seed 0、42、99 的赢家、玩家名次和 roster hash 均有差异。后端另完成8 Seed×4预测机构×6策略的多样性审计，以及首批3 Seed×3风格×3授权的正式账户三年分布校准；后者建立了基线和门禁，仍不是完整长期难度结论。
