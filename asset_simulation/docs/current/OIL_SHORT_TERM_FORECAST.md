# 原油双合约短期预测

> 状态：模型、评分、独立 API 与竞技后台接入已实现；前台预测 K 已撤下，摘要和长期成绩界面尚未实现  
> 权威范围：当前主力／下一主力周线预测、六维蛛网能力、滚动修订与事后评分  
> 代码基线：`asset-simulation-oil-short-term-forecast-v0.1.3`  
> 最近核对：2026-08-25

## 产品边界

短期预测位于只读 `oil_futures_overlay_v8` 之后，是研究信息层，不是价格 owner。每份报告只覆盖当前主力和下一主力两个 `OIL-YYMM` 命名合约；回溯比例调整的连续主连仍只是不可交易展示指数。

```text
隐藏期货真实路径
→ 六维能力控制的预测误差
→ 主力／下一主力联合周线预测
→ 半月 vintage 继承与修订
→ 目标周实现后评分
```

生成器会读取世界已生成的隐藏合约路径，以受控误差制造合成量化机构。输出只含预测 OHLC、置信区间和修订幅度，不含未来真实周 K。该机制用于游戏内“能力有高低”的研究服务，不声称是现实世界可部署的预测算法，也不能修改真实价格、成交量、持仓量、宏观或玩家仓位。

长期组织按预测研究、策略研究、投资决策、公司风控和交易执行分工。预测研究负责方向、路径和区间；策略研究把普通预测转换为理想目标；公司风控形成批准目标；交易部在容量内成交。四层已在随机任命竞技 Demo 中运行，但投资决策仍由系统代理串联，玩家尚不能改变任命、额度或策略组合。当前事实见 [`OIL_INVESTMENT_COMPETITION.md`](OIL_INVESTMENT_COMPETITION.md) 与 [`OIL_TRADING_STRATEGY.md`](OIL_TRADING_STRATEGY.md)。

服务保留 `GET /api/oil-short-term-profile` 和 `GET /api/oil-short-term-forecast` 供独立研究与测试调用。v5.41 中，游戏行情详情不显示“预测配置／短期预测”或预测 K；`oil_investment_competition` 在后台为每家机构生成一份同时覆盖两个合约的预测，并继承该机构紧邻上一半月 vintage。竞技会话在进程内保留滚动历史，正式持久化仍未实现。Python 调用方也可直接使用：

- `build_institution_profile`：填写六维蛛网数值并计算配置总分；
- `generate_institution_profile_for_score_range`：按 Seed 与期望总分范围生成稳定、非平坦的六维配置；
- `generate_oil_short_term_forecast`：生成一个半月预测 vintage；
- `score_oil_short_term_forecast`：按评价截点的已实现周评分；
- `aggregate_oil_short_term_scorecards`：把多期成绩聚合为实测蛛网图。

任意历史 vintage 仍须由调用方传回以完成跨多期修订和修订评分，尚无游戏存档 owner，因此“不可覆盖旧预测”是函数和契约边界，不代表服务已经持久化。当前 API 只重建紧邻上一半月版本。

总分范围生成器仍按5分粒度接受独立 API 输入；总分是生成约束，不是事后预测成绩。自动生成的六维多数围绕目标总分展开，同时允许一两个长处和一个短板，单维与目标中枢的最大距离由配置限制为14分。竞技 Demo 不提供配置弹窗，而是为四家机构按 Seed 自动生成不同研究档案。研究摘要、实测蛛网和事后评分仍未放进游戏界面。

## 目标与期限

每个半月回合选择：

1. `curve.main_contract_id` 对应的当前主力命名合约；
2. 挂牌顺序中紧随其后的下一主力命名合约。

两者均预测截点之后到最终结算周的剩余周 K；如果合约到期晚于本次生成世界的终点，则在世界终点截断。到期月标记为 `settlement`，此前为 `tradable`。例如2030年1月上半月，Seed 42 的默认机构分别预测：

- `OIL-3005`：18根剩余周 K；
- `OIL-3009`：34根剩余周 K。

上半月截点之后从 W3 开始，下半月截点之后从下月 W1 开始。预测不会重复已经公布的周线。

## 蛛网能力和总分

能力是未来蛛网图的六个0—100分维度：

| 维度 | 控制内容 |
|---|---|
| `direction` | 周涨跌与中短趋势误差 |
| `path` | 预测收盘路径与真实路径的距离 |
| `turning_points` | 高低点提前、滞后和拐点形状 |
| `range` | 周高低区间和振幅 |
| `term_structure` | 主力／下一主力价差与期限结构 |
| `revision` | 新信息到来后的纠错速度与纪律 |

不再设置能力等级、研究风格或性格模板。每家机构直接保存六个蛛网数值，并按正式评分权重计算一个 `capability_total_score`。玩家界面不逐项填写这些数值，只提交期望总分范围，生成器负责形成蛛网形状。这些数值不直接加到事后成绩，而是控制路径误差、方向误差、时点错位、振幅误差、合约特异误差、价差误差和修订质量的尺度。所有机构共享同一套中性预测与修订规则。

## 联合路径和滚动修订

两个合约共享按目标周寻址的市场误差，同时保留由 `term_structure` 能力控制的合约差异误差，因此不会被当作两个互不相关的价格序列。期限结构评分直接评价同一周的预测价差。

同一目标周的误差方向跨 vintage 保持稳定，并随剩余期限缩短而收敛。调用方传入上一期 vintage 时，当前期按修订能力、修订速度、观点黏性和刚实现周的预测意外，在旧观点与新观点之间平滑混合。换月后，同一命名合约即使从“下一主力”升为“当前主力”，仍按合约 ID 继承旧预测。

## 评分

一份 vintage 只能评价截止日期已经实现的目标周。评分响应不返回真实周 K，只返回样本数、分项分数和哈希。当前权重为：

| 维度 | 权重 |
|---|---:|
| 路径 | 30% |
| 方向 | 20% |
| 拐点 | 15% |
| 振幅 | 15% |
| 期限结构 | 15% |
| 修订 | 5% |

路径、方向、拐点和振幅先在两个合约内分别评分，再按当前主力65%、下一主力35%合成。期限结构评价两个合约同期对数价差。修订评价新版预测是否朝真实结果纠错，同时惩罚超过所需幅度的过度修订。样本尚不足的维度为 `null`，综合分只对已有维度重新归一化，不把缺失项当零分。

多期 `scorecard` 可按已实现周样本数聚合为 `measured_radar`。机构配置给出的 `capability_radar` 是先验实力参数，`measured_radar` 是玩家以后可以看到的实际业绩，两者不得混为一项。

## 当前校准和限制

v0.1.3 将隐藏真实路径从“所有机构的预测基底”改为按能力开放的信息。零分机构的收盘路径、每周振幅和上下影线形状只由截点已见的当前价格、历史趋势、历史振幅和独立误差生成；能力从0提高到100时，通过平滑曲线逐步混入未来真实形状。15分大约保留6%的隐藏形状，70分约78%，100分才完整保留；配置分仍不传入交易策略或直接缩放仓位。

专项测试验证确定性、短／长运行前缀一致、OHLC 恒等式、无未来字段、半月继承、双合约联合评分，以及直接蛛网数值能形成可测量的能力差异。配置总分只是机构初始能力摘要；真正给玩家参考的长期水平应使用已实现预测聚合出的实测总分。

当前限制：

- 没有持久化完整 vintage 历史；API 只即时重建上一半月版本；
- 没有玩家／AI购买或任命研究机构、研究摘要、完整 vintage 或成绩展示界面；当前竞技任命由 Seed 自动决定；
- 预测已经在四机构竞技后台接入目标仓位，但玩家前端不能查看或批准预测报告；
- 没有按现实历史数据校准机构胜率，分数只表示本模拟世界内相对隐藏路径的能力；
- 普通世界没有命名战争、禁运等尾部事件，预测误差模型也尚未单列事件识别能力。
