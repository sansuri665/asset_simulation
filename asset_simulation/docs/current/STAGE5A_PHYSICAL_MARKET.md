# Stage5A：海湾—东亚固定船队与独立定价

> 基线：main `a2a7281424d066a11eea3eea23d9442aa329b9a0`

> 模型：`asset-simulation-stage5a-physical-market-v0.1.0`  
> 定价：直接调用 main 的 `single_route_pricing` v0.2.1，未修改其代码、系数或护栏。

## 1. 已完成与未做

```
Seed 的 Gulf→East Asia 月度货量计划
 → 按真实日历拆成每月三个回合
 → 固定编号船队在本回合产生 prompt supply
 → 现有独立定价核心给出指示性 TCE
 → 货量与船数约束下执行整船运输
 → 真实交货、压载返回、更新运输计划偏离
 → 下一回合
```

`single_route_fleet.py` 只负责船；`single_route_market.py` 负责调度顺序、实际桶数和计划偏离；价格仍由 `single_route_pricing.py` 负责。价格高低不反向决定派船数量：没有船东策略，也没有货主价格弹性。因此这是有物理反馈的运输系统加定价器，不是完整的价格清算均衡。

不包含燃油、港口费、佣金、OPEX、折旧、船价、债务、期租、新船、拆船、维修、主动扣船或跨航线调船；不修改主干宏观和海运需求，不接入现有Viewer/API。全部输出是研究回放，不供玩家提前查看未来。

## 2. 船舶时间与供给

船有永久整数编号1..N，六个状态池保存编号而不只是数量。无任何外部补船池。

| 回合（t开始装船） | 船状态／事件 |
|---|---|
| t | 装货0回合，立刻进入 LADEN_1 |
| t+1 | LADEN_2 |
| t+2 | EA_DISCHARGE，占用完整1回合 |
| t+3开始 | 卸货完成，原油交付；船进入 BALLAST_1 |
| t+4 | BALLAST_2 |
| t+5开始 | 返回Gulf，可再次装货 |

回合开头先推进已有船舶，再公布prompt，再定价及派船。船队状态带open/closed标记，重复推进或重复派船报错。同一编号不允许丢失、复制、越级派出。

没有货可装的船留在GULF_PROMPT，下回合仍参加供给。停港等货不等于退出市场。

默认245艘只是实验起点，绝非已校准的最优或正常船队规模。审计扫描230、235、239、242、245、250、260、280艘；不会因为某个Seed欠运便自动增加总船数。

默认按固定9.3 mb/d参考将开局在途船分散在5个航次年龄，组间数量差不超过1。不读取未来峰值需求。另测5种相位轮换及全部在港冷启动。预热36回合只排除统计，不清除库存、欠运或价格历史。

## 3. 真实货物与虚拟库存

每票固定1,971,000桶。月度计划先四舍五入到整数桶，再分配到三个回合，严格保持月总量。余下不足一船的桶数留在源端，不另建fractional-demand累计器。

每回合可装货量 = 前期未装量 + 本回合计划量。现有定价器给出含有限库存纠偏的需求，把它向上取到整船意向后，执行量再受实际货物和prompt船数共同限制。

```
实际派船 = min(整船意向, 实际可装整船货量, Gulf prompt船数)
```

不会因为定价器建议多运，就凭空生成原油。执行层不借用未知岸罐库存，因此此版本G（未装计划量）非负；通用定价接口仍允许正负偏离，W和E也仍可正可负。

实际到货只从完成卸货的船号产生。参考到货是三回合前的正常装船计划；它只用于计算偏离，不能创造真实到货。

逐回合同时验证：

```
G = 累计计划量 − 累计实际装货量
实际在途 = 初始在途 + 累计装货 − 累计实际交货
实际在途 = (LADEN_1 + LADEN_2 + EA_DISCHARGE船数) × 单船桶数
E = 累计实际交货 − 累计参考交货
W = 实际在途 − 参考在途
G + W + E = 0
```

所有上述数量用整数桶，残差是严格的0，不通过round把浮点误差伪装成零。开局已有船上的货单独登记为初始在途，避免空管线启动制造假短缺。

这些是相对运输计划的偏离，不是岸罐绝对库存或炼厂断供预测。`cumulative_unfilled_fixture_observations`不是独立货盘数，也不是期末欠运；期末G单独报告。

## 4. 报价与结算边界

TCE仍为指示性标准船收益基准，实际2025美元护栏1,000—122,500／日不变。执行记录中的`executed_benchmark_real_tce`仅表示将本回合基准价标记到已执行货盘，绝不是已模拟了谈判、发票或现金收入。零船时可有高报价，但无执行价格。

没有新增需求、仍有历史可运货盘的边界场景可以清理整船欠运；此时仅沿用上一指示价格，不产生新的价格观测。最后不足一船的残量不会凭空消失。

名义TCE使用本回合开始前最近已结算年度CPI；2025使用初始条件，2026使用2025年度值。不提前读取本年未知的全年CPI。每条输入记录保留`cpi_information_year`。

窗口平均需求9.456 mb/d对应约243.38艘循环占用，但多年高需求阶段需要更多。平均运力够不代表各阶段都够：245艘会积累大量欠运。较小船队的高运价、数百天欠运是不可持续服务约束的诊断，不能称为真实市场均衡或已模拟出超级周期。

同样245艘，在Seed0/1/5/7中的实际TCE中位数分别约22,932／21,476／14,047／20,131，而Seed42约80,323。固定船队下的需求路径差异不再被外部补船适配器消除。

Seed42拉长到60次年度转移（预热后60年）时，245艘的TCE中位数约17,374，250／260／280艘分别约12,761／8,528／4,439；长期较低需求释放了闲置船。价格尾部仍受库存代理和护栏影响，未做真实运费校准。

## 6. 日历与同步诊断：不能隐瞒的局限

等长10天窗口、恒定每回合50票货盘的控制实验，252艘在预热后TCE严格平稳（约35,472／日）。200艘则严格每100回合最多执行4,000票，欠运增量与解析吞吐量上限一致。

但固定5回合并不等于固定50个自然日。真实日历中每回合9、10或11天，完整循环48—52天，交货28—31天。因此即使每日货量固定，返航批次与窗口长度仍会产生机械价格回声。

恒定9.3 mb/d、真实日历、245艘的六年控制实验，在预热后TCE约16,582—40,293／日，中位数30,685。五种开局相位和全部在港冷启动在预热后得到同样的分布。这是整回合时钟/批次的结构效果，不是上轮已修掉的“滞后窗口总量误当当前供给”bug，更不能算经济新闻造成的波动。

本版忠实保留用户确定的0+2+1+2原则，同时明确展示此效果；没有通过调高价格惯性、减少弹性或添加随机噪声把它隐藏。后续若要求更真实的短周期波动，需要单独决定是否细化物理时钟或研究不同报价窗口，而不是把这些机械波动直接拿去拟合真实TCE。

## 8. 当前定位

这一步完成了固定真实船队约束下的单航线运输执行和定价连接。没有恢复旧成本分支，没有制造自动补船机制，也没有把强制欠运包装成现实均衡。下一步应先审视时钟粒度与供给窗口的定价含义，再决定成本层或全球扩展。
