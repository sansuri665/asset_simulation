# 文档入口

当前项目只保留全球宏观与原油航运需求底座。

- [`INDEX.md`](INDEX.md)：文档与 owner 路由；
- [`MODEL_CONTEXT_GUIDE.md`](MODEL_CONTEXT_GUIDE.md)：修改前最低证据集；
- [`current/PROJECT_STATUS.md`](current/PROJECT_STATUS.md)：当前完成度；
- [`current/RUNTIME_ARCHITECTURE.md`](current/RUNTIME_ARCHITECTURE.md)：年度／月度时序；
- [`current/CONTRACTS_AND_UNITS.md`](current/CONTRACTS_AND_UNITS.md)：注册契约和单位；
- [`current/OIL_PRICE_PROJECTION.md`](current/OIL_PRICE_PROJECTION.md)：年度原油锚与月度价格路径；
- [`current/OIL_SHIPPING_DEMAND.md`](current/OIL_SHIPPING_DEMAND.md)：物理油池、货量和吨海里。

`decisions/` 与 `components/` 中保留的文件只描述仍有效的全球宏观决策。
