# ADR-003：区域单向消费全球与 G17 边界

> 状态：已被 ADR-006 取代  
> 日期：2026-08-14  
> 影响：历史区域与 G17 边界（不再是当前产品）

> 2026-08-25复核：下文全部是历史方案。当前代码没有区域 runner、G17、RoW、汇率或相关 Viewer，不能从本 ADR 推断运行事实。

## 决策

区域逐年读取同年已经结账的全球状态，生成本地状态，但不在同年写回全球。汇率、贸易、资本流和储备货币需求由 G17-lite 统一形成相对量，再通过滞后端口进入区域。

## 原因

单一区域无法独立定义双边汇率或全球资本流守恒。若每个区域各自随机生成这些量，区域间会出现无法对账的重复资金和贸易结果。

## 后果

- 北美和中国大陆接入后，默认 World 的 G17-lite 五个端口已为温和非零；独立单区 runner 仍保留零端口夹具。
- 全球美元状态不是北美区域汇率，也不是完整 DXY。
- 当前相对清算覆盖北美、中国大陆、西欧／北欧、日韩和剩余世界。ADR-005 冻结为环境层后，不再按地图默认从 RoW 拆出新的完整宏观区域。
- G17 负责跨区域传导与守恒，不承担特殊事件、普通国运或称号级世界方向。
- 单一 World、缓存和 RoW 的完整决策见 ADR-004。
