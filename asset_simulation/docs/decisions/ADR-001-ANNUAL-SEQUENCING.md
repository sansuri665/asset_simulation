# ADR-001：年度同年前馈与跨年反馈

> 状态：已接受  
> 日期：2026-08-14  
> 当前复核：2026-08-25，全球 v0.8.1 与原油竞技继续遵守  
> 影响：全球年度内核

## 决策

年度内允许有明确方向的同年前馈；任何返回上游的反馈必须通过具名 `NextYearInputs` 在下一年生效。禁止为了形成“闭环”在同一年隐藏重跑。

全球顺序固定为实际经济 → 通胀名义账户 → 利率曲线 → 资金信用 → 石油商品 → 资产参考。禁止为了形成“闭环”在同一年隐藏重跑。

## 原因

单向执行使 Seed 可复算、短窗口保持前缀一致，并能明确区分原因与结果。隐藏固定点循环会让 GDP、资产和政策在同一年互相重写，难以审计与测试。

## 后果

- 同年下游可以读取已经结账的上游状态。
- 资产、信用、油价等若反馈 GDP 或通胀，必须注明来源年、目标年、owner 和单位。
- 修改调用顺序属于共享架构变更，必须运行完整回归。
- 半月原油期货、预测和竞技都位于年度 row 之后；机构交易不得触发同年宏观重算。
