# ADR-006：单一全球联邦宏观，取消汇率与分区

> 状态：已接受  
> 日期：2026-08-15  
> 当前修订：2026-08-25，全球版本与下游服务清单更新，不改变核心决策  
> 影响：默认产品、Viewer、注册资产、质量审计  
> 取代：ADR-003、ADR-004、ADR-005 中“四区宏观环境 + G17 汇率”的产品路线

## 决策

默认产品只运行全球 `asset-simulation-global-macro-v0.8.1`。世界是一个计价单位下的全球联邦账户：没有双边汇率，没有正式区域，没有 G17-lite，没有 `CoupledWorldRun`。

Viewer 与 API 只投影这一条全球运行。`global_dollar_index` 仍是该货币的资金松紧，不是汇率。资本市场环境只读全球快照。

## 原因

一二级市场需要的是增长、CPI、政策、曲线、FCI、HY、资金、油和名义盈利。分区 GDP 与汇率清算不增加可交易市场对象，却把默认世界绑在五套内核上。取消汇率后，G17 与四区不再有产品职责。

## 后果

- 默认入口是 `run_global_macro()`；服务缓存全球运行，最多64条。
- 8783在同一全球世界上另提供只读商品、原油期货、研究 roster 和四机构竞技 API；这些都是下游投影，不能写回全球宏观。
- 区域配置、区域契约、G17 与 World 从运行时删除。历史任务书留在 `docs/archive/`。
- 若未来需要人民币债、欧元债或日元融资，必须重新引入汇率与制度对象，不能把 `global_dollar_index` 假装成外汇。

## 未包含

本 ADR 本身不实现一二级资本市场 runtime。原油期货与机构竞技已经作为只读价格接受者下游运行；通用资本市场契约仍未注册。
