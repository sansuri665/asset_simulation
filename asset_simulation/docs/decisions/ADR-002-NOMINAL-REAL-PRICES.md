# ADR-002：名义价格与实际审计口径

> 状态：已接受  
> 日期：2026-08-14  
> 当前复核：2026-08-25，原油期货、账户和回合报告继续使用名义美元  
> 影响：GDP、能源商品、权益、债券与 Viewer

## 决策

Viewer 主图展示玩家实际面对的当年名义价格或财富，同时模型保留实际价格、实际财富或价格平减指数作为审计口径。所有长期名义序列必须能解释一般物价与真实供需的各自贡献。

## 原因

只用不变价会让长期资产与债务缺少现实货币尺度；只用名义价又会把累计 CPI 误当成真实稀缺、贸易条件改善或投资回报。两套口径并存可以避免重复计价。

## 后果

- 名义 GDP 与实际 GDP 并列。
- Brent、商品、权益和主权债公开主口径为名义值。
- 下一年商品通胀传导优先读取实际价格变化。
- 无量纲状态如贸易条件、风险偏好和 FCI 不随 CPI 自动膨胀，也不应为视觉对齐随意乘倍数。
- 期货报价使用美元／桶，机构权益和盈亏使用美元；实际油价指数只作购买力和长期模型审计，不能直接与名义账户相加。
