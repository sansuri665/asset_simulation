# ADR-004：单一耦合世界、RoW 与跨年 G17 清算

> 状态：已被 ADR-006 取代  
> 日期：2026-08-14  
> 影响：历史 Coupled World / RoW / G17（不再是当前产品）

> 2026-08-25复核：`CoupledWorldRun` 和 scoped 区域缓存已退出运行时。当前只有全球运行缓存与原油竞技会话缓存。

## 决策

默认产品只运行一个 `CoupledWorldRun`。全球先形成普通基座；每个正式区域读取同年全球和上一年 G17 输入；RoW 作为全球减去正式区域的共同币种残差；G17 在区域完成后清算当年账户，并只把五类端口发布到下一年。

服务只缓存完整世界。全球、区域和 G17 API/Viewer Scope 都是同一缓存对象的投影，scoped endpoint 不得再次调用模型。

## 原因

分别模拟各 Scope 会让同 Seed 的全球、区域、汇率和贸易来自不同世界。区域自己生成汇率／资本流又会破坏守恒；要求北美和中国机械加总成全球则会把未建模经济体抹去。单一 World、RoW 与滞后清算同时解决身份一致、规模对账和因果时序。

## 后果

- 同年区域不会因 G17 结果而隐藏重跑；国际传导有明确一年滞后。
- RoW 暂时承担未建模经济体的规模和跨区账户残差，但不是完整政策模型。
- 区域本地账户保留本币；跨区加总使用共同美元。
- 独立单区 runner 只作为零 G17 测试夹具。
- 若仍新增区域，必须接入 World/G17、从 RoW 扣除规模，并复跑守恒与留出集验收。ADR-005 规定这不是默认产品路线。

## 未包含

特殊事件、普通国运和称号级世界仍是独立后续层；它们不能通过改变普通 Seed 或绕过类型化端口偷偷接入。
