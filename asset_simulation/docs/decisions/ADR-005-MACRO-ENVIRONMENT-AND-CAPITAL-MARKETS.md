# ADR-005：宏观环境冻结，资本市场另建 owner

> 状态：部分被 ADR-006 取代  
> 日期：2026-08-15  
> 影响：历史四区环境冻结；资本市场另建 owner 仍然有效  
> 修正：ADR-003「后续区域从 RoW 逐步拆出」不再作为默认产品路线；ADR-004 的「新增区域必须接入 World/G17」仍适用于若真的新增区域

> 2026-08-25复核：下文“四区＋G17”是作出决策时的历史基线，已由 ADR-006删除。仍有效的只有“市场另建 owner、宏观事件显式 opt-in、不得把资产参考伪装成成交市场”。

## 决策

当前宏观层冻结为资本市场的年度环境，不再按地图继续拆出完整正式区域。默认产品停在：

- 全球 `asset-simulation-global-macro-v0.7`
- 北美、中国大陆、西欧／北欧、日韩四个正式区域
- G17-lite v0.4 与 World v0.5
- RoW 继续作为未建模经济体的会计残差，不是下一个政策模型

一二级市场必须另建 owner 与契约，不得把 `asset_reference`、区域财政或 G17 账户伪装成可交易市场。特殊事件默认打市场层端口；现有六个宏观 `ExogenousImpulseBundle` 端口继续保留且普通 Seed 全零，只有显式 opt-in 才写入宏观。

南欧、东南亚等地图区域只有在出现独立的上市、发行或货币制度**市场对象**时才允许从 RoW 拆出完整宏观机。禁止为了填满 14 区地图而复制 GDP 内核。

ADR-006 进一步取消四区与汇率；本 ADR 关于资本市场另建 owner、宏观六端口仅 opt-in 的部分仍然有效。

## 原因

四区已经提供资本市场需要的环境：增长、CPI、政策、曲线、FCI、HY、美元资金、USD/CNY、EUR/USD、JPY/USD，以及名义盈利与复利参考。再拆完整宏观区域的成本是 G17 权重、RoW 恒等式、Viewer 和 700 Seed，却几乎不增加发行、流动性或可交易价格对象。

把特殊事件默认打进 GDP/通胀/政策，会再次做成小型危机宏观机，一二级对象仍然没有 owner。旧 `capital_market_lab` 的 14 区全链证明了这条路走不通。

## 后果

- 当前单一全球运行、8783和普通 Seed 行为不因未来资本市场设计而改变。
- 资本市场最小契约 `capital_market_minimum_v1` 先冻结字段与端口，不注册、不进入 `run_global_macro`。
- 市场层若反馈宏观，只能走已有一年滞后 `NextYearInputs`，禁止同年回写 GDP。
- 未来层顺序改为：资本市场 owner → 市场事件端口 → 少数宏观事件 opt-in → 国运 / 称号世界。

## 未包含

本 ADR 不实现簿记、做市商、可交易指数或 Viewer 市场 Scope。它只冻结产品边界。
