# 全球普通周期模型 v0.8.1

> 状态：已实装并通过冻结前校准、独立验证与留出验证  
> 模型身份：`asset-simulation-global-macro-v0.8.1`  
> 权威范围：无命名特殊事件的全球普通周期机制与冻结校准  
> 代码 owner：`model/real_economy.py`、`model/impulses.py`  
> 最近核对：2026-08-25

## 1. 模型目的

普通周期让全球基座在没有金融危机、疫情或战争时仍然具有自然的扩张、晚周期、收缩与修复。它不是事件生成器，也不改变潜在 GDP 的长期所有权；它只负责围绕慢趋势形成持续数年的需求周期，并把周期通过既有年度主链传给通胀、政策、曲线、资金、信用、能源和资产参考。

当前原油期货与四机构投资决策竞技都只读这一已结账普通世界。玩家、AI、预测、策略、风控和交易结果不能反向改变普通周期；普通 Seed 也不会因为进入游戏页而自动获得战争、禁运或金融危机。

```text
潜在 GDP 慢趋势
→ 普通周期水平与动量
→ 实际 GDP / 产出缺口
→ 通胀 → 政策与曲线 → 美元、资金与信用
→ 石油、商品与资产参考
→ 下一年具名反馈
```

同年主链按箭头单向前馈；任何返回上游的潜在反馈仍然滞后一年，资产市场不能在同一年反写 GDP。

## 2. 持续状态与阶段

实际经济内部新增两个持续状态：

| 状态 | 含义 | 边界 |
|---|---|---:|
| `ordinary_cycle_index` | 普通需求周期水平 | `[-4, 4]` |
| `ordinary_cycle_momentum_index` | 周期增强或减弱的动量 | `[-3, 3]` |

周期采用带动量和均值回拉的二阶结构。上一年真实政策缺口、HY 相对中枢、资金流动性和能源成本进入周期 forcing；新地址 `ordinary_cycle` 提供普通创新。正的信用条件也可以支持下一年需求，因此 HY 使用相对 420bp 的对称缺口，不只计算紧缩拖累。

阶段由水平和动量派生：

- `recovery`：周期仍弱，但动量已经转正；
- `expansion`：周期与动量均偏强；
- `late_cycle`：周期仍强，但动量已经转弱；
- `contraction`：周期与动量均偏弱；
- `neutral`：水平和动量都位于小死区。

阶段只用于解释和未来事件路由，不回写方程。

## 3. 下游响应

- 产出缺口将普通周期转换为实际 GDP 相对潜在 GDP 的偏离；
- 产出缺口进入核心通胀，通胀预期仍保持慢锚定；
- 政策率根据通胀、预期和产出缺口渐进调整；
- 2Y 主要反映政策预期，10Y 等于长期短率预期加期限溢价；v0.2 缩短了长端与期限溢价的过度惯性，使普通倒挂和债券负年份可以自然出现；
- 融资压力、信用可得性、违约压力、IG/HY 与 FCI 继续响应真实政策、增长和流动性；
- 石油需求读取本年真实经济，油价和商品只通过下一年正式输入影响通胀；
- 资产共同参考读取盈利、折现率、信用与能源结果。权益资本化保留价格／估值中枢语义；权益与主权债另发布可比较的含现金收益复投总回报参考，但仍不冒充可交易指数。

## 4. 特殊事件端口

`ExogenousImpulseBundle` 为未来事件层冻结六个具名端口：

| 端口 | 消费 owner | 单位 |
|---|---|---|
| `demand_growth_impulse_pp` | `real_economy` | 百分点 |
| `potential_growth_impulse_pp` | `real_economy` | 百分点 |
| `inflation_impulse_pp` | `inflation_nominal` | 百分点 |
| `dollar_funding_impulse_index` | `funding_credit` | 指数点 |
| `credit_spread_impulse_bps` | `funding_credit` | 基点 |
| `oil_supply_growth_impulse_pp` | `oil_commodity` | 百分点 |

普通产品入口 `run_global_macro()` 每年只能生成全零 bundle。显式开发入口 `run_global_macro_with_impulses()` 用于验证未来事件接线；8783 服务不暴露事件参数。Bundle 校验 Seed、目标年度、有限值、未知字段、owner 和单位，事件不能通过 Seed 名称偷偷进入普通世界。

## 5. 跨 Seed 校准结果

每个 Seed 运行 60 个转移年；Seed `0–399`、`400–499`、`500–699` 仍分别保留为校准、验证和留出分段。Goal A 完成后的 0–699 聚合审计为：

| 指标 | v0.6 结果 |
|---|---:|
| 平均实际增长 | 2.352% |
| 增长 5%–95% | 0.678%–4.047% |
| 负增长年度 | 0.886% |
| 10Y–2Y 倒挂年度 | 22.90% |
| headline 均值／年变化标准差 | 2.198%／0.352pp |
| 10Y 年变化标准差 | 0.309pp |

联合方向在 Seed `0–699` 上保持清楚：

- 周期水平与本年增长正相关；
- 产出缺口与通胀正相关；
- 通胀与政策率正相关；
- 真实政策缺口与下一年增长负相关；
- 实际增长与权益资本化参考增长正相关；
- 10Y 收益率变化与主权债财富参考回报强负相关。

v0.4 收口价格和购买力口径；v0.5 不改变普通周期所有权与随机地址，进一步修正能源反馈口径：

- 企业盈利等于名义 GDP 路径乘慢变利润份额，不再只吸收部分 CPI；
- 权益总回报等于名义资本化价格变化加按上一期价格计算的股息率，工程锚采用 `40%` 盈利派息率；
- Brent 与综合商品都先形成实际供需价格，再乘累计 CPI 生成当年名义价格；
- 实际商品变化负责下一年通胀传导，防止一般 CPI 被商品通胀重复计价；
- 能源成本压力改由实际石油和实际商品同比形成，避免一般 CPI 经能源压力再次进入下一年真实需求；
- `NextYearInputs` 只发布实际石油／商品同比，不再携带无人消费的名义同比；
- 权益和主权债同时保留名义总回报与扣除 CPI 的实际财富，Viewer 主图只展示名义值。

v0.6 不改变 GDP 周期 owner，但在价格与利率链上增加了可审计的普通波动：

- `inflation_supply_pressure_index` 把实际能源、商品和不可观测供给变化转成 2–4 年衰减的共同压力；
- headline/core 降低过强惯性，预期在持续偏差后部分移动、随后回归目标；
- 全球政策在小偏差时暂停，在偏差持续时形成行动阶段；
- 2Y 更快读取政策路径，10Y 由长期短率预期和期限溢价共同重定价；
- 仍保留显式事件通胀端口，普通尾部不取代疫情、战争或金融危机设计。

0–699 共 700 个 Seed、每个 60 年中，全球 headline 均值为 2.21%，年度变化标准差为 0.35pp；高于 4% 和低于 0% 的年份分别约 0.69%–0.77% 和 0.11%–0.18%。全球 10Y 年度变化标准差约 0.31pp。所有结果来自普通内生链条，没有启用命名事件端口。当前全球门禁见 `docs/current/MODEL_QUALITY_AUDIT.md`。

v0.7 不改变普通周期状态机。潜在增速对生产率残差的放大从 1.0 降到 0.35，避免 `[1.25, 3.4]` 成为近积分夹具；IG/HY 对锚的回复从 0.18 提到 0.22，减轻平静扩张期贴下沿。产出缺口公式与轨道保持不变，作为有意的周期夹具。最新三段统计见 `docs/current/MODEL_QUALITY_AUDIT.md`。

v0.8 保持普通 Seed 不绑定危机事件，调整石油常态路径：库存紧张度持久系数由 0.72 降至 0.60，价格对库存的系数由 0.22 降至 0.16，实际价格均值回复由 0.045 提至 0.060，并加入独立的年度常态油价扰动。目标是把普通世界的实际油价年度波动放在约 8%–10%，同时避免旧版过强的连续多年单向趋势。

v0.8.1 在不生成命名危机的前提下增加两个石油持续状态：`oil_return_momentum_pct` 表示有限持续的年度趋势，`oil_volatility_regime_index` 围绕 1.0 对称变化并共同控制年度包络、月线和周线。实际油价越过过程边界时使用有阻尼的对数反射，不再连续钳在同一底价。常态多 Seed 校准把年度收盘绝对对数变化中位数提高到约 9%，年内振幅中位数约 38%–40%；危机尾部仍留给显式事件端口。

## 6. 产品表现与限制

8783 不新增重复的顶级周期面板。现有增长图继续展示实际增长、潜在增长和产出缺口；右侧年度明细增加普通周期阶段、水平和动量。Viewer 不展示跨 Seed 百分位。

全球普通周期是默认产品的全部宏观内核。没有正式区域、G17 或汇率层。

普通 Seed 内核仍不包括：

- 命名危机、疫情、战争或供给禁运；
- 普通国运分化和称号级世界；
- 事件概率、持续时间、传播图或恢复政策；
- 可交易资产市场的高频波动和恐慌定价；
- 双边汇率或分区宏观机。

这些内容必须在独立 owner 中实现，不能重新塞入普通 Seed 内核。质量门禁见 `docs/current/MODEL_QUALITY_AUDIT.md`。
