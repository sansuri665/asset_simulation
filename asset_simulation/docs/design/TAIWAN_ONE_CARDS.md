## 位置

全球银行营收饼拉通。`hk_macao_taiwan` 只是归属标签，对齐 Viewer 个股页区域下拉。组团 `taiwan_1`（台湾）不是分区宏观机，也不出现在区域下拉。不做台湾二，也不新开 Viewer 区域。

台湾是封闭结构切片：本地特许权加少量国际收入，不写回同年全球。北美／中国大陆／西欧北欧路径不经过这里。

富邦香港留给本张台北富邦皮，不另做香港皮肤。华侨永亨仍留给星洲。台湾银行、土银、输银、渣打台湾不进。王道／高雄体量会逼出第二组，本轮不做。京城质量小票可选，为压在十家而放下。

中国信托 id 是 `ctbc`，不能用 `citic`（中信）。上海商银 id 是 `scsb`，不能用 `shcb`（香港上海商业）也不能用 `shb`（上海银行）。台湾 SCSB 是香港上海商业的股东：两张上市皮，饼上不扣子公司。

## 营收锚（2024）

公式仍是 `2.0% × 人民币营收 / 8218`。工行中枢锁 2.0%，分母 8218 亿不变。美元用国家统计局 2024 年均 **7.1217 人民币/美元**；新台币按联储 G.5A / FRED AEXTAUS 2024 年均 **32.1064 新台币/美元**，折 **0.22182 人民币/新台币**（算法与港元 0.9127 相同）。默认两位小数；小于 0.1% 用三位。

营收口径是银行净收益／operating income，不是金控合并利润，也不是毛利息收入。金管会利息收入表（例如中国信托约 3200 亿新台币）不能当饼。中国信托用银行年报净收益 **1540 亿新台币**；上海商银用母行净收益 **274.5 亿新台币**（并表含香港重叠，不用）。其余八家没有钉死年报净收益时，用 2024 税后利润按约 30%（彰化／台中商银用 28%）反推净收益，只作份额对照，卡片净利率仍是影子。

年报净利率只作对照，卡片用影子溢价。台湾现金股利可以很高；卡片压低，以免整本名录均值被带到 36% 软拉之上。信用成本、CET1、ROE 仍照抄工行会计，不进属性卡。绝对宏观系数按体量从恒生档缩放，不要把南京那种 gap 系数抄到这些票上。
