# 后续系统层次

> 状态：未来设计，不是当前运行事实  
> 权威范围：从原油竞技 Demo 到正式投资游戏的开发顺序和概念边界  
> 当前基线：全球 v0.8.1、原油四机构竞技 v0.1.0  
> 最近核对：2026-08-25

## 当前已经越过的阶段

以下内容不再是未来设想：

- 商品 overlay 与原油年／月／周路径；
- 01／05／09原油期货、期限结构、换月和全球流动性；
- 短期双合约预测；
- 策略研究、公司风控、交易部和全成本结算；
- 玩家与3家 AI 的随机任命、独立账户、排名和半月报告。

这些当前事实见 `docs/current/`。本文件只描述尚未完成的产品层。

## 建议顺序

```text
玩家任命与投委会额度
→ 正式账户、存档、保证金与强平
→ 报告归因和 UI 信息架构重做
→ 第二／第三种独立原油策略
→ 多品种组合与期现关系
→ 独立资本市场 owner
→ 市场事件端口
→ 少数宏观事件 opt-in
→ 普通国运与称号级世界
```

不要因为界面看起来简单就跳过账户和决策 owner，也不要为扩品种恢复旧四区、汇率或 G17。

## 第一阶段：可操作投委会

最小玩家决策不是自由拖蛛网，而是从 Seed 候选中进行有限选择：

- 任命预测、策略研究、公司 CRO 和交易执行负责人；
- 批准原油总额度、单策略额度、最大回撤和最大保证金；
- 冻结决定至下一次正式调整窗口；
- AI 使用相同候选和审批规则；
- 回合报告解释“谁提出、谁裁剪、谁执行、结果如何”。

LLM 未来可以把自然语言意图转换为候选策略或额度草案，但必须由结构化契约校验并由玩家最终批准。LLM 不能直接写市场、账户或绕过风控。

## 第二阶段：正式账户与存档

需要独立 owner 管理：

- 现金、权益、保证金冻结和可用资金；
- 持仓、未完成调仓、追保、强平和到期结算；
- 人员任命、投委会授权和变更历史；
- 回合报告、年度快照和存档版本迁移；
- 长距离推进、取消、错误恢复和重放校验。

当前浏览器回合位置加服务器进程缓存只适合 Demo，不能承担正式账户。

## 第三阶段：策略多样性

当前只有预测方向／区间位置策略。下一批独立 Alpha 应按利润来源区分：

1. 预测偏差逆向：交易实现价格相对旧预测的残差回归；
2. 期限结构相对价值：交易主力／下一主力实际价差和预测价差的收敛；
3. 后续才考虑跨品种、期现和事件策略。

换手、仓位、杠杆、期限偏好和执行紧迫度是策略覆盖层，不应伪装成新的 Alpha。

## 多品种与资本市场

多品种出现后，投资决策委员会才真正承担组合职责：预测机构与策略团队选择、品种额度、风险预算、相关性、止损、策略停用和交易权限。

资本市场必须另建 owner。`contracts/capital_market_minimum_v1.json` 仍未注册，不进入 `run_global_macro`：

- 一级对象：发行日历、簿记覆盖、新发 concession；
- 二级对象：价格标记、流动性、相对价值；
- 市场只读同年已结账全球环境；
- 市场行为不得同年重写 GDP、通胀或政策。

只有出现人民币债、欧元债、日元融资等独立制度市场对象时，才允许重新引入双边汇率。地图本身不是恢复区域宏观机的理由。

## 事件、国运和称号

市场事件优先打市场层端口，例如发行失败、评级下调、流动性冻结、做市商资产负债表收缩。少数真正改变实体经济、政策或石油供给的事件才允许显式写入六个宏观 impulse 端口。

普通国运是长期生产率、人口、信用、政策质量和资本积累的分化。称号级世界是更深的结构预设。两者都不能暗中混入普通 Seed，也不能绕过身份和版本契约。

## 接入约束

- 每一层先冻结 owner、身份、时序、单位、守恒和最小验收；
- 市场、账户、投委会、风控和 UI 状态不得共用一个无版本字典；
- 新层只能通过类型化端口进入现有 owner；
- 玩家与 AI 必须使用同一公开规则；
- 预测能力分不得直接变成仓位或收益加成；
- 任何市场反馈宏观只能走一年滞后 `NextYearInputs`；
- 禁止恢复旧 lab 的十轮联合求解、14区地图、YCC、危机 QE 或 G17 汇率清算。
