# 宏观波动结构现实化 v0.2 阶段路线

> 状态：Goal A（W1–W4）、Goal B（W5–W6）与 Goal C（W7–W8）已实施，待归档  
> Goal：保留现有稳态中枢、名义／实际口径和 G17 守恒，修正普通世界中过平的通胀、政策、收益率、汇率与资本流，并停止让 RoW 单独吸收大部分波动  
> 实施前基线：全球 v0.5、北美 v0.4、中国大陆 v0.1、G17/World v0.1、宏观 UI v4  
> 当前运行版本：全球 v0.6、北美 v0.6、中国大陆 v0.3、G17/World v0.2、宏观 UI v4.1  
> 最终运行版本：全球 v0.6、北美 v0.6、中国大陆 v0.3、G17/World v0.2、宏观 UI v4.1  
> 最近核对：2026-08-14  
> 边界：本路线完成前不接特殊事件、普通国运或称号级世界

## 1. 为什么需要这一阶段

当前模型已经完成三件重要的事情：长期中枢基本合理、实际／名义账户可以闭合、全球—区域—G17 使用同一个可复算世界。现在的主要问题不再是“缺少字段”，而是波动如何在系统内传播。

0–699 共 700 个 Seed、每个 60 年的审计显示：

| 指标 | 当前结果 | 主要问题 |
|---|---:|---|
| 全球实际增长 | 均值 2.35%，5%–95% 为 0.70%–4.02% | 中枢与普通幅度可保留 |
| 北美实际增长 | 均值 2.16%，5%–95% 为 0.66%–3.68% | 年度负增长仅 0.63% |
| 中国实际增长 | 均值 3.35%，5%–95% 为 1.67%–4.95% | 42,000 年中仅 2 个负增长年 |
| 全球／北美／中国通胀 | 均值约 2.21%／2.23%／2.00% | 无一次 >4%，无一次通缩 |
| 北美政策变化 | 年度标准差 23bp，最大 75bp | 调整周期过弱 |
| 中国政策变化 | 年度标准差 13bp，几乎年年微调 | 没有暂停与集中动作 |
| 北美／中国 10Y 变化 | 年度标准差 3.4bp／2.8bp | 严重低于可用市场尺度 |
| 北美／中国汇率变化 | 年度标准差 0.69%／0.55% | 缺少普通国际风险周期 |
| 北美／中国贸易变化 | 年度标准差约 0.07pp | 余额过度锚定 |
| 中国私人资本流 | 5%–95% 为 -0.07%～+0.35% GDP | 无法形成资本潮汐 |
| RoW 负增长 | 10.2% 的年份 | 全球与正式区域的不一致被倒入残差 |

这说明模型已经“稳态正确”，但还没有“波动结构正确”。本阶段不推翻现有架构，也不靠扩大独立白噪声解决问题；目标是让普通供需、政策反应、期限溢价、风险偏好和跨境账户形成有持续时间、有因果方向的温和波动。

## 2. 现实锚点与使用方式

现实资料只用于确定数量级和方向，不要求复刻某段历史：

- 世界银行的全球周期研究区分普通增长、全球下行与全球衰退，并显示衰退中通胀、利率、资本流和资产会共同变化：<https://documents1.worldbank.org/curated/en/185391583249079464/pdf/global-recessions.pdf>
- NBER 战后周期表明普通收缩并非只能由史诗事件触发：<https://www.nber.org/research/data/us-business-cycle-expansions-and-contractions>
- BLS 与中国国家统计局序列都包含高于 4% 的通胀和通缩年份：<https://www.bls.gov/opub/ted/2023/consumer-price-index-2022-in-review.htm>、<https://zjzd.stats.gov.cn/dcsj/ndsj/2016n/jmxfjgzsCPI/art/2017/art_a67dcc4c5b4a40daa45798d0800c8316.html>
- 美联储 1994 年等普通紧缩周期包含远大于 75bp 的年度政策变化：<https://www.federalreserve.gov/monetarypolicy/openmarket_archive.htm>
- BIS／美联储汇率序列和人民币历史表明，即使管理浮动货币也会出现数个百分点的年度调整：<https://www.bis.org/statistics/dataportal/exr.htm>、<https://fred.stlouisfed.org/data/EXCHUS>

本路线仍然是“普通平行世界”，因此不用 2020 疫情、2008 金融危机或货币危机作为普通分布中心。现实尾部只用于证明普通模型不能永远困在 1%–3% 通胀、±1% 汇率和几乎不动的长债收益率中。

## 3. 冻结不动的部分

以下内容不是本阶段问题来源，原则上保持：

1. 单一 `CoupledWorldRun`、统一世界缓存和四 Scope 投影。
2. 全球同年前馈与 G17 `t→t+1` 跨年时序。
3. 全球、北美、中国大陆、RoW 的实际／名义 GDP 恒等式。
4. 本地 GDP 使用本币，跨区域才换共同美元。
5. G17 贸易、资本、货币篮子和国际收支守恒。
6. 普通 Seed 不绑定命名危机；特殊事件六端口继续为零。
7. 当前 GDP 长期中枢：全球约 2.1%–2.6%、北美约 1.8%–2.5%、中国约 2.8%–3.8%。
8. CPI 60 年累计、名义 GDP 与实际 GDP 的复利关系。

任何阶段若为了增加波动破坏以上恒等式、确定性或前缀一致性，应回退公式设计，不得用结果截断器遮盖。

## 4. 统一设计原则

### 4.1 普通波动不是特殊事件

允许普通世界出现：温和衰退、供给压力、通缩、阶段性高通胀、集中加息／降息、期限溢价再定价和资本撤退。这些是现有周期、能源、信用和风险变量的内生结果，不需要命名，也不写入事件身份。

### 4.2 不新增庞大的“周期状态机”

优先重用：

- `ordinary_cycle_index / momentum`
- `output_gap_pct`
- 实际能源变化与能源成本压力
- 通胀预期误差
- 政策缺口与政策变化
- HY、FCI、资金压力和风险偏好
- 久期供给、储备需求和资本流

确有必要时最多新增少量带 owner 的持久性普通冲量；不得增加一套与现有普通周期并行的宏观世界状态。

### 4.3 波动必须有共同来源

收益率、汇率和资本流不能分别靠独立随机数变热。一个普通风险收缩应能产生可追踪链条：

```text
增长／通胀预期变化
→ 政策路径与期限溢价重估
→ 资金、信用与风险偏好变化
→ 资本流与货币变化
→ 下一年区域外需、融资和进口通胀
```

地址化随机项只触发或扰动这一链条，不承担全部经济解释。

### 4.4 边界不是目标

各项安全 bounds 继续防止数值崩溃，但验收要求统计分布远离边界。不得通过频繁撞上下限制造通胀尾部、汇率危机或收益率周期。

## 5. W1：建立波动审计合同

在改公式前先把这次审计转成独立的统计工具或测试辅助函数，输出：

- 水平的均值、标准差、5%／50%／95%、极值；
- 年度变化分布；
- 高通胀、通缩、负增长、政策暂停和收益率倒挂频率；
- 连续状态的持续时间；
- 区域与全球的周期相关性；
- 汇率、资本流、实际利差和 FCI 的方向相关；
- RoW 承担的增长方差比例；
- 所有 bounds 命中率。

这不是新增大量常驻单元测试。审计脚本用于最后三段 Seed 校准；常规测试只保留确定性、恒等式和关键方向性。

完成判定：当前基线可以一条命令复现，且结果不依赖 Viewer 或服务缓存。

## 6. W2：通胀普通尾部 v0.2

### 6.1 修改方向

- 降低 headline/core 对上期值的过强黏性，但保留预期锚。
- 提高实际能源变化、食品能源缺口和产出缺口在普通周期中的有效传导。
- 让供给压力具有 2–4 年衰减，而不是单年白噪声。
- 允许通胀预期在持续偏差后部分脱锚，再缓慢回归。
- 全球形成共同供给环境；北美和中国按本地能源暴露、工资、汇率和制度系数投影，不独立制造三个互不相关的通胀世界。
- 保留 CPI 与 GDP 平减指数独立但相关的结构，禁止直接用 CPI 代替平减指数。

### 6.2 初步验收区间

在普通 0–699 Seed 中：

- 全球／北美平均通胀仍约 1.8%–2.7%，中国约 1.3%–2.7%。
- 年度通胀变化标准差由当前约 0.2pp 提高到约 0.35–0.70pp。
- >4% 的年份占比初步为 0.5%–5%，不能仍为零。
- 通缩年份占比初步为 0.2%–2%，主要来自需求收缩或能源回落。
- 普通世界可偶见 5%–6% 通胀，但不频繁出现 8%以上事件型结果。
- 高／低通胀通常持续 1–3 年，不能只是孤立尖点或边界贴线。

## 7. W3：政策反应与行动阶段 v0.2

### 7.1 北美

- 保留 25bp 网格。
- 建立小型不行动区：目标偏差很小时保持利率。
- 偏差持续扩大时允许连续 25／50bp 动作，必要时年度累计达到 150–250bp。
- 降息速度可在衰退、信用急剧收紧时快于常态加息。
- 不把同年资产回报作为政策 owner。

### 7.2 中国大陆

- 继续使用代表性政策率，不复制 25bp 网格。
- 用阈值和行动阶段代替“每年十几个基点微调”。
- 小于 5bp 的变化视为政策暂停；普通运行应出现成段暂停。
- RRR、政策流动性与价格工具分工：数量工具先缓冲信用／流动性，持续的通胀或需求偏差才推动政策率。

### 7.3 初步验收

- 北美约 25%–60% 年份保持不变，动作年主要为 25／50bp，普通极值允许 150–250bp 年度累计。
- 中国约 20%–55% 年份为实质暂停；行动年不再都是同一量级的微调。
- 通胀偏离、产出缺口和信用收缩方向性通过。
- 政策动作具备阶段持续性，但不会在目标附近每年正负反复。

## 8. W4：区域收益率曲线 v0.2

这是本阶段最严重、但必须在通胀与政策之后校准的部分。

### 8.1 2Y

- 主要读取当前政策、未来 1–2 年政策方向和短期风险溢价。
- 对政策行动的反应快于 10Y。
- 政策暂停时仍可因预期变化先行再定价。

### 8.2 10Y

保持“政策预期＋期限溢价”结构，但增强：

- 中长期通胀预期与预期误差；
- 普通风险偏好／避险需求；
- 国债净发行、私人久期供给和债务可持续压力；
- QE/QT 或准备金管理的实际方向影响；
- G17 储备货币需求和资本流；
- 独立但持久、幅度受限的期限溢价创新。

10Y 不直接复制全球 10Y，但北美、中国的波动不应低于全球的十分之一。

### 8.3 初步验收

- 北美 10Y 年度变化标准差约 0.30–0.70pp，中国约 0.25–0.60pp。
- 普通 5%–95% 年度变化大致落在 ±0.5–1.2pp，而不是当前 ±0.05pp。
- 2Y 对政策冲击的弹性显著高于 10Y。
- 通胀预期、久期供给、储备需求和避险冲击分别有方向测试。
- 倒挂、熊陡、牛陡都能在普通 Seed 出现，但不绑定命名事件。
- 债券总回报随曲线重定价自然增加波动，不单独增加债券随机噪声。

## 9. W5：G17 汇率、贸易与资本潮汐 v0.2

### 9.1 汇率

- 保留共同篮子加权 log 守恒与管理浮动差异。
- 减弱过强的逐年均值回复，允许基本面偏差积累 2–5 年。
- 加入共同风险偏好：全球风险收缩通常支持美元、削弱风险货币，并通过资本流而不是硬编码区域名称传导。
- 汇率仍由增长、实际利差、通胀、贸易、资本和储备需求共同决定；提高波动不能只放大 `g17_fx` 随机项。

### 9.2 贸易

- 保留北美负余额、中国正余额的普通中枢，但提高对伙伴需求、实际汇率和能源贸易条件的响应。
- 贸易账户水平继续持久；给区域的仍是余额变化脉冲，避免重复把余额水平加进 GDP。
- 不强迫每个 Seed 保持固定贸易角色；长期反转留给国运／称号世界，本阶段只允许中枢附近的周期变化。

### 9.3 资本

- 资本流读取实际利差、增长差、FCI、HY、全球风险偏好和汇率预期。
- 建立流入持续、拥挤减弱和风险撤退的普通阶段。
- 中国资本开放度继续低于北美；管理项可以缓冲，但不能把每次压力都吸收为零。

### 9.4 初步验收

- 北美汇率年度变化标准差约 1.5%–3.5%，中国约 1.0%–2.8%。
- 中国普通年度变化多数在 ±4% 内，允许少量约 5%–6% 调整；边界命中率接近零。
- 北美／中国贸易余额年度变化标准差由约 0.07pp 提高到约 0.20–0.60pp。
- 私人净资本流多数年份在 ±2% GDP 内，风险撤退尾部可以接近 ±3%，不模拟危机型突然停止。
- 风险收缩、实际利差上升、增长改善和储备需求增强分别有方向性测试。
- 贸易、资本、国际收支和货币篮子残差继续 `<1e-8`。

## 10. W6：RoW 波动分配收口

RoW 继续是会计残差，不在本阶段建设完整第三类政策模型。但正式区域必须更充分继承全球共同周期，避免全球波动几乎全部压到 RoW。

修改顺序：

1. 检查北美、中国对全球普通周期、能源和金融条件的 beta。
2. 检查全球与区域初始实际／名义权重。
3. 调整区域共同因子暴露，使加权区域增长能够解释全球的大部分普通波动。
4. 最后才调本地独立创新，不能直接截断 RoW 增长。

验收：

- RoW 实际／名义 GDP 始终为正，全球加总残差 `<1e-8`。
- RoW 不再成为唯一的衰退承担者；其负增长频率不得长期达到正式区域加权频率的数十倍。
- RoW 增长 5%–95% 与全球普通周期同阶，不出现长期系统性反向。
- 新增区域前仍保留 RoW 的合理多样性，不追求与全球完全同线。

### Goal B 实施结果（2026-08-14）

W5–W6 已完成。G17 v0.2 新增单一持久国际风险周期，由全球增长缺口、FCI、HY、美元资金和风险偏好驱动；它同时进入资本、汇率和储备需求，不再让三类市场量各自靠独立白噪声变热。贸易仍发布余额变化脉冲，资本和货币仍使用原五端口与 `t→t+1` 时序。

0–699 共 700 个 Seed、每个 60 年的最终结果：

| 指标 | 北美 | 中国大陆 |
|---|---:|---:|
| 汇率年度变化标准差 | 1.50% | 1.24% |
| 汇率年度变化 5%–95% | -2.57%～+2.39% | -1.90%～+2.16% |
| 贸易余额年度变化标准差 | 0.201pp | 0.205pp |
| 私人资本流 5%–95% GDP | -1.96%～+1.65% | -1.17%～+1.77% |

国际风险周期均值 0.003、标准差 1.30；RoW 在三地区未加权增长方差中的占比由约 55.1% 降至约 42.8%。全球与北美、中国、RoW 增长相关约 0.88、0.83、0.89。贸易与资本残差为零，货币篮子最大残差 `4.9e-9`；所有 700 个世界运行成功。Viewer 的内部 Scope 仍为 `g17_lite`，面向用户的显示名已改为“国际”。

## 11. W7：过度设计收口与 Viewer 语义

> Goal C 的独立执行细则、界面文案、国际总览坐标、三段 Seed 门禁和 Grok 异议规则见 `MACRO_VOLATILITY_REALISM_GOAL_C_PLAN.md`。本节只保留总路线摘要。

本阶段不大规模删除已经存在的字段，而是按用途分级：

### Core

GDP、通胀、政策、2Y/10Y、FCI、信用、能源、货币、贸易、资本、公共债务。

### Derived

实际政策率、期限利差、实际 10Y、平减指数、实际资产财富、国际收支残差等纯派生量。派生字段不拥有随机项。

### Reserved

TGA、逆回购、MBS、准备金目标、QE/QT、细分期限份额和部分中国数量工具。这些保留给特殊事件、央行和行业层，但本阶段不逐项追求现实波动。

界面调整原则：

- 默认页面突出 Core；Reserved 留在公共账户／专业模式。
- 区域“权益总回报”改为“权益复利参考”或“宏观资产中枢”，避免被理解成真实股票市场收益。
- 实际财富、PE、ERP、利润份额等保留在资产参考明细，不扩张为更多同级模块。
- 不显示跨 Seed 百分位、版本解释和开发状态。

## 12. W8：统一校准与最终验收

> Goal C 的可执行命令、分段阈值、跨段漂移规则、交付报告与最终页面验收见 `MACRO_VOLATILITY_REALISM_GOAL_C_PLAN.md`。

阶段之间只做单 Seed 冒烟和直接方向检查；完整测试集中在所有公式完成后。

### Seed 分段

- 校准集：0–399。
- 验证集：400–499。
- 留出集：500–699。

三段必须同时满足目标；不得看到留出集后继续改参数而不重新定义校准流程。

### 必过项目

1. World、全球、北美、中国、G17 的确定性和前缀一致。
2. 全球及区域实际／名义 GDP 恒等式。
3. G17 贸易、资本、国际收支与货币篮子守恒。
4. 无 NaN／Infinity，bounds 命中率接近零。
5. 通胀、政策、曲线、资本、汇率的方向性。
6. 三段 Seed 的均值、波动、尾部和持续期不存在明显漂移。
7. 真实页面四 Scope、pointer 年份、单位和控制台检查。
8. 25 项现有测试及新增必要测试通过，避免把统计报告全部塞进日常测试套件。

## 13. 明确不做

- 不加入疫情、战争、金融危机或具名货币危机。
- 不接普通国运或称号级世界。
- 不把权益参考改造成完整交易市场；真实市场波动属于后续资产／行业层。
- 不新增国家级贸易矩阵、逐行业资本流或高频外汇市场。
- 不删除 G17 守恒、CNY 本地口径或单一 World 架构。
- 不为 TGA、MBS、QE/QT 等 Reserved 字段单独制造随机波动。
- 不使用“把所有噪声乘大”作为完成方案。
