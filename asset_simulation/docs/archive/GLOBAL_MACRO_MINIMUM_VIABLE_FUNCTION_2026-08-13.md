# 全球宏观最小可用功能合同（资产模拟版）

> 状态：历史归档，不是当前实现权威  
> 日期：2026-08-13  
> 实现目录：`airport/asset_simulation`  
> 适用范围：普通年度世界、单一 Seed、资本市场与区域宏观共同输入  
> 不包含：命名特殊事件、G17 跨区域清算、G13 普通国运、称号级世界

本文件保留新目录重建时的完整推演和旧实施路线，其中部分调用顺序、文件名和实施状态已经过时。当前事实请改读 [`../current/RUNTIME_ARCHITECTURE.md`](../current/RUNTIME_ARCHITECTURE.md) 与 [`../current/CONTRACTS_AND_UNITS.md`](../current/CONTRACTS_AND_UNITS.md)；未来层次请读 [`../design/FUTURE_LAYERS.md`](../design/FUTURE_LAYERS.md)。

## 1. 目标与结论

当前全球宏观主链已经覆盖资本市场需要的主要经济机制，问题不是“缺少更多模块”，而是模型内部字段很多、资本市场消费者可以直接读取的字段过宽，尚未形成稳定的最小公共合同。

本文件的目标是：

1. 盘点现有全球宏观主链实际拥有什么；
2. 定义资本市场必须读取的少数全球共同因子；
3. 把名义账户、通胀分项、石油物理库存等保留为支持性状态，而不是每个行业的必选输入；
4. 明确财政、主权债务、央行数量账户和本币汇率等应由区域拥有；
5. 为后续“完成一个新区域后立即接入既有区域并联合调整”的开发方式提供统一接口。

本文件最初同时比较“旧内核增加只读薄投影”和“新目录重建”两条路线。当前已经选择并实现新目录路线：旧 Capital Market Lab 保留为只读参照，新 Asset Simulation 使用独立状态容器、参数、随机流、API 和 Viewer，不导入旧模型运行时。

最小可用不等于只保留 GDP 和 CPI。对于资本市场，至少还必须知道折现率、信用、资金、汇率和能源成本，否则股票、债券、银行、保险与商品资产只能靠彼此无关的随机数运行。

## 2. 当前全球主链摸排

当前 `runner.py::_run_global_downstream_annual()` 的正式年度顺序为：

```text
GDPBase 与普通周期
→ 全球通胀
→ GDP 平减指数与名义账户
→ 全球政策利率
→ 全球收益率曲线
→ 广义美元、美元融资压力与上游流动性
→ 全球信用条件与 IG/HY OAS
→ 全球资产参考中枢、风险偏好与综合 FCI
→ 全球石油与轻量商品族
→ 下一年通胀及其它具名滞后接口
```

通胀在第 `t` 年只消费第 `t-1` 年已经结账的美元和商品输入；主链没有同年第二遍回算。GDPBase 已包含水平＋动量的普通周期，不接受当年资本市场回写。Seed 只固定普通随机路径，不绑定金融危机、疫情或其它命名事件。正式机制与校准结果见 [`../components/GLOBAL_ORDINARY_CYCLE.md`](../components/GLOBAL_ORDINARY_CYCLE.md)。

| 当前组件 | 当前主要所有权 | 对最小合同的处理 |
|---|---|---|
| GDPBase | 实际 GDP、潜在增长、产出缺口 | 核心输入，保留 |
| 全球通胀 | headline、core、预期及消费篮子分项 | headline/core/预期进入核心；分项保留在内部 |
| GDP 平减指数与名义账户 | 平减指数、名义 GDP、名义增长 | 支持性账户；用于金额和规模，不作为独立冲击 |
| 全球政策利率 | 合成政策率、真实政策率、中性真实利率 | 核心输入，保留 |
| 全球收益率曲线 | 2Y、10Y、期限溢价、实际 10Y | 核心输入，保留 |
| 美元与资金流动性 | 广义美元、美元融资压力、信用前流动性 | 核心输入，保留 |
| 全球信用 | IG/HY OAS、信用可得性、违约和银行压力 | 核心输入，压缩字段 |
| 全球资产参考中枢 | 盈利、估值、资本化、财富、风险偏好、FCI | 资本市场共同输出，不是宏观原始驱动 |
| 石油与商品 | 供需库存、实际/名义 Brent、商品族、能源成本 | 价格与成本进入核心；物理明细留在内部 |

### 2.1 已经做得好的部分

- 实际、价格和名义账户已经分开，名义 GDP 不再由 CPI 直接冒充；
- 政策率、2Y/10Y、期限溢价和信用 OAS 的语义已经区分；
- 美元相对价值、美元融资压力和上游资金流动性不是同一个指数；
- Brent 已是 CPI 折算后的名义美元价格，石油物理存量与价格形成有明确会计；
- 资产参考中枢明确是盈利—估值—复利的共同锚，不冒充可交易指数收益预测；
- 年度所有权和滞后关系清楚，没有隐藏同年固定点循环；
- 同 Seed 可复算、短路径是长路径前缀，普通 Seed 不携带命名事件。

### 2.2 当前最值得收口的问题

1. 完整年度行包含大量诊断、贡献、边界和会计字段，消费者缺少一个明确的“小接口”。
2. `financial_stress_index` 是 GDP 后、通胀前的普通压力桥；`global_financial_conditions_index` 则由资产参考中枢在信用和市场状态之后发布。二者时点和所有者不同，但部分旧区域模板会同时读取，未来容易重复计价。
3. 资产参考位于同一 Runner 主链中，容易被误认为全球宏观原始状态；实际上它应被视为宏观与信用形成后的资本市场共同输出。
4. 全球美元的相对增长、相对通胀和相对政策仍有合成占位成分。正式双边汇率、贸易和资本流要等 G17 统一清算，不能由单一区域私自补齐。
5. 全球收益率曲线有意不虚构全球财政赤字、全球国债发行或全球央行 QT；这些数量账户必须由区域财政部、主权债务和区域央行拥有。

## 3. 最小可用功能

资本市场最小底座必须回答七组问题。

| 因子族 | 必须回答的问题 | 主要资本市场用途 |
|---|---|---|
| 实际增长 | 经济增长多快，位于潜在水平上方还是下方 | 盈利、违约、信贷需求、商品需求 |
| 通胀 | 当前通胀、基础通胀和中长期预期是多少 | 名义收入、政策反应、利率和利润率 |
| 政策 | 货币政策是宽松、中性还是紧缩 | 短端资金成本、银行息差、估值折现 |
| 收益率曲线 | 市场怎样定价未来政策和期限风险 | 国债、保险、银行、久期与股票估值 |
| 货币与资金 | 美元在升值还是贬值，融资是否紧张 | 跨境资金、外币债、流动性与换算效应 |
| 信用 | 企业融资是否可得，信用补偿和违约风险多高 | 银行、公司债、信用损失和风险资产 |
| 能源与商品 | 关键投入价格和贸易条件压力怎样变化 | 通胀、工业成本、资源行业与消费能力 |

资产参考中枢是这七组状态形成后的共同市场输出。财政、主权债务和央行数量账户是区域层对收益率、流动性与主权风险的必要补充，不应伪造为全球统一账户。

## 4. 全球最小公共字段合同

以下字段组成 `global_macro_minimum_v3`。这是对现有年度行的只读投影，不产生新随机数。

### 4.1 A 级：资本市场必需输入

| 因子族 | 权威字段 | 说明 |
|---|---|---|
| 实际增长 | `global_gdp_trillion_usd` | 2025 年不变价实际 GDP；用于经济规模和真实活动水平 |
| 实际增长 | `realized_growth_pct` | 实际 GDP 同比；t0 可为空，转移年必须有限 |
| 实际增长 | `potential_growth_pct` | 潜在增长；t0 可为空，转移年必须有限 |
| 实际增长 | `output_gap_pct` | 实际相对潜在的唯一权威缺口 |
| 通胀 | `headline_inflation_pct` | 居民消费篮子总体通胀 |
| 通胀 | `core_inflation_pct` | 去除高波动食品能源后的基础通胀 |
| 通胀 | `inflation_expectation_pct` | 当前工程口径的长期平均通胀预期 |
| 政策 | `global_policy_rate_pct` | 连续的合成全球政策率，不冒充单一央行会议动作 |
| 政策 | `real_policy_rate_pct` | 政策率减通胀预期后的真实政策率 |
| 政策 | `neutral_real_policy_rate_pct` | 判断紧缩或宽松的真实中性锚 |
| 曲线 | `global_2y_yield_pct` | 近端政策预期与短期限溢价 |
| 曲线 | `global_10y_yield_pct` | 长端名义折现率 |
| 曲线 | `term_premium_10y_pct` | 10Y 中非未来短端预期的期限补偿 |
| 曲线 | `global_real_10y_yield_pct` | 长期真实折现率近似 |
| 美元资金 | `global_dollar_index` | 基期 100 的合成广义美元相对价值 |
| 美元资金 | `dollar_yoy_change_pct` | 美元年度变化，供换算和进口价格传导 |
| 美元资金 | `dollar_funding_stress_index` | 美元批发和跨币种融资压力 |
| 美元资金 | `global_funding_liquidity_index` | 信用与资产定价前的上游资金便利度 |
| 信用 | `global_investment_grade_spread_bps` | 全球美元 IG OAS 参考 |
| 信用 | `global_high_yield_spread_bps` | 全球美元 HY OAS 参考 |
| 信用 | `credit_availability_index` | 融资是否容易获得，不是 OAS 的代数反函数 |
| 信用 | `default_risk_index` | 聚合企业违约压力 |
| 能源商品 | `brent_oil_price_usd` | 当年价名义 Brent |
| 能源商品 | `oil_yoy_change_pct` | 油价年度变化 |
| 能源商品 | `commodity_yoy_change_pct` | 能源、工业与食品聚合商品变化 |
| 能源商品 | `energy_cost_pressure_index` | 对企业和居民更直接的能源成本压力 |

消费者可以从权威字段派生以下便利量，但不得另建随机状态：

```text
真实政策缺口 = real_policy_rate_pct - neutral_real_policy_rate_pct
10Y-2Y 斜率 = global_10y_yield_pct - global_2y_yield_pct
```

现有 `term_spread_10y_2y_pct` 可继续发布并用于恒等式检查，但不是新增独立因子。

### 4.2 B 级：资本市场共同输出

以下字段由宏观、资金和信用状态生成。它们可供区域、行业或 Viewer 使用，但不能反向冒充 A 级原始输入：

| 类别 | 字段 |
|---|---|
| 综合市场状态 | `global_financial_conditions_index`、`risk_appetite_index` |
| 盈利共同锚 | `global_corporate_earnings_reference_growth_pct`；由名义 GDP 与慢变利润份额形成 |
| 估值共同锚 | `global_equity_valuation_center_pe`、`global_equity_risk_premium_center_pct` |
| 权益价格共同锚 | `global_equity_capitalization_reference_growth_pct` |
| 权益总回报共同锚 | `global_equity_dividend_yield_pct`、`global_equity_total_return_reference_growth_pct` |
| 固收共同锚 | `global_sovereign_bond_wealth_reference_growth_pct` |

这些输出用于给区域、行业和公司市场提供共同中枢。权益资本化是名义价格参考；权益总回报在其上加入按上一期价格计算并复投的股息，因而可与含票息的名义主权债财富参考比较。两者除以累计 CPI 后得到实际购买力支持状态。真正的可交易收益、波动、流动性折价、交易冲击和机构行为仍由更下游的市场层拥有。

### 4.3 C 级：保留的支持性账户

以下内容继续运行和保存，但不是每个资本市场消费者的强制输入：

- GDP 平减指数、平减指数价格水平、名义 GDP 和名义增长；
- 累计 CPI 价格水平，以及 food、energy、services、core goods、import cost、wage 等通胀分项；
- 政策反应贡献、方向、执行边界和 QE 占位诊断；
- 预期短端路径、2Y/10Y 分解贡献和曲线会计残差；
- 放贷标准、银行资产负债表压力、信用损伤存量及 IG/HY 会计分解；
- 石油需求、供给、产能、闲置产能、库存、实际油价和商品子指数；
- 各模块的模型身份、参数哈希、随机消费、边界命中和会计残差。

名义账户仍很重要：银行资产规模、财政金额、企业营收和市场市值需要名义分母。但它们属于规模换算和会计支持，不应与实际增长、通胀和估值因子重复计价。

## 5. 全球层不应拥有的账户

以下项目对资本市场很重要，但不能因为“重要”就放进全球统一模型：

| 项目 | 正确所有者 | 全球层可提供什么 |
|---|---|---|
| 财政赤字与初级余额 | 区域财政账户 | 区域结果完成后的加权诊断，不作为全球政府行为 |
| 主权债务存量 | 区域主权债务账户 | 全球风险环境与比较锚 |
| 国债净发行和期限结构 | 区域财政部/债务管理账户 | 公共期限溢价框架 |
| 央行资产负债表、准备金、QE/QT | 区域央行数量账户 | 全球资金环境，不虚构全球央行 |
| 主权风险溢价 | 区域公共收益率曲线 | 全球期限与风险基准 |
| 本币汇率和外汇储备 | 区域货币账户与 G17 | 广义美元共同因子 |
| 贸易、经常账户与资本流 | G17 共享清算层 | 全球活动、商品和资金共同环境 |

因此，“央行国债类”在最小系统中没有被删除，而是分为两层：全球提供政策、无风险曲线、美元与资金环境；区域提供财政、主权供给、央行数量和本币风险。

## 6. 区域最小扩展合同

每个完成的区域不必拥有完全相同的内部模块，但必须能够投影到同一组语义。区域可以因地制宜：北美强调市场化国债与 QE/QT，中国大陆强调银行、社融、中央/地方财政和政策工具，日韩可保留日本型债务与央行数量特征，东南亚可保留多制度组合。

在全球 A 级因子之外，成熟区域至少发布：

- 区域实际增长、潜在增长、产出缺口；
- 区域 headline、core、通胀预期；
- 区域政策率、真实政策率和中性真实利率；
- 区域 2Y、10Y、期限溢价和普通主权风险贡献；
- 财政余额/GDP、政府债务/GDP、净发行或私人市场久期供给压力；
- 央行资产/GDP、准备金或上游流动性，以及具名 QE/QT/常规数量操作方向；
- 本币相对价值、融资压力和资金流动性；
- IG/HY 或当地可用的等价信用压力、信用可得性和违约压力；
- 能源成本或贸易条件暴露；
- 区域最终 FCI 和风险偏好，作为后置市场输出。

如果某区域没有发达 HY 市场、没有典型 2Y 国债或采用汇率型政策，不应伪造相同制度；它只需通过明确的映射给出可比较的“短端政策条件、长期折现率、信用压力、货币资金条件”。内部指标可以不同，跨区域合同语义必须相同。

## 7. 年度因果与反馈规则

普通基座建议继续使用以下规则：

```text
第 t 年已结账的全球与区域状态
→ 第 t 年资本市场定价与支持账户
→ 发布具名的 t+1 宏观输入
→ 第 t+1 年 GDP、通胀、政策或信用消费者读取
```

规则如下：

1. 同年状态只生成一次，不为追求“闭环”隐藏重跑；
2. 每个反馈字段必须有唯一 owner、source year、target year 和单位；
3. 资产价格不能在同年同时影响 GDP，又被同年 GDP 反向定价；
4. 石油与商品可以读取本年全球需求和风险事实，但只能通过正式接口影响下一年通胀或真实活动；
5. 当前 `financial_stress_index` 暂留为内部预链桥，新的资本市场消费者不应直接依赖它；
6. 对外综合状态以资产后置的 `global_financial_conditions_index` 为准，细分消费者应优先读取其真正需要的资金、信用或利率组件，避免把 FCI 再叠加一遍；
7. 特殊事件以后通过独立事件接口注入，不改变普通 Seed 的随机历史。

## 8. 面向资本市场的使用规则

不同资产只读取与自己有关的因子，不能把全部字段无差别塞进一个总分。

| 消费者 | 最小输入组合 |
|---|---|
| 股票盈利 | 实际增长、产出缺口、通胀、美元、信用可得性、能源成本 |
| 股票估值 | 真实 10Y、期限溢价、ERP/信用、资金压力 |
| 国债 | 政策、2Y/10Y、期限溢价；区域模型另加发行、央行数量和主权风险 |
| 公司债 | 无风险曲线、IG/HY OAS、违约、信用可得性 |
| 银行 | 政策、曲线斜率、信用数量/质量、融资流动性 |
| 保险 | 长端利率、曲线、信用、通胀及资产负债久期 |
| 商品/能源 | 全球增长、美元、库存/供给支持状态、风险溢价 |
| 跨境资产 | 本地与全球增长/利差、汇率、融资压力；正式资本流等待 G17 |

这张映射也是未来削减重复随机因子的依据：能够由宏观现金流、折现率、信用和汇率解释的变化，不再额外加入同方向的独立大随机项。

## 9. 最小验收合同

建立投影层后，只需要一组小而稳定的主干测试：

1. **字段门禁**：A 级字段在转移年全部存在且有限；t0 的增长字段允许为空，水平字段必须存在。
2. **会计门禁**：实际 GDP、名义 GDP、CPI/平减指数、曲线分解、信用 OAS 和油价名义/实际口径继续由原 owner 验证。
3. **Seed 门禁**：同 Seed 可复算；短期限严格等于长期限前缀；普通 Seed 不绑定命名事件。
4. **时序门禁**：不得出现同年市场回写；下一年输入必须校验来源年和目标年。
5. **方向门禁**：通胀上升通常提高政策压力和名义收益率；真实政策偏紧、融资压力或 HY 扩张通常收紧信用；油价冲击通过滞后通道进入通胀。
6. **所有权门禁**：一个经济事实只有一个权威 owner；派生字段不得再次作为独立冲击计价。
7. **消费者冒烟**：股票、主权债、公司债、银行和区域投影各跑一个最小消费者，不在每次区域改动时重跑全部历史专项测试。

模块自身的冻结验证继续保留，但日常开发按“改动模块专项测试 + 最小合同测试 + 直接消费者冒烟”执行；只有修改共享合同、随机地址或跨层时序时才运行全链回归。

## 10. 推荐实施顺序

### M0：冻结薄合同（已完成）

把本文件中的 A/B/C 分层转成机器可读字段表，注明 owner、单位、t0 空值规则和来源版本。

### M1：只读投影（已完成）

增加 `build_global_macro_minimum_snapshot(row)` 一类纯函数，只挑选和派生字段，不重跑模型、不抽随机数、不改变结果哈希。API 可同时保留完整诊断行和轻量快照。

### M2：消费者迁移（资产参考已完成，行业与区域待后续）

逐步让行业和新区域读取最小快照。旧区域继续兼容，但登记其对 `financial_stress_index`、完整资产参考或通胀细项的直接读取，确认是否确有必要。

### M3：新区域即接即调（接口已冻结，尚未开始区域实现）

下一个区域不再先做成孤岛。每完成一个模块，就把它投影到区域最小合同，并与北美、中国大陆、西欧/北欧、日韩、东南亚和南亚已有状态运行联合冒烟；只调整共同接口和必要载荷，不反复推翻全球底座。

### M4：G17-lite（后置）

当至少两个正式货币区的最小合同稳定后，先接汇率、贸易和资本流的轻量共享清算。G17 只负责跨区域传导和守恒，不承担普通国运或称号级世界方向。

### M5：后续层次（后置）

顺序仍为：

```text
区域宏观最小合同
→ G17 跨区域对齐
→ 特殊事件
→ G13 普通国运分化
→ 称号级世界
```

## 11. 完成定义

达到以下状态即可称为“资本市场最小可用全球宏观”：

- 七组 A 级因子由唯一 owner 稳定发布；
- 股票、债券、银行、保险、信用和商品模型无需读取整张全球诊断行；
- 名义账户和详细分项仍可审计，但不会被下游重复计价；
- 全球层不虚构统一财政、统一国债发行或统一央行资产负债表；
- 不同区域内部设计可以不同，但都能映射到同一资本市场语义；
- 新区域完成后能够立即与既有区域进行联合冒烟和动态调整；
- 普通 Seed、特殊事件、普通国运和称号级世界保持四套互不混淆的身份；
- Viewer 只展示当前 Seed 的本世界信息，不展示跨 Seed 排名或百分位。

到这一步，模型就足以支持资本市场各行业的第一版。之后新增细项应由明确玩家行为或下游消费者驱动，而不是为了让宏观目录看起来更完整。

## 12. 新目录重建方案：资产市场专用全球内核

本方案已经在 `airport/asset_simulation` 落地，采用“复用经济关系、重做状态容器与执行框架”的方式。现有模型继续作为完整参照、机制资料库和结果对照组，新模型只承担资本市场环境生成职责。

这不是把当前目录完整复制后机械删除字段。新内核应从最小状态合同出发，选择性移植已经验证过的经济关系，并避免继承当前约 795 字段的平面年度行。

### 12.1 建议保留的六个组件

#### 12.1.1 实际经济

正式保留：

- 实际 GDP 水平；
- 实际 GDP 增长率；
- 潜在增长率；
- 产出缺口。

内部增长结构压缩为：

```text
长期潜在增长
+ 普通需求周期
+ 小幅普通扰动
```

劳动、生产率和资本深化仍可用于形成潜在增长，但不必全部成为每年向下游公开的持续状态。新模型可以复用 GDPBase 已经验证过的增长、缺口、Seed 寻址和前缀一致性原则。

#### 12.1.2 通胀与名义经济

正式保留：

- headline CPI 通胀；
- core CPI 通胀；
- 通胀预期；
- CPI 价格水平；
- GDP 平减指数；
- 名义 GDP。

内部结构可压缩为：

```text
核心通胀
= 通胀预期
+ 产出缺口贡献
+ 工资/服务惯性
+ 进口价格压力

总体通胀
= 核心通胀
+ 食品能源偏离
```

能源保留明确状态，因为石油、运输、居民消费和工业成本都有真实消费者。食品、服务、核心商品、进口成本等仍可输出当年贡献，但不必全部成为互相独立的长期慢状态。

#### 12.1.3 货币政策与收益率曲线

正式保留：

- 政策利率；
- 中性实际利率；
- 实际政策利率；
- 2Y 收益率；
- 10Y 收益率；
- 10Y 期限溢价；
- 实际 10Y。

政策仍应具有观望区、渐进执行和方向惯性，不能每年机械追随当期通胀。收益率继续遵守：

```text
国债收益率 = 同期限未来政策利率预期 + 同期限期限溢价
```

政策和曲线的经济含义不能合并，但可以共用一个利率系统的状态容器、随机合同、边界工具和测试框架。全球层不建立详细 QE/QT、准备金或国债发行；这些由区域公共账户拥有。

#### 12.1.4 全球资金与信用

新模型可把美元、流动性和信用放进同一个金融条件系统，但必须保留三个不同的基础状态：

1. 美元相对价值；
2. 全球资金流动性；
3. 企业信用压力。

正式对外保留：

- 美元指数及年度变化；
- 美元或跨境融资压力；
- 上游资金流动性；
- IG/HY 信用利差；
- 信用可得性；
- 违约风险；
- 最终综合 FCI。

新内核不再保留一套独立的前置普通 `financial_stress_index` 供消费者使用。最终 FCI 由利率、美元、流动性和信用状态派生；需要在通胀前表示资金压力时，直接读取对应基础因子，不再叠加第二个综合压力指数。

#### 12.1.5 石油与轻量商品

石油同时影响通胀、工业成本、运输、航空和资产市场，应继续独立建模。正式保留：

- 石油需求缺口；
- 石油供给缺口；
- 库存紧张程度；
- 实际油价；
- 名义 Brent；
- 综合商品价格变化；
- 能源成本压力。

当前产能、闲置产能、库存覆盖天数和详细价格贡献可压缩为少数内部状态，仅在审计模式输出完整解释。食品和工业商品保持轻量指数，不立即建立完整物理市场。

#### 12.1.6 资产市场公共输入

资产参考中枢不属于全球宏观内核，而是内核之后的第一个消费者：

```text
全球宏观快照
→ 企业盈利中枢
→ 要求回报/ERP
→ 估值中枢
→ 权益价格、权益总回报、国债和信用资产参考
```

宏观内核只交付最小快照。权益资本化价格参考不得与含票息债券财富直接比较；统一比较必须使用权益与债券各自的总回报参考。如未来确需反馈，只能通过具名的下一年接口进入对应宏观 owner。

### 12.2 建议简化或取消的内容

#### 取消虚构的全球统一账户

新全球内核不建立：

- 全球财政赤字或初级余额；
- 全球政府债务；
- 全球国债净发行和期限结构；
- 全球央行资产负债表；
- 全球 QE/QT；
- 全球主权风险溢价。

这些项目对资本市场很重要，但现实所有者是各区域财政部、主权债务账户和区域央行。全球层只提供共同政策、无风险曲线、美元、资金和风险环境。

#### 缩减通胀分项慢状态

核心、预期和能源传导继续保留。其它分项优先作为当年贡献或支持性账户，不为每个分项建立完整的记忆、随机过程、边界和公开合同。

#### 合并工程框架而不混淆经济含义

- 政策与曲线共用利率系统基础设施；
- 美元、资金与信用共用金融条件基础设施；
- 各组件共用年度状态、边界、随机寻址、身份和诊断协议；
- 区域共用相同执行骨架，通过制度组件表达北美市场型、中国银行/社融型、欧洲货币联盟型、日韩低利率高债务型及新兴区域外部融资型差异。

#### 删除重复综合指数

不同时保留多个表达相同方向的金融压力、流动性、风险偏好和信用压力总分。基础因子分别拥有状态，系统只发布一个后置 FCI。风险偏好如资产层确有消费者，可作为资产定价结果，而非宏观内核的第二个 FCI。

#### 派生字段随用随算

真实政策缺口、10Y-2Y 斜率、名义 GDP 等由权威状态派生。它们可以公开展示并接受恒等式验证，但不拥有独立随机过程，也不成为另一套调参对象。

#### 身份与诊断分离

模型版本、参数哈希、初始条件哈希和批准记录每次运行保存一次，不在每个年度行重复。普通运行只生成核心状态；审计模式再生成贡献、边界调整、会计残差和随机消费记录。

### 12.3 建议的数据结构

```text
RunIdentity
├─ Seed、期限、模型版本
├─ 参数与初始条件哈希
└─ 随机合同与结果哈希

AnnualMacroState
├─ 实际经济
├─ 通胀与名义经济
├─ 政策与收益率曲线
├─ 美元、资金与信用
└─ 石油与商品

NextYearInputs
├─ source_year
├─ target_year
├─ owner
└─ 具名传导值

OptionalDiagnostics
├─ 状态转移贡献
├─ 会计残差
├─ 边界命中
└─ 随机消费记录
```

这样可以避免所有模块不断把自己的中间字段平铺追加到同一个年度字典，同时保留必要的解释和审计能力。

### 12.4 目标规模

新资产市场专用全球内核当前规模为：

- 39 个真正参与年度转移的持续状态；
- 62 个年度状态字段和 42 个正式最小快照字段；
- 10 个彼此有明确经济含义、按地址独立的普通随机源；
- 六个主要组件；
- 一个最终 FCI；
- 一套可选诊断输出。

当前全球年度行约有 795 个字段，其中大量是贡献、会计、边界和身份数据。新模型不是要求永久删除这些审计信息，而是让普通运行和资本市场消费者不再承担它们。

### 12.5 推荐执行顺序

```text
实际经济
→ 通胀与名义账户
→ 政策与收益率曲线
→ 美元、资金与信用
→ 石油与商品
→ 最终全球宏观快照
→ 资产市场
```

石油在第 `t` 年形成的成本冲击只能通过具名接口影响第 `t+1` 年通胀或真实活动。资产市场如果以后需要反馈，也遵守同样的一年滞后规则。普通路径没有隐藏第二遍回算。

### 12.6 与当前模型的关系

推荐保留两套用途清楚的目录：

```text
现有 Capital Market Lab
= 完整参照、经济机制资料库、冻结结果与对照组

新的 Asset Simulation
= 精简全球内核、精简区域合同、行业/机构与交易市场
```

新模型优先复用以下已经验证的原则，而不是复制整套实现：

- GDPBase 的增长与产出缺口；
- 通胀惯性及油价滞后传导；
- 政策率的渐进反应；
- 收益率的政策预期加期限溢价；
- 信用可得性与 IG/HY OAS 分离；
- 石油实际价格与名义价格分离；
- Seed 可复算、短路径前缀一致；
- 普通 Seed 与特殊事件分离；
- 唯一 owner、具名下一年接口和无同年隐藏循环。

新目录已经正式建立。后续经济参数只在 `asset_simulation/config/` 内独立调整，不反写旧 Capital Market Lab；旧目录也不再把本文件列为自己的当前任务。两套模型具有不同用途和结果身份，不能混用参数或结果哈希。
