## 名录分节

行业层已经移动过「银行 vs 其它上市企业」。梯队 `world_1` / `second` / `third` 只做身份、同档新闻零和的对手圈和份额软地板：没有组墙、信封惯性、路径尺度或组加总吃饼。下文表格仍按梯队分节，方便对照卡片。各票走自己的特许权路径。份额目标只跟本年特许权中枢加自身新闻，不再把 HY／FCI／缺口同号加到每一票上。公布份额先夹进该票硬轨道，再按同档把今年份额新闻做成零和，再套行业 Lorenz 天花板，再按本年特许权中枢做梯队软地板，再用命名合计 vs 残差的慢信封贴回本年中枢合计附近。净利率公布值 = 特许权路径残差 + 同年 `(banks_net_margin − 20%)`，再夹进该票硬轨道。残差份额是 `1 − 命名公布份额之和`，允许为负。`listed_net_margin` 仍不接到个股。

| 词 | 是什么 | 不是什么 |
|---|---|---|
| 票中枢 | 各票自己的份额／净利率／派息折线 | 组加总目标 |
| 硬轨道 | 各票自己的份额／净利率／派息墙 | 组容量 |
| 梯队 | 世界级／二等／三等身份；同档新闻零和对手圈；份额软地板 | Viewer 筛选器、组墙、组加总吃饼 |
| 同档新闻零和 | 今年份额新闻为正的，按本年中枢从同档新闻为负的手里拿；力度 0.30 | 特许权中枢竞赛、跨档吃饼、残差出纳 |
| 行业 Lorenz | 命名个体占银行营收饼的头部天花板 | 净利率曲线、日常油门 |
| 命名合计信封 | 命名 vs 残差贴本年特许权中枢合计；普通年 ±1.0pp | 组墙、同号份额宏观 |
| 行业气候 | 同年 `banks_net_margin − 20%` 加在各票净利率上 | 把个股中枢改写成 20%、把份额再跟一遍宏观 |
| 残差 | `1 − 命名公布份额之和` | 必须为正的其它饼 |

## 同档份额新闻零和

身份仍走本年特许权中枢。只有步进里那截已经夹过硬轨道的 `share_news_excess`（有新闻的份额 − 没新闻的份额）进入竞赛。不是 `公布份额 − 中枢`，也不是组加总吃饼。

```text
同档 = 配置里的 world_1 / second / third
若该档既有新闻为正的票、也有新闻为负的票：
    过账 = 0.30 × min(正新闻之和, |负新闻|之和)
    赢家按 本年中枢 × 正新闻 分赃
    输家按 本年中枢 × |负新闻| 出账
硬轨道仍赢；档内合计不变；残差不进场
全档同号或开局新闻为 0：不动
```

招行只和二等抢今年运气，不抢摩根大通，也不抢苏州。中枢慢慢抬头是卡片，不是武器。插在 Lorenz 之前：同行先过账，若世界级一起把前缀顶穿，Lorenz 再削给残差。本年刚被 Lorenz 削过的头仍不靠地板／信封补回去；新闻零和发生在削头之前，信号也不含压力事件的份额砸盘。

## 行业份额 Lorenz 天花板

命名个体占银行营收饼有一条连续天花板。不是组墙，也不是 5%／10% 两档台阶。净利率不走这条曲线，改走行业气候。

开局银行饼前缀（104 家）：CR1 摩根大通 3.08%（个股硬墙 4.60%）、CR5 10.41%、CR10 16.85%、CR20 23.86%、命名合计 36.45%。结点大约比这些前缀高 25%；第一名结点 4.8%，高于摩根大通个股墙。

```text
L(0) = 0
L(1/104) = 4.8%
L(5/104) = 13.0%
L(10/104) = 21.0%
L(20/104) = 29.5%
L(1) = 45%
```

名次用上一年公布份额；t0 用开局。只削当前头部前缀：若前 k 名合计超过 L(k/n)，按力度 1.0 收到天花板。削下来的给残差；不抬尾、不挤尾。没有 Lorenz 地板，也没有 Lorenz 惯性。普通开局前缀在曲线内，各票特许权 RNG、惯性、新闻尺度和个股硬轨道都不改写；只有头部作为一组冲过 L(k/n) 时才动手。

## 梯队份额软地板

`world_1` / `second` / `third` 不是组墙。Lorenz 之后，对每个未在本年被 Lorenz 削过的名字：

```text
自身地板 = 0.80 × 本年特许权份额中枢
若公布份额 < 自身地板：
    公布份额 += 0.60 × (自身地板 − 公布份额)
    再夹进该票硬轨道
```

同梯队合计若仍低于 `0.80 × 本年中枢合计`，把差额的 0.60 按「低于自身中枢的程度」加给薄票，硬天花板仍赢。抬上来的份额来自残差。本年刚被 Lorenz 削过的头不抬。普通 ±10% 摆动碰不到这条地板；贴在个股硬墙上会被抬离。整包三等都已经顶死在各自硬地板、又没有上修空间时，软地板可以绑不住——接受。

## 命名合计 vs 残差

残差也是银行。点名的 104 家合计不该跟着信用周期从残差里抢饼或吐饼。行业层已经移动过银行占上市营收；个股层只切这块饼。

```text
结构合计 = 本年各票特许权份额中枢之和（开局约 36%）
目标合计 = 当前命名合计 + 0.35 × (结构合计 − 当前命名合计)
再夹进 [结构合计 − 1.0pp, 结构合计 + 1.0pp]
按灵活票（未顶死在个股硬墙、本年没被 Lorenz 削过的头）同比缩放
削下来或补上去的给残差
```

本年刚被 Lorenz 削过的头不往上加回去，削下来的留在残差。相对涨跌仍由特许权折线和新闻决定；信封只动命名合计这一档，不恢复组墙。JSON 里仍留着份额宏观系数，步进不再读取它们。

## 会计

```text
营收 = 占银行营收份额 × 银行营收
盈利 = 营收 × 净利率
信用成本 = 营收 × 信用成本率
分红 = 盈利 × 派息率
本年留存 = 盈利 − 分红
开局ROE = clamp(12% + 1.2pp × tanh(Seed), 9%, 15%)
期初净资产_0 = 当年盈利 / 开局ROE
期初净资产_t = 上一年年末净资产
年末净资产 = 期初净资产 + 本年留存
ROE = 盈利 / 期初净资产
残差份额 = 1 − 命名观察份额之和
```

开局 ROE 不再钉死在 12%。12% 仍是卡片会计中枢和事件抽签权重锚，也是暴雷目标净资产用的 `anchors.roe`；Seed 只在 t0 把开局 ROE 轻抖约 ±1.2pp（tanh 饱和，常见大约 10.8%–13.2%）。成立年份写在各票 `identity.founded_year` 和属性卡上，overlay 另公布 `opening_age_years = start_year − founded_year`。年龄不改特许权、新闻或事件。虚构皮：葡京 1999、卡斯卡迪亚 1986、阿尔伯塔北方 1938。合并换皮用现行法人年（摩根大通 2000、Truist 2019、ABN 2010），连续品牌用品牌年（巴克莱 1690、汇丰 1865）。

个股净利率是各票自己的影子折线，再加上同年行业气候。银行 overlay 的 `listed_net_margin` 不写入 `*_net_margin`。`banks_net_margin` 只作为相对 20% 中枢的加减项，不改写卡片中枢。

## 三条控制量

份额、净利率、派息独立发布；盈利和分红是派生。锚点按 `year_index`（2025=0）锁死，不随本次请求的 `years` 缩放。第 60 年之后钉死终点，不再往外爬。步进公式在 `model/issuer_icbc.py`，不复制；只换配置和 `issuer.{id}.*` 随机地址。

份额是主故事，有开局、中途、第 60 年三个锚，中间用单调折线连接：

```text
终点 = 开局 + 60年跨度 × 折叠抽签（向上更难）
u = tanh(share_pace)
中途年 = clip(25 − 10u, 15, 35)
中途比例 = clip(0.5 + 0.25u, 0.25, 0.75)
中途水平 = 开局 + 中途比例 × (终点 − 开局)
中枢_t = 折线(开局 → 中途 → 终点)，t≥60 钉死
观察值_raw = persist × 上年公布 + (1−persist) × (中枢_t + 宏观) + 年噪声
公布观察值_t = clamp(观察值_raw, 该票硬轨道)
```

净利率和派息只有开局和第 60 年，中间是直线。终点仍分别与份额终点 unit 相关约 0.50 / 0.40。开局也对份额起点做很小的同向偏置。净利率公布时再加同年 `(banks_net_margin − 20%)`；惯性走去掉气候后的特许权残差。个股净利率上不再另加期限利差／HY／缺口／衰退，避免和行业 AR 算两次。顶到轨道后停在边界。没有 S/SS/A 标签。六个宏观事件端口仍不绑定银行危机。银行行业压力事件已打开：抽中后改写该票剩余份额中枢折线，暴雷靠亏损缩、跃进靠大赚扩，硬轨道仍赢。

预留且恒为空：本地政策利率、本地信用周期、存款特许权、RWA 密度。

## 同年拥挤步骤

各票仍独立画中枢。没有组团缩放。净利率和派息不是饼。

| 量 | 规则 |
|---|---|
| 份额路径 | 始终 `k = 1.0` |
| 份额当年中枢 | 不按组加总缩放 |
| 份额公布观察值 | 先夹进该票自己的硬轨道；再按同档把今年份额新闻做成零和；再按上年名次套 Lorenz 天花板；再按本年特许权中枢做梯队软地板；再用命名合计 vs 残差信封贴回本年中枢合计附近。普通 Lorenz 碰不到；贴墙会被抬离 |
| 净利率 | 特许权折线 + 自身噪声 + 同年 `(banks_net_margin − 20%)`，再夹进该票硬轨道。名录不再做 32% 均值软拉 |
| 派息 | 全名录至少两票且均值 > 36% 时，按 0.25 力度下拉；不是饼，也不上 Lorenz |

公布的 `*_residual_banks_revenue_share` 是 `1 − 命名观察份额之和`，同一年残差值相同，允许为负。

## 命名发行人压力事件（银行第一类）

这是行业层的第一类随机特殊事件，行业记录在 [`INDUSTRY_LAYER.md`](INDUSTRY_LAYER.md)。不是宏观六端口。目录 `config/bank_issuer_events_v0.1.json`，步进 `model/issuer_fade.py`。**当前打开**：`events_open: true`，`max_events_per_run: 2`。第一次 55%，第二次独立 24%。动手大约第 8–20 年。抽中的票仍上市。组加总吃饼仍不调用。

抽中后改写该票**剩下的份额中枢折线**：动手当年中枢钉住，终点改成新平台，硬轨道仍赢。下移靠几年亏损／少分；上移靠几年多赚少分。净利率和派息之后回到特许权路径，但走在新的份额中枢上。12% ROE 不是产品目标。命名信封按新的中枢合计贴残差；动手中的票不参与新闻零和、软地板和信封缩放。

默认 104 家在可抽池，`excluded_ids` 为空。形态按动手前一年公布份额名次，加绝对份额安全轨：

| 档 | 开局先验 | 可抽形态 | Viewer |
|---|---|---|---|
| 大行 `mild` | 名次偏前，或份额明显高于 0.32% | 盈利受压或小幅跃进 | 可轻微受压或小幅跃进 |
| 中票 `core` | 中间名次 | 确认暴雷、份额阴跌、特许权跃进；不能挤兑重组 | 可确认暴雷或跃进 |
| 尾票 `tail` | 名次偏后且份额明显低于 0.10% | 确认／阴跌／挤兑重组或特许权突破 | 可重组或突破 |

档与档的形态权重在边界重叠。下移的 `stub_frac` 仍随名次从大约 0.94 插到 0.42；上移不走这条下移插值，只用形态自己的 1.05–1.55 带子。0.32% / 0.10% 是行业饼否决切点，与名次共用 `blend_width = 0.08` 做相对半宽：贴在切点上否决约一半，远高于切点才锁死。CIBC 开局仍是大行赢家档，但形态混权不再从百分位的 50% 跳到 100%。

抽签仍用影子净利率当特许权 ROE 代理：净利率越低权重越高；`share_mix = −0.45` 再按体量缩小权重，所以工行可以抽中，但远小于西盟／葡京。打开可抽池只改谁能被抽，不改 0.55 / 0.24。

四种下移加上三种上移：

| 形态 | 谁 | 份额中枢 | 盈利 |
|---|---|---|---|
| 盈利受压 | 大行档 | 约两年收到约 92% | 净利率变薄，仍为正 |
| 确认暴雷 | 中票／尾票 | 约四年收到约一半 | 1–2 年净利为负 |
| 份额阴跌后确认 | 中票／尾票 | 约七年阴跌 | 前面仍赚钱，再确认 |
| 挤兑后重组 | 只限尾票 | 约两年快掉 | 同年巨亏 |
| 小幅跃进 | 大行档 | 约两年升约 10% | 多赚少分 |
| 特许权跃进 | 中票 | 约四年升约 22% | 多赚少分 |
| 特许权突破 | 尾票 | 约三年升约 38% | 多赚少分 |

盈利恒等式不变：`盈利 = 营收 × 净利率`。确认／阴跌／重组的确认年净利率可以为负，派息 0。跃进不走负利润。属性卡中枢表不随 Seed 改写。

## 五年营收／盈利预测

每票每年（只要后面还剩 5 年）出一份 vintage。对象只有营收和盈利。没有初级／中级／高级，没有看涨／看淡标签，分数不展示。

```text
普通五年折线
  as-of 尚未到暴雷动手年：
      营收缰绳 = 无事件特许权份额中枢 × 同年银行营收
      盈利缰绳 = 营收缰绳 × (特许权净利率中枢 + 同年行业气候)
      再按 Seed 轻抖，营收夹在缰绳 ±12%，净利率夹在缰绳 ±3pp
  as-of 已经到达动手年：
      缰绳改用此后公布真值（事件已是事实），仍做同样轻抖和夹带
神级五年折线
  = 该五年已经公布的营收／盈利，含新闻、气候和窗口里的暴雷或跃进
```

普通报告在动手前不当这票会出事。神级可以看到真实曲线。盈利 = 营收 × 净利率。点上的营收／盈利是十亿美元（`revenue_billion_usd` / `earnings_billion_usd`），和 Viewer 个股金额同一单位，不是年报里的万亿美元。预测不回写全球、银行饼或个股 `result_hash`。载荷在 `issuers.{id}Forecast`；当前 Viewer 不画操作界面。

## 季度展示

`expand_issuer_quarters` 把年报拆成 Q1–Q4，季节中枢略偏 Q4，带 Seed 噪声，前三季四舍五入、Q4 吃残差。各票走 `issuer.{id}.quarter.*`。四季营收、盈利、分红、信用成本加总等于当年年报；Q4 净资产钉死年末。这不是季度宏观机。`expand_icbc_quarters` 是工行包装。
