## 1. Goal C 到底要解决什么

Goal A 已把普通通胀、政策行动和收益率曲线做出可用波动；Goal B 已把国际风险周期、汇率、贸易、资本流与 RoW 波动分配接通。Goal C 不再建设新的宏观层，也不通过继续加随机项让曲线“更热”。它负责把已经形成的模型收成一个可以长期维护和交给资本市场下游使用的稳定版本。

最终结果必须同时做到：

1. **用户看见的是宏观状态，不是开发过程。** 默认页面突出 GDP、通胀、政策、曲线、信用、能源、货币和国际账户；版本号、哈希、开发术语和过度解释退出主要界面。
2. **资产字段不冒充真实交易市场。** 当前权益与债券序列是宏观盈利、估值和利率条件形成的复利参考，不是可交易市场逐年收益预测；界面名称必须准确。
3. **复杂账户可以继续存在，但不争夺默认注意力。** TGA、RRP、MBS、准备金目标、QE/QT 和债务期限份额仍是央行、财政、事件和行业层的接口，放在公共账户／专业明细中即可。
4. **好看的 Seed 不能替代统计验收。** 0–399 用于校准，400–499 用于验证，500–699 是留出集；三段都要满足同一组硬门槛。
5. **不破坏已经完成的架构。** 单一 World、同年前馈、G17 跨年清算、实际／名义 GDP 恒等式、国际账户守恒和普通 Seed 无具名事件全部冻结。

一句话概括：**Goal C 是产品语义和质量门禁的收口，不是第三轮模型扩张。**

## 3. 冻结边界：不可自行改写

以下属于架构和会计红线。即使执行者有不同意见，也只能写进复核意见，不能在 Goal C 中直接改变：

- 默认产品仍是一个 `CoupledWorldRun`，Viewer 仍只请求 `/api/world`。
- 全球同年仍按 `real → inflation → rates → funding/credit → oil/commodity → asset` 前馈。
- 区域读取同年全球结账行与上一年国际输入；G17 当年清算后只发布给下一年。
- 北美和中国大陆不反写同年全球，不进行隐藏重跑。
- 实际 GDP、GDP 平减指数、名义 GDP 与增长恒等式保持闭合。
- 本地 GDP 继续使用本币；跨区域加总才换共同美元。
- G17 贸易、资本、国际收支和货币篮子残差继续 `<1e-8`。
- 内部 Scope 和契约名称 `g17_lite` 可以保留；面向用户统一显示“国际”。
- 六个特殊事件端口继续为零；普通 Seed 不绑定疫情、战争、金融危机、国运或称号世界。
- API 字段名、JSON 契约和模型内部资产字段名不因文案调整而重命名。

## 4. W7：过度设计与 Viewer 语义收口

### 4.1 三层字段规则

Goal C 不进行大规模删字段。按用途分成三层：

| 层级 | 内容 | Viewer 位置 | 规则 |
|---|---|---|---|
| Core | GDP、通胀、政策率、2Y/10Y、FCI、信用、能源、货币、贸易、资本、公共债务 | 默认卡片和主要模块 | 先回答“世界处于什么状态” |
| Derived | 实际政策率、期限利差、实际 10Y、平减指数、实际资产财富、PE、ERP、利润份额、守恒残差 | 年度明细或对应模块 | 不拥有独立随机项，不升级为更多同级模块 |
| Reserved | TGA、RRP、MBS、准备金目标、QE/QT、期限份额、中国数量工具 | 公共账户／专业明细 | 保留接口，不为平稳世界逐项制造随机波动 |

这里的“默认突出 Core”不等于删除已有模块。实际／名义 GDP、增长、通胀、政策曲线、信用、能源、资产和公共账户可以继续存在；差别是首页卡片和文案必须先服务于宏观判断。

### 4.2 必做的界面语义修改

#### A. 资产参考重新命名

内部字段保持不变，只改用户可见文案：

- “权益总回报” → “权益复利参考”。
- “主权债总回报” → “主权债复利参考”。
- “宏观之后的资产总回报参考” → “宏观资产复利参考”。
- “权益价格 / 总回报” → “权益价格 / 复利参考”。
- “实际权益 / 债券财富”可保留在年度明细；不得升级为首页主叙事。

目标是明确：这些指数用于给后续行业和资本市场提供长期中枢，不是声称未来某年真实股票会涨跌多少。

#### B. 移除主要界面的开发信息

当前底部 identity 文案包含模型版本、结果哈希和 Seed。模型 identity 和哈希继续保留在 API、缓存、测试和调试数据中，但不在主要 Viewer 中显示版本解释或哈希。

建议面向用户只显示：

```text
Seed 42 · 61 个年度状态
```

服务状态仍可显示“单一世界 · 全球 + 北美 + 中国大陆 + 国际”，但不要出现 `vNext`、内部版本标签、构建号、跨 Seed 百分位或开发完成度。

#### C. 修正“国际账户总览”的坐标口径

当前国际总览把约 100 的 `USD/CNY 相对指数` 放在左轴，把约 ±数点的国际风险周期放在右轴；同在左轴的贸易与资本流因此容易被压平。

改成：

- 左轴：国际风险周期、北美贸易余额/GDP、中国私人资本流入/GDP。
- 右轴：USD/CNY 相对指数。

图例明确标注“USD/CNY 相对指数（右轴）”。不对任何序列使用 `×5`、`×10` 等视觉放大，也不改变底层数据。

#### D. 保持四 Scope 的统一交互

- 全球、北美、中国大陆、国际继续共用年份 slider 和图上 pointer 年份切换。
- Scope 切换后，当前年份不跳回末年。
- 窄屏不允许 25bp 文案断裂、横向溢出或模块按钮不可见。
- 面向用户不得再出现 “G17-lite”；URL 中的 `scope=g17_lite` 和内部键保留。

### 4.3 W7 明确不做

- 不新增“高级模式”状态机或新的服务端查询参数。
- 不删除公共账户字段、契约或 JSON 数据。
- 不把 Viewer 变成交易终端，不增加 K 线、订单簿、行业板块或逐日数据。
- 不因文案改名而改变权益、债券、PE、ERP 的公式。
- 不给 Reserved 字段补随机波动来让图看起来更丰富。

### 4.4 W7 最低代码验收

- `node --check asset_simulation/viewer/static/js/app.js` 通过。
- Viewer 静态契约测试同步更新，旧的“权益总回报／主权债总回报”不再作为用户可见主标签。
- `/api/world` 返回结构、内部 model version、result hash 和 `g17_lite` 键不变。
- 四个 Scope 均能打开；国际总览的左右轴不再把贸易／资本线压扁。

## 5. W8：三段 Seed 与统一终验

### 5.1 审计工具目标

保留现有 `build_audit(seed_start, seed_end, years)` 与默认 CLI 用法，新增一个轻量的 Goal C 分段入口，不建立第二个模型 owner。

建议形式：

```powershell
cd C:\d_e\oiltanker\airport
py -3.13 -m asset_simulation.audit_volatility --profile goal-c --years 60 --output <path>
```

`goal-c` profile 固定运行：

- calibration：0–399；
- validation：400–499；
- holdout：500–699。

三段总计仍是 700 个世界，不要为了同时生成“全体”再重复跑一遍 0–699。报告应包含每段原有审计结构、门禁结果和总的 pass/fail 摘要。日常单元测试只用极小 Seed 范围验证报告结构，不把 700 Seed 运行塞进常规测试。

### 5.2 审计需补齐的质量信号

现有报告已经覆盖水平、年度变化、事件频率、持续期、相关性、RoW 方差、bounds 与 G17 残差。Goal C 需要补齐：

1. 每个 Scope 的非有限值计数，必须为零。
2. 每个 bound 的命中率，而不只是命中次数。
3. 三段 Seed 的门禁判定与失败原因。
4. 必要的跨段漂移摘要，避免只给三大块 JSON 让人手工比较。

不要在审计脚本复制宏观公式；所有数据继续来自 `run_coupled_world`。

### 5.3 硬门禁

每个 Seed 分段都必须满足：

| 门禁 | 要求 |
|---|---|
| 可运行性 | 所有世界完成，无异常、NaN、Infinity |
| 守恒 | 贸易、资本、货币篮子最大残差 `<1e-8` |
| Bounds | 单字段命中率 `<0.5%`；若高于 `0.1%` 必须在报告中解释 |
| 全球增长相关 | 全球—北美、全球—中国、全球—RoW 增长相关均不低于 `0.75` |
| RoW 波动份额 | 三地区未加权增长方差占比大致 `25%–50%` |
| 通胀均值 | 全球 `1.8%–2.7%`，北美 `1.6%–2.7%`，中国 `1.3%–2.7%` |
| 通胀年变动标准差 | 全球、北美、中国均为 `0.30–0.75pp` |
| 普通通胀尾部 | 每段应出现高于 4% 和低于 0% 的年份；不频繁出现 8% 以上事件型结果 |
| 政策暂停 | 北美约 `25%–60%`；中国小于 5bp 的实质暂停约 `20%–55%` |
| 10Y 年变动标准差 | 北美 `0.25–0.75pp`；中国 `0.22–0.65pp` |
| 汇率年变动标准差 | 北美 `1.2%–3.5%`；中国 `0.8%–2.8%` |
| 贸易年变动标准差 | 北美、中国均为 `0.15–0.70pp GDP` |
| 私人资本流 | 5%–95% 主要位于 `±3.5% GDP`，且不是近似常数 |

这些是普通平稳世界的使用门槛，不是“越靠上限越好”的优化目标。边界附近的结果要先检查因果链和持续期，不得用输出截断器把失败藏起来。

### 5.4 跨段稳定性

除三段各自过门禁外，还需输出以下漂移检查：

- 增长、通胀、政策和 10Y 的分段均值最大差一般不超过 `0.25pp`。
- 通胀、10Y、汇率、贸易和资本流的标准差，任意两段相对差一般不超过 `30%`。
- 5%／95% 尾部方向一致，不允许只有校准集出现尾部、验证和留出集全部消失。
- 高通胀、通缩、倒挂和政策暂停的频率不应在留出集突然变成校准集的数倍。

“一般”表示这几项属于带解释的质量门禁：若仅有一个小样本频率略超阈值，可以判为 warning；若涉及均值漂移、尾部消失或多项同时失败，则必须判 fail。

### 5.5 确定性、恒等式与方向性

完整测试必须继续证明：

1. 全球、北美、中国、G17、World 对相同 Seed 可复算且前缀一致。
2. 全球和区域实际 GDP × 平减指数 = 名义 GDP，累计增长口径一致。
3. 2Y 对政策路径的响应强于 10Y；期限溢价、久期供给、储备需求与避险方向不倒置。
4. G17 风险收缩、实际利差、增长差和储备需求对资本／汇率的方向与文档一致。
5. 资产实际财富仍等于名义复利指数除以 CPI，不因 Viewer 改名而变化。

优先复用现有测试。新增测试只覆盖分段报告结构、判定逻辑和本次改动的 Viewer 契约，避免重复已有公式测试。

### 5.6 真实页面验收

由 Codex 在 Grok 完成后执行最终页面验收，至少检查：

- `seed=42&years=60` 的全球、北美、中国大陆、国际四 Scope。
- Scope 和模块切换，slider 与图上 pointer 年份同步。
- 国际总览左右轴、零线、图例和小数位。
- 实际／名义 GDP、CPI／平减指数、货币、能源和资产复利参考的单位。
- 桌面宽屏与窄屏布局。
- 浏览器控制台无错误，网络只请求一个耦合世界。

Grok 在实施前可以对 Goal C 提出更好的拆分、阈值或界面方案。不同意见不能只写成一句偏好，必须在实施报告中按下列格式记录：


允许直接采用的范围：

- 更清楚但不改变含义的中文文案。
- 更小、更容易维护的 Viewer 实现。
- 不重复运行 700 Seed 的审计组织方式。
- 更合理的 warning / fail 划分，只要不放松守恒、非有限值、确定性和留出集原则。
- 补充本任务书遗漏但与 Goal C 同范围的真实缺陷。

不得自行采用的范围：

- 改变年度时序、World 架构、G17 跨年规则或会计恒等式。
- 删除公共字段、改变 API／契约或重命名内部 `g17_lite`。
- 修改宏观公式以追求漂亮曲线，却没有先证明 Goal A/B 的统计门禁失败。
- 加入特殊事件、国运、称号世界、完整交易市场或新区域。
- 为节省时间跳过留出集、把留出集并回校准集，或看完留出集后无记录地继续调参。
